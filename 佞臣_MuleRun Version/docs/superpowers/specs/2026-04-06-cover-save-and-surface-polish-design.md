# 《佞臣》封面、单存档与页面信息层优化设计

日期：2026-04-06
工作区：`C:\Users\happyelements\Desktop\佞臣 Demo\.worktrees\codex-difficulty-balance-inline\佞臣_MuleRun Version`

## 目标

这一轮不改核心数值公式，重点解决三类体验问题：

1. 游戏入口不够成熟  
当前仍以“背景介绍页 + 启动即弹恢复存档”为主，缺少真正的封面、开始/读档分流与统一菜单感。

2. 回合内信息层虽已丰富，但仍有断裂  
回合首页文案密度不够，冯道之锦囊仍偏摘要感；朝堂页部分说明过多但关键信息仍不够直观；结算页与玩法总览命名也不够统一。

3. 单存档与回到菜单流程尚未产品化  
现在自动续档弹窗适合开发期，不适合正式入口体验。

## 设计范围

本轮覆盖：

- 新增封面页
- 单存档覆盖式保存与“回到菜单”流转
- 难度选择前置
- 首页、朝堂页、玩法总览、结算页、计谋回报页的文案与信息层优化
- NPC 回复长度的软下限优化

本轮不覆盖：

- `average-mainline` 前 10 回合平衡研究
- 新的战役数值调优
- 新的外部势力数值门槛调整

## 一、信息架构调整

新的入口结构改成：

1. `封面页`
2. `背景介绍页：纷乱之世`
3. `玩法总览页`
4. `正式游戏`

### 1. 封面页

封面页是新的默认入口。

功能：

- 背景使用本地视频  
  `C:\Users\happyelements\Desktop\513896983.mp4`
- 左下提供两个主按钮：
  - `开始游戏`
  - `加载存档`
- 同一区域前置难度选择：
  - 简单
  - 普通
  - 困难
  - 地狱

交互：

- `开始游戏`
  - 进入背景介绍页
  - 使用当前选中的难度
- `加载存档`
  - 读取唯一存档
  - 直接恢复到存档所处进度
- 若无存档：
  - `加载存档` 置灰或弱禁用
  - 提示“暂无存档”

### 2. 背景介绍页

保留现有“纷乱之世”的世界观作用，但补清楚北周状态：

- 明确加入：`贺拔琪已垂帘听政五年`

这一页不再承担难度选择职责。

### 3. 玩法总览页

命名与文本统一到当前系统术语：

- 每回合流程中的 `北周结算` 改为 `天道结算`
- `天道判官` 改为 `天道结算`

### 4. 回合内统一菜单

所有回合内页面，在现有 `玩法说明` 附近统一增加两个按钮：

- `存档`
- `回到菜单`

按钮尺寸、层级、风格与 `玩法说明` 一致。

行为：

- `存档`
  - 覆盖保存当前唯一存档
  - 成功后给轻提示，例如“已存档”
- `回到菜单`
  - 先自动保存
  - 再返回封面页

## 二、单存档设计

采用单存档覆盖模式，不做多栏位。

### 当前问题

现在 `App.tsx` 中存在“发现上局存档”的 overlay。  
这一流程与新封面页冲突，因为封面已经承担了“开始/读档”的决策。

### 新设计

- 启动时不再弹恢复存档 overlay
- 启动后直接进入封面页
- 存档的读取入口统一收敛到封面页的 `加载存档`
- 回合内的 `回到菜单` 会自动保存后退出到封面

### 数据层原则

继续复用现有单存档存储键与 snapshot 结构，不新增第二套存档系统。  
本轮只改入口与调用时机，不重写底层 save schema。

## 三、回合首页优化

### 1. 朝堂简报

当前首页 `朝堂简报` 信息密度仍不足。  
改法：

- 参考文档  
  `C:\Users\happyelements\Desktop\佞臣_20回合首页开场文案_修订整合版.docx`
- 平均长度目标：
  - 每回合约 `230-250` 字
- 优先直接采用 Word 稿的小说化正文
- 保持“北周为主、南陈为辅”的叙事方式

实现上建议单独维护首页专用 briefing 数据，不直接覆盖所有 `event.briefing`，避免影响 AI prompt 的事件摘要长度。

### 2. 冯道之锦囊

改为明确的两段结构：

- 第一段：`冯道之密语【朝局】`
  - 只写朝堂势力、宫廷名分、责任归属、借刀、议程争夺
- 第二段：`冯道之密语【外部军头】`
  - 只写外部势力线的阶段、缺口、窗口和下一手建议

要求：

- 不再出现“话没说完就以省略号截断”的情况
- 必须是完整句
- 若某回合没有明显外部军头建议，则第二段允许不显示

### 3. 战役分支回合补全

第 `11` 回合（蜀地）与第 `17` 回合（淮南）首页回响，需要补齐三种状态：

- `得手`
- `僵持`
- `战败`

不仅补标题，也补正文 summary。

## 四、朝堂页优化

### 1. 标题与说明

- 大标题改为：`朝堂局势：先辨阵营，再锁人心`
- 删除说明条：
  - `先看什么`
  - `再看什么 / 为什么重要`
  - `下一步做什么`
- 删除朝堂势力与地方军头区块下的批语型说明

目标是让页面更像“情报台”，而不是“玩法说明页”。

### 2. 军事人物驻地直显

以下人物在卡面直接显示驻地，不必点开详情才知道：

- 尉迟暮
- 令狐律光
- 独孤文约
- 贺拔伯圭
- 安思明
- 尔朱烈

### 3. 地方军头卡布局

外部人物卡从“头像式”升级成更直观的横向卡：

- 左侧：人物立绘
- 右侧：当前信息

保留目前已有的：

- 军力
- 忠诚
- 姿态
- 外部线进度
- gap 文案

### 4. 朝堂势力角色卡补暗线信息

朝堂人物卡也直接显示：

- `暗线已明：x/x`

这样玩家在朝堂页就能建立“试探揭暗线 -> 其余计谋更贴个人利益”的长期心智。

### 5. 首次进入朝堂页弹窗

第一回合玩家第一次进入朝堂页时，弹出暗线教学：

- 每个角色有数条暗线
- 暗线代表其个人利益、旧怨、隐秘筹码
- `试探` 可揭露暗线
- 其余计谋越符合角色个人利益，越容易取得更大效果

## 六、NPC 回答长度优化

### 问题来源

目前 NPC 回复之所以比早期版本短，主要是：

- prompt 变长了
- 结构化上下文变多了
- 但 `maxTokens` 没同步拉高

### 设计原则

不做硬性的“字数不足自动拼句”，避免水话。  
采用软下限：

- prompt 明确要求：
  - 至少 `2-4` 句
  - 目标长度约 `90-160` 中文字
- 模型 token 上限提高
- 仍允许在极短情绪场景下略短，但不能只剩一句话敷衍了事
