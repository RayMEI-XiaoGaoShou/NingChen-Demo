# 《佞臣》割据 / 叛乱自然可达性与教学增强设计

日期：2026-04-06  
适用分支：`codex/difficulty-balance-inline`

## 1. 背景

当前外部势力线的机制已经完整落地：

- `割据` 与 `造反` 都有明确门槛与回合窗口。
- `试探 -> 献策 -> 谗言 / 离间 -> 割据 / 造反` 这条玩法链在规则上成立。
- 冯道之锦囊也已经能给出 `养信 / 探暗线 / 离心 / 等窗口` 这类阶段提示。

但从试玩体验和既有 balance 研究看，普通玩家仍然很难顺着玩法自然摸到这条线。问题不在“系统有没有”，而在“玩家是否能看见、理解并持续追踪这条线”。

## 2. 目标

本轮优化目标不是把割据 / 造反做成首通默认主路，而是把它们做成：

1. 可见  
玩家能明确意识到“这是可追的一条副路线”。

2. 可学  
玩家能理解自己当前处在哪个阶段，还差哪一环。

3. 可追  
普通玩家在连续几回合有意识投入后，能比较自然地接近 `割据`；`造反` 仍保留为更高理解度、更高风险的上位结果。

4. 不破坏主线  
外部势力线仍是副路线，不应压过中枢主线的存在感。

## 3. 当前问题拆解

### 3.1 入口可见性不够

当前首页锦囊会提示某个外部人物处在 `养信 / 探暗线 / 离心 / 等窗口` 哪一步，但这些提示仍偏概括：

- 更像一句方向提醒。
- 不像一条可执行的阶段任务。
- 不足以让玩家明确“再做什么就能前进”。

### 3.2 缺少“进度感”

当前普通玩家通常不知道：

- 自己距离 `割据` 还差多少信任。
- 还差几层暗线。
- 忠诚离可用阈值还差多远。
- 当前回合是否已经是值得出手的窗口。

于是玩家虽然知道有这条线，但很难把它当成一条可规划的路线去推进。

### 3.3 主循环过强地把注意力拉回中枢

每回合：

- 首页高亮核心人物
- 朝局情报更强调中枢冲突
- 玩家天然更容易优先处理“这回合最急”的中枢问题

而外部势力线恰恰需要：

- 连续盯同一个外部人物
- 先养、再探、再压、再等

这与普通玩家的自然操作习惯存在张力。

### 3.4 奖励出现偏晚

当前外部线的爽点通常出现在很后面：

- 前期多是涨 trust、降 loyalty、探暗线
- 真正“明牌”的成就感要等到 `割据 / 造反`

中间阶段缺少足够强的“阶段性确认”，导致普通玩家容易中途放弃。

## 4. 设计原则

### 4.1 不先大改硬门槛

本轮先把外部线视为“教学与体验问题”，而不是优先继续放松数值门槛。

原因：

- 如果先直接放门槛，玩家会更容易误以为这是一键大招。
- 会削弱这条线作为“高理解度副路线”的辨识度。

### 4.2 让玩家知道自己“还差什么”

外部线不该只给阶段名，还要给：

- 当前进度
- 下一步建议
- 距离明牌差哪一环

### 4.3 让冯道之成为阶段导师，而不是只给一句谜语

冯道之在这条线里最适合扮演：

- 阶段解释者
- 风险提示者
- 行动建议提供者

而不是仅仅继续保留模糊锦囊。

### 4.4 把“造反”与“割据”区分清楚

- `割据`：先求自保、自雄、坐据地方
- `造反`：在更高风险窗口下明牌举兵

普通玩家应更容易先摸到 `割据`，而不是直接把 `造反` 当成默认按钮。

## 5. 推荐方案

推荐走“进度可视化 + 专属教学 + 冯道之阶段辅佐”的组合方案。

### 5.1 外部线做成明确的四阶段链

围绕单个外部人物，明确显示四阶段：

1. `养信`
2. `探暗线`
3. `离心`
4. `等窗口`

但不再只显示阶段名，还要附一条当前最关键信息：

- `养信`：离可用信任还差多少
- `探暗线`：还差几层暗线
- `离心`：忠诚是否已降到危险区
- `等窗口`：当前回合是否适合明牌

### 5.2 首次接近外部线时给专属教学弹窗

触发建议：

- 当任一外部人物第一次进入“接近可操作”的状态时触发
- 例如：
  - trust 达到中高位
  - 或已探出第一层暗线
  - 或 loyalty 明显下滑

弹窗需要讲清：

1. 外部势力线不是一回合打成
2. 你需要先养信、再探暗线、再压离心、最后等窗口
3. `割据` 与 `造反` 的区别
4. 这条线更适合连续投入，而不是偶尔点一下

### 5.3 冯道之给“阶段化建议”，而不只是抽象提醒

冯道之围绕当前选中的外部人物，建议输出这三类信息：

1. **当前阶段**
   - 你现在是在 `养信 / 探暗线 / 离心 / 等窗口` 哪一步

2. **还差哪一环**
   - 例如：
     - “此人已近可用，仍差最后一层暗线。”
     - “其心已离，然信火尚不足，不可骤然摊牌。”

3. **下一手建议**
   - 推荐更适合的计谋方向
   - 例如：
     - 现在先用 `试探`
     - 现在适合 `献策`
     - 现在应当 `离间`
     - 现在只待窗口，不宜明牌

### 5.4 在可明牌窗口前一回合给更明确的“临门一脚提示”

当某外部人物已满足大部分条件，但只差窗口或只差一小环时：

- 首页锦囊提示要明显升级
- 让玩家明确感到“这条线就快成熟了”

例如：

- “贺拔伯圭已近可用，只待乱局窗口，再迫其明牌。”
- “安思明离翻旗只差最后一层底牌，不可此时操切。”

### 5.5 中间阶段要有更强的阶段反馈

当前外部线的正反馈主要集中在最后明牌时。建议中间阶段也加强反馈文案：

- 暗线增加时，让玩家更明确意识到“你摸到对方底牌了”
- loyalty 下滑到关键阈值附近时，给更显著的危险感
- trust 达到关键阈值附近时，给更明确的“他开始愿意听你”反馈

## 6. 冯道之在这条线中的角色定义

冯道之在外部势力线中应被定义为：

### 6.1 阶段导师

他负责告诉玩家：

- 这条线不是单点操作，而是一条链
- 你正在链上的哪一步
- 下一步最合理的推进方式是什么

### 6.2 风险解释者

他要提醒玩家：

- 现在太早摊牌会翻车
- 外部人物未离心就硬推会适得其反
- 暗线未足时造反只会被平叛

### 6.3 不开天眼的谋士

他不能提供玩家尚未掌握的秘密，只能基于：

- 已知人物公开背景
- 已探出的暗线
- 当前 trust / loyalty / status
- 当前回合时局标签

给出建议。

## 7. 预期效果

如果这套优化成立，普通玩家体验应变成：

1. 能明确意识到外部线存在
2. 能理解它是四阶段推进，不是一键触发
3. 能知道当前差什么
4. 更容易在普通游玩中自然接近一次 `割据`
5. `造反` 仍然是更高风险、更高理解度的路线

## 8. 本轮不做什么

本 spec 不包含：

- 直接放松割据 / 造反硬门槛
- 改写外部线数值公式
- 新增外部势力的全新结局分支
- 调整战役系统与主线数值

这些内容如需继续优化，应在教学增强落地并观察一轮后再判断。

## 9. 成功标准

本轮优化成功，至少应满足：

1. 玩家首轮接触外部线时，能说清它的四阶段链条
2. 玩家在某个外部人物身上，能明确知道“还差哪一环”
3. 冯道之的建议不再只是抽象密语，而能变成可执行建议
4. 普通玩家在后续试玩里，比当前更容易自然接近一次 `割据`
