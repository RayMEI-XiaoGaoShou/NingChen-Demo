# 难度分档与数值曲线设计

## 目标

本设计稿聚焦《佞臣》当前中后期体验里的五个相关问题：

1. 北周计谋成功率偏高，普通玩家容易连续三手全成。
2. 南陈国力增长偏快，前十回合较容易提前反超北周。
3. 按冯道之锦囊游玩时，普通玩家较难自然触发割据与叛乱玩法。
4. 谶纬回合的玩法学习成本偏高，玩家第一次进入相关回合时不知道该如何使用。
5. 游戏需要明确的难度分档，以同时满足剧情体验玩家与策略挑战玩家。

本轮设计的主基准是：

- `普通` 难度下，普通玩家首通胜率大致过半，目标区间为 `45% - 55%`。
- 玩家需要做出有效判断才能获胜，但不应感到系统在前期就明显向自己倾斜。
- 割据、叛乱、谶纬这类高理解度玩法应该是“可见、可学、可追”的，而不是完全靠复读攻略。

## 设计原则

### 1. 先钉住普通档，再派生其他档位

所有难度都基于同一套内容、同一套状态机、同一套 AI 结构化解析链路。  
不同难度只通过参数偏移、提示强弱和门槛松紧来区分，不拆成多套玩法规则。

### 2. 不用“硬抬敌人数值”代替策略深度

`困难` 与 `地狱` 难度应主要通过以下维度增加挑战：

- 下调北周线常规成功率
- 收紧南陈自然增长与问政余波
- 提高失败与曝光成本
- 减少系统提示

不建议用“把叛乱/割据门槛也无限抬高”的方式增加难度，否则会削弱高手路线的存在感。

### 3. 高理解度玩法先补教学，再考虑放宽门槛

割据、叛乱与谶纬都不是纯数值问题。  
在调整门槛之前，先让玩家知道：

- 这条线是什么
- 现在处在哪一步
- 下一步该做什么

如果教学补足后仍明显偏难，再小幅放松门槛。

## 当前问题诊断

### 北周计谋成功率

当前北周线成功率由以下部分叠加构成：

- 基础成功率
- 信任度加成
- 计谋类型修正
- AI 结构化解析的角色匹配、事件匹配、可执行性加成
- 曝露风险惩罚

当前问题不在单一极端计谋，而在整体基线过高，尤其是 `probe` 与 `advise` 这类低风险常用计谋过稳。  
同时，代码中虽存在“同回合同目标惩罚”，但真实玩法中同回合同一 NPC 本就不能重复出手，这条惩罚在正常游玩中几乎不会生效。

结果是：

- 玩家更容易在前中期稳定打穿北周关键人物
- 北周五维受损节奏偏快
- 普通玩家首通胜率被显著抬高

### 南陈国力增长

当前南陈增长由三部分叠加：

- 自然增长
- 每回合问政即时收益
- 问政余波

问题不在问政即时收益本身，而在“自然增长 + 余波”累加后，南陈在前中期增长过顺。  
这样会导致即便玩家北周线只是发挥正常，南陈也可能靠系统曲线自行追近。

### 割据与叛乱玩法

当前外部势力升级路线本身是合理的，但普通玩家不容易自然理解完整链路：

- 涨信任
- 压忠诚
- 攒暗线
- 等到允许发动外部行动的窗口回合

目前冯道之锦囊更偏“提示哪个人值得碰”，但对“你此刻在链路的哪一步”提示不够。

### 谶纬玩法

谶纬玩法在系统内已具备独特位置，但首见学习成本偏高。  
玩家第一次进入可用谶纬的回合时，往往不能迅速理解：

- 谶纬不是普通献策
- 它适合打谁
- 说辞该偏什么语义
- 为什么它比普通献策更容易反噬

## 普通难度基准参数

以下参数是本轮建议的首轮调校值，优先目标是把 `普通` 调到“首通胜率过半，但不会明显偏易”的区间。

### 北周计谋成功率

| 参数 | 当前 | 普通档建议 |
| --- | --- | --- |
| `baseRate` | `0.62` | `0.56` |
| `probe` 修正 | `+0.18` | `+0.11` |
| `advise` 修正 | `+0.14` | `+0.09` |
| `characterFit` 加成 | `0.18` | `0.14` |
| `executability` 加成 | `0.12` | `0.09` |
| `eventFit` 加成 | `0.12` | `0.09` |
| `exposureRisk` 惩罚 | `0.08` | `0.11` |

设计意图：

- 低风险计谋仍是稳定主力，但不再接近白送。
- 玩家若想打出三手全成，需要更好的识人与时机判断。
- 高风险计谋先不大动，保留“更像刀尖起舞”的辨识度。

### 南陈自然增长与问政余波

| 维度 | 当前 | 普通档建议 |
| --- | --- | --- |
| `finance` 自然增长 | `0.65` | `0.54` |
| `grain` 自然增长 | `0.55` | `0.46` |
| `military` 自然增长 | `0.50` | `0.42` |
| `socialOrder` 自然增长 | `0.55` | `0.46` |
| `governance` 自然增长 | `0.48` | `0.40` |

问政收益建议：

- 即时收益先不调整
- 余波整体乘以 `0.88`

设计意图：

- 把南陈从“自然就涨得很顺”改成“要靠答对问政才能稳步追上”。
- 保留玩家在南陈线做出正确判断时的正反馈。
- 压低系统自动滚雪球的强度。

## 割据与叛乱玩法设计

### 当前定位

割据与叛乱应是“高理解度奖励路线”，而不是普通玩家首通默认主路。

因此这条线的理想状态是：

- 首通玩家能意识到它存在
- 二周目起玩家能主动尝试
- 熟练玩家可以围绕它制定完整策略

### 第一阶段方案：先补教学，不改门槛

第一阶段不直接修改门槛，而是先让冯道之锦囊从“提示关键人物”升级为“提示链路阶段”。

锦囊应显式传达三类信息：

1. 这回合该碰谁
2. 你现在是在“养信 / 离心 / 探暗线 / 等窗口”的哪一步
3. 还差哪一环才能走向割据或叛乱

### 第二阶段方案：若仍偏难，再小幅放宽

如果补足教学后，实际体验仍证明普通玩家几乎看不到这条玩法，可小幅放宽：

| 条件 | 当前 | 建议 |
| --- | --- | --- |
| 割据信任门槛 | `72` | `68` |
| 割据忠诚门槛 | `35` | `40` |
| 割据暗线门槛 | `2` | 不变 |
| 叛乱信任门槛 | `85` | `82` |
| 叛乱忠诚门槛 | `18` | `22` |
| 叛乱暗线门槛 | `3` | 不变 |

设计意图：

- 降低普通玩家“看得到却永远够不着”的挫败感
- 不把高理解度玩法削成低门槛玩法

## 谶纬玩法设计

### 设计目标

第一次接触谶纬时，玩家应该在施计页内明确理解：

- 谶纬不是普通献策
- 它偏向“名分、法统、天命、灾异”
- 它更适合打宫廷中枢与名分焦虑强的目标
- 它收益更高，也更容易反噬

### 引导投放方案

| 回合 | 形式 | 内容 |
| --- | --- | --- |
| 第 13 回合首次进入施计页 | 弹窗 | 完整介绍谶纬的用途、目标、语义方向与风险 |
| 第 14 回合 | 小提示条 | 提醒谶纬仍偏“法统/名分裂缝”，不是普通献策 |
| 第 19 回合 | 小提示条 | 提醒这是高风险终局工具 |
| 第 20 回合 | 小提示条 | 只保留极简提醒，不再重复教学 |

### 弹窗核心文案结构

建议弹窗只讲四点，不写成长教程：

1. 谶纬不是普通献策，而是借天命不稳放大朝局裂痕。
2. 它更适合对宫廷中枢、名分焦虑重的人下手。
3. 说辞应偏灾异、法统、天意与人心，不宜写成兵粮调度。
4. 用得准可极大放大收益，用偏则更易反噬自身。

## 四档难度设计

### 总体分工

| 难度 | 面向玩家 | 目标首通胜率 |
| --- | --- | --- |
| `简单` | 想体验剧情与人物关系的玩家 | `75% - 85%` |
| `普通` | 默认玩家 | `45% - 55%` |
| `困难` | 复盘后希望有明显压力的玩家 | `20% - 30%` |
| `地狱` | 熟练玩家与挑战玩家 | `< 10% - 15%` |

### 相对普通档的参数偏移

| 难度 | 北周成功率 | 南陈自然增长 | 问政余波 | 外部势力门槛 | 引导强度 |
| --- | --- | --- | --- | --- | --- |
| `简单` | `+0.06` | `+12%` | `+10%` | 略放松 | 最完整 |
| `普通` | 基准 | 基准 | 基准 | 基准 | 完整 |
| `困难` | `-0.05` | `-10%` | `-10%` | 建议基本不变 | 简版 |
| `地狱` | `-0.09` | `-15%` | `-18%` | 建议基本不变 | 极简 |

### 高难度设计说明

`困难` 与 `地狱` 不建议再明显抬高割据、叛乱的门槛。  
高难度更适合：

- 压低普通施计的容错
- 放慢南陈自然增长
- 增强曝光与失败的代价
- 减少系统的教学与提示

这样可以保留“高手仍有高手玩法”，而不是让高难玩法变窄。

## 引导投放表

### 冯道之锦囊

| 场景 | 建议输出重点 |
| --- | --- |
| 外部军头首次成为关键人物 | 明确告诉玩家现在该做的是“养信”还是“离心” |
| 外部军头接近升级门槛 | 明确提示“还差暗线 / 还差信任 / 还差窗口” |
| 第一次进入允许割据的窗口回合 | 提示地方军权、粮道与中央失控感的联动 |
| 第一次进入允许叛乱的窗口回合 | 提示叛乱需要的不只是忠诚低，还需要私心、暗线与战时空隙 |

### 谶纬教学

| 场景 | 建议输出重点 |
| --- | --- |
| 第一次可用谶纬 | 完整弹窗 |
| 后续可用谶纬回合 | 一行或两行轻提醒 |

## 验证标准

普通档调整完成后，应重点验证以下体验目标：

1. 前五回合里，玩家感受应是“局势可撬动，但北周不脆”。
2. 第十回合时，普通玩家大多应仍处于胶着或略落后，不应稳定提前反超。
3. 低风险施计不再普遍三连成。
4. 玩家在第十三回合首次接触谶纬时，能够明白它的基本使用思路。
5. 外部势力路线即便首通不一定成功，玩家也应能理解其成长链路。

## 实施顺序

建议实现时按以下顺序推进：

1. 先只调整 `普通` 档数值。
2. 跑自动回归与真人试玩，确认第十回合国力分布回到合理区间。
3. 补冯道之锦囊与谶纬引导。
4. 在 `普通` 档稳定后，再派生 `简单 / 困难 / 地狱`。

## 非目标

本设计稿不包含以下内容：

- 不重写 AI 结构化解析链路
- 不新增新的回合或新的战役分支
- 不改动二十回合的主框架
- 不重做 UI 风格，只涉及提示内容与数值配置
