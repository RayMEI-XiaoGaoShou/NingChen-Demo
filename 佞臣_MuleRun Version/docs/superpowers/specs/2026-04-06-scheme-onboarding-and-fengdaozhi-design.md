# 《佞臣》施计教学与 AI 冯道之辅佐设计

日期：2026-04-06

## 背景

当前施计系统经过多轮重构后，计谋语义与数值链路已经比早期版本清晰许多：
- `献策` 已区分利国、利人害国与空泛建议
- `谶纬` 已具备专属双段输入流程
- `设局嫁祸` 已从旧的“放风构陷”重定义为更贴合 UI 的单目标话术做局
- `谗言 / 离间 / 借刀` 已补 nation-impact gate，避免泛泛输入直接伤及北周国力

但实际试玩与朋友体验反馈仍集中在同一个问题：**玩家一开始不知道怎么玩**。

问题不只在“说明不够多”，而在于三层断裂：
1. 玩家不知道每条计谋到底在干什么、彼此边界是什么。
2. 玩家不知道天道 AI 会如何判断“你的这段输入是否有效”。
3. 即使理解规则，玩家也未必会写出第一段合格输入，尤其在 `献策 / 谶纬 / 设局嫁祸` 这三类语义要求较高的计谋上。

因此，这轮设计目标不是再补零散 tooltip，而是把“施计入门”升级为一个完整的新手教学与实战辅佐系统。

## 目标

### 体验目标
- 新玩家在首回合进入施计页时，应能快速理解各计谋的玩家视角定义、判定逻辑和潜在效果。
- 玩家在第一次可用 `谶纬` 时，应知道“谶（chen）纬”是什么、为什么不是普通离间、以及应如何输入。
- 玩家在不会写输入时，可以借助 AI 冯道之得到一段符合当回合局势和当前计谋逻辑的可用文本。
- 冯道之的辅佐不能变成“开天眼代打”，必须严格受限于玩家当前可见信息。

### 设计目标
- 将现有“首回合施计提示弹窗”升级为“施计总引导弹窗”。
- 将现有谶纬提示升级为“首次谶纬专属教学弹窗”。
- 将冯道之从纯文本提示升级为“AI 驱动谋士”，提供限次实战代拟能力。
- 让教学与辅佐遵循难度分档：
  - 简单：每回合 3 次
  - 普通：每回合 2 次
  - 困难：每回合 1 次
  - 地狱：每回合 0 次

## 方案对比

### 方案 A：双层教学 + AI 冯道之渐进式辅佐（推荐）
内容：
- 首回合施计页弹完整计谋引导弹窗
- 首次谶纬解锁弹专属引导
- 冯道之提供按难度限次的 AI 代拟辅佐

优点：
- 同时解决“看不懂规则”和“不会写输入”
- 与当前 AI Native 玩法方向完全一致
- 冯道之角色更鲜明，不只是页面上的一段提示词

缺点：
- 设计与实现工作量最大
- 需要严格定义冯道之的权限边界和用词风格

### 方案 B：重做教学弹窗，不做 AI 代拟
优点：
- 实现快、风险低
- 能改善首回合迷茫感

缺点：
- 仍不能解决玩家“知道概念但不会写”的问题

### 方案 C：只做 AI 冯道之，不重做大引导
优点：
- 立刻提高可玩性

缺点：
- 容易变成“代打”而不是教学
- 玩家对计谋系统的理解依旧薄弱

### 结论
采用方案 A。

## 设计一：首回合施计总引导弹窗

### 触发时机
- 玩家第一次进入施计页面时自动弹出。
- 弹出后本局不再自动重复。
- 后续回合通过右上角常驻按钮再次打开。

### 替代关系
- 该弹窗取代当前首回合施计提示弹窗。
- “玩法介绍”按钮继续保留；新增一个更聚焦的按钮，例如：`计谋指南` 或 `施计总览`。

### 信息结构
建议使用分页或手风琴结构，而不是一整页长文本。

#### 第一屏：玩家视角定义
每条计谋都用一句话解释“你到底在做什么”。
建议定义如下：
- `试探`：探口风、探弱点、探暗线。
- `献策`：借对方私利送上一策；利国则帮敌，利人害国才是真有用。
- `谗言`：对他说另一个人的坏话，先种下疑刺。
- `离间`：让两方关系起裂缝，彼此开始提防。
- `设局嫁祸`：诱其失言、失态或误判，让嫌疑落回他自己身上。
- `借刀`：让他替你去对付另一个人，是整条裂缝链路的收尾技。
- `请托`：求人情、求遮掩、求照应，主要用于关系与立场维护。
- `谶纬`：借灾异、征兆与天命说法，撬动名分与合法性的裂缝。
- `煽动割据 / 煽动造反`：外部势力专用的高门槛终局动作。

#### 第二屏：天道如何判断是否有效
用非技术化方式解释 AI 判定逻辑：
- 你说的话要先切中这个计谋本身的语义。
- 还要切中这个 NPC 的性格、处境、利益或恐惧。
- 如果你想伤到北周国力，还必须把人物层后果真正传导到国家层。
- 空泛大道理、谁都能套的话，通常只会带来很弱的效果。

#### 第三屏：可能影响哪些层次
建议分层列出：
- 人物层：信任、忠诚、暗线、是否更愿意听你。
- 关系层：谁开始怀疑谁、谁和谁关系裂开。
- 势力层：帝党、后党、地方外镇之间的平衡变化。
- 国力层：财政、粮赋、军事、秩序、统治穿透力。
- 战役层：当输入真正触及军粮、转运、调度、名分时，会逐步影响蜀地与淮南战局。

#### 第四屏：特别提醒
必须突出 3 条：
1. `献策` 可能反效果：
   - 若你写的是利国之策，北周会因此变强。
   - 只有“对目标个人有利、对北周整体有害”的献策，才会稳定帮助你。
2. `谶纬` 不是普通离间：
   - 它先动摇的是合法性和名分，而不是直接挑拨两个人。
3. `设局嫁祸` 的逻辑：
   - 不是“替他去放风”，而是“让他自己掉进局里、背上嫌疑”。

## 设计二：首次谶纬专属教学弹窗

### 触发时机
- 第一次进入可用 `谶纬` 的回合时自动弹出。
- 之后不再自动重复，但可通过指南按钮再次查看。

### 核心内容
必须覆盖：
1. 术语解释：`谶（chen）纬`。
2. 谶纬是什么：
   - 统治者用来解释天命、吉凶、法统与灾异的神秘主义话语体系。
3. 在《佞臣》里的作用：
   - 不是普通政治挑拨。
   - 它通过灾异/征兆 → 名分裂缝 → 指向可疑之人/势力，来动摇北周合法性与人心。
4. 如何使用：
   - 先写一段 `谶辞 / 征兆`
   - 再写一段 `解释 / 指向`
5. 它如何影响北周：
   - 若解释得当，会动摇法统、秩序、治理与军心。
   - 若只是泛泛玄虚或写成普通离间，效果会很弱。

### 示例结构
用一正一反两个示例：
- 好示例：有征兆、有解释、有指向
- 坏示例：只有泛泛“天意不好”，没有落到名分和人物结构

## 设计三：AI 冯道之的角色定义

### 角色定位
冯道之在这一版中不再只是“每回合一句提示”的旁白，而是：
- 一个玩家可主动请求的谋士
- 一个只基于当前已知局势推演的代拟者
- 一个帮助新手迈过“第一句怎么写”的门槛的人

### 不是开天眼
冯道之的权限必须严格受限：
- 只能使用玩家当前已知信息：
  - 当前回合事件
  - 当前可见 NPC 公开信息
  - 玩家已解锁的暗线
  - 当前朝局和最近余波
  - 主角是否处于生存危机
- 不可访问未解锁暗线
- 不可给出“系统层面最优解”式上帝视角建议

### 使用方式
玩家在施计页已经选好：
- 目标 NPC
- 计谋类型

此时出现按钮：
- `让冯道之帮你谋划（0/2）`

玩家点击后：
- 冯道之基于当回合时局、NPC 背景、所选计谋的结算链路，生成一段可用输入
- 对 `谶纬` 则生成双段：
  - 谶辞/征兆
  - 解释/指向
- 玩家可以：
  - 直接采用
  - 在此基础上改写
  - 放弃不用

### 难度分档
- 简单：每回合 3 次
- 普通：每回合 2 次
- 困难：每回合 1 次
- 地狱：0 次

### 冯道之的输出风格
- 不是写成长篇策论
- 应给 1 段可直接使用、带明确方向的说辞
- 口气应像“点你一手”，不是替你把所有逻辑说穿

## 设计四：页面入口与交互

### 页面入口
在施计页面右上角形成两类按钮：
- `玩法介绍`
- `计谋指南`

说明：
- `玩法介绍` 仍是全局说明
- `计谋指南` 聚焦于计谋定义、判定逻辑、特别规则、谶纬教程

### 施计页中的冯道之按钮
触发条件：
- 已选目标 NPC
- 已选计谋类型
- 剩余可用次数 > 0

文案建议：
- `请冯道之代拟一手（1/2）`
- 谶纬下可改成：`请冯道之拟谶（1/2）`

### 玩家体验顺序
首回合：
1. 进入施计页
2. 自动弹“施计总引导”
3. 关闭后开始选 NPC / 计谋 / 输入
4. 如不会写，可点冯道之按钮

首次谶纬回合：
1. 进入可用谶纬的施计页
2. 自动弹“谶纬专属教学”
3. 玩家看到双段输入框
4. 可自己写，也可请冯道之先代拟

## 冯道之在两类教学中的角色

### 在割据/叛乱教学中的角色
他应是“阶段导师”，不是旁观评论员。
职责：
- 明确告诉玩家当前在 `养信 / 探暗线 / 离心 / 等窗口` 哪一步
- 在接近门槛时指出“还差哪一环”
- 在可出手回合提醒这是窗口，而不是继续泛泛铺垫

### 在谶纬教学中的角色
他应是“解释话语规则的人”。
职责：
- 告诉玩家谶纬先动摇的是合法性，不是直接挑拨关系
- 强调先写征兆，再解释名分裂缝，最后暗示谁最可疑
- 在玩家请求代拟时，输出一段合格的谶辞与解释

## 风险与边界
- 风险 1：AI 冯道之过强，导致玩家只点“代拟”不思考。  
  解决：限次、输出不过长、不给完整最优链路，只给一手。  
- 风险 2：教学弹窗过长，玩家直接跳过。  
  解决：分页、摘要化、给示例、强调“之后可再看”。  
- 风险 3：冯道之越权，泄露未解锁信息。  
  解决：提示与代拟都只基于玩家已见上下文。  
- 风险 4：谶纬教学与离间教学仍重叠。  
  解决：在专属弹窗中明确强调“谶纬先动合法性，离间先动关系线”。

## 验证标准
- 新玩家第一次进入施计页后，能说清各主要计谋至少一层基本定义。
- 玩家能明确知道为什么 `献策` 可能帮敌国、为什么 `设局嫁祸` 是让目标自己背锅。
- 第一次解锁谶纬后，玩家能理解双段输入结构，不再把它写成普通离间。
- 简单 / 普通难度下，冯道之代拟应显著降低“第一句不会写”的卡顿。
- 冯道之输出不能出现明显开天眼或泄露未解锁信息。

## 结论
本轮应优先把“施计体验优化”定义成一个完整系统，而不是继续零碎补 tooltip：
1. 首回合施计总引导弹窗  
2. 首次谶纬专属教学弹窗  
3. AI 冯道之按难度限次实时代拟  
4. 冯道之在割据/叛乱与谶纬教学中担任阶段导师，而非纯文本提示者
