# 《佞臣》计谋语义与 UI 对齐设计

日期：2026-04-05  
范围：`MuleRun Version` 数值分支  
状态：设计稿

## 1. 背景

当前施计交互的玩家感知是：

1. 先选一个 NPC
2. 对这个 NPC 说一段话
3. 下一页看到这个 NPC 的反馈

这套交互天然会让玩家认为：**我是在通过这个 NPC 发动计谋，或至少我的话是直接“对他本人说”的。**

但部分计谋的系统语义并不完全符合这种直觉，尤其是：

- `放风构陷`
- `谶纬`

这会导致理解偏差、学习成本和样本编写混乱。

## 2. 当前问题

### 2.1 放风构陷的语义与 UI 冲突最大

当前系统里，`frame` 不需要第二目标，且结算主要落在施计对象本人身上。  
也就是说，当前真实语义更接近：

- 选中某人
- 围绕此人做局、放大疑点、令其背上政治成本

但在现有 UI 中，玩家会自然理解成：

- 我在对这个人说话
- 然后借这个人去对付别人

这会造成“我为什么在对他本人说一段话，却变成把他自己搞臭”的错位。

### 2.2 谶纬与离间的边界不够清晰

当前玩家容易把谶纬理解成：

- 另一种写得更神秘的离间

而不是：

- 借灾异、天命、法统、名分这些解释框架，动摇一个人对当前政治秩序正当性的判断
- 进而改变他看待其他人、势力和行动选择的方式

如果不把两者区分开，谶纬会退化成“带神秘词汇的离间”。

### 2.3 玩家视角定义不统一

目前系统内部有很多真实逻辑，但玩家视角下缺少统一的一句话定义。  
结果是：

- 样本编写不稳定
- 教学难写
- 玩家难以迅速形成“这个计谋到底是干什么的”心智模型

## 3. 设计目标

本轮不直接改数值，也不先改具体代码实现。先统一三个目标：

1. 每个计谋都要有**玩家视角的一句话定义**
2. 计谋的系统语义要尽量和“选人 + 说话 + NPC反馈”这套交互对齐
3. `谶纬` 必须与 `离间` 拉开层级差异，保住特色玩法辨识度

## 4. 计谋分层定义

### 4.1 关系层计谋

这类计谋主要作用于“人和人之间”。

#### 谗言

玩家视角定义：

> 对他说另一个人的坏话，让他先对那个人起疑或生厌。

核心作用：

- 种刺
- 递黑材料
- 让对方开始看某个人不顺眼

#### 离间

玩家视角定义：

> 利用他的疑心与处境，主动撕开他与另一方的裂缝。

核心作用：

- 拆关系
- 扩大互疑
- 令双方合作带刺

### 4.2 声誉层计谋

这类计谋主要作用于“某个人在朝局中的名声与安全感”。

#### 放风构陷

推荐重定义后的玩家视角定义：

> 借他周围的口风、流言与疑点做局，让他自己背上嫌疑与政治成本。

关键点：

- 施计对象仍然是被做局的人
- 但 UI 与文案必须明确告诉玩家：这是“围绕此人放风做局”，不是“托此人去做事”

这意味着 `frame` 应被定位成：

- 不是双人关系计
- 不是借刀
- 而是“把目标本人推向风口浪尖”

### 4.3 代理层计谋

#### 借刀

玩家视角定义：

> 借他之手、借他之势，去压另一个人。

核心作用：

- 让别人替你出手
- 目标在第二人身上
- 风险与收益都高

### 4.4 合法性层计谋

#### 谶纬

推荐重定义后的玩家视角定义：

> 借灾异、天命与名分之说，改变他对局势正当性的理解，再让这种理解撬动关系与行动。

关键点：

- 谶纬不是直接挑拨“谁和谁”
- 它先动“这个局面还是不是天命所归、名实相副”
- 然后才间接改变他看待君臣、党争、边镇、主战次序的方式

## 5. 离间与谶纬的边界

这是本设计里最关键的区分。

### 离间

直接作用对象：

- 两个人
- 两条关系线
- 两个集团之间的互信

常见语言：

- 谁会先甩锅
- 谁会先保自己
- 谁在抢功
- 谁会趁乱上位

一句话：

> 离间直接撬关系裂缝。

### 谶纬

直接作用对象：

- 一个人对“秩序是否还正当”的理解

常见语言：

- 灾异
- 龙气
- 天命
- 名分
- 法统
- 名实不副

一句话：

> 谶纬先撬合法性裂缝，再让关系和行动随之变化。

### 判别标准

如果一句话主要在说：

- “某人会害你 / 会甩锅 / 会踩你 / 会抢你位置”  
  更像 `离间`

如果一句话主要在说：

- “天命已乱 / 灾异示警 / 名分不安 / 有人越分侵权 / 局面失其正当”  
  更像 `谶纬`

## 6. UI 对齐建议

本轮先给设计结论，不直接规定实现细节。

### 6.1 放风构陷

推荐优先改展示语义，而不是先改机制。

现有交互可保留，但在 `frame` 选中后，至少应在 UI 上改为类似表述：

- “选择被做局的人”
- “围绕此人放风做局”
- “你将放大其疑点与政治风险”

不要再让它看起来像：

- “你要对这个人说一句话，让他替你做事”

### 6.2 谶纬

推荐在 UI 和引导里强调：

- 你不是在“神神叨叨吓他”
- 你是在借天命与灾异，重写他对局势的解释框架

因此谶纬的引导最好补两点：

1. 适合谁  
   名分焦虑强、位置敏感、离权力中枢近的人
2. 怎么写  
   先写征兆，再写名分裂缝，再暗示谁最值得警惕

## 7. 推荐的一句话定义（玩家版）

后续教学、样本、提示、设计说明都应尽量统一这套说法。

- `试探`：探他的真心、顾虑和暗线
- `献策`：顺着他的盘算给路，但要分清是利国还是利人害国
- `谗言`：对他说另一个人的坏话，让他先起疑
- `离间`：撕开他与另一方的裂缝
- `放风构陷`：围绕某人做局，让他自己背上嫌疑
- `借刀`：借他之手，去打另一个人
- `求援`：让高信任者替你遮掩、保举或留后路
- `谶纬`：借灾异天命改写他对局势的理解

## 8. 建议的后续实现顺序

1. 先改 `frame` 的展示语义  
   这是当前和 UI 冲突最大的计谋。

2. 再改 `omen` 的教学文案与示例  
   重点不是再加解释，而是把它和 `离间` 拉开。

3. 再决定是否要微调机制  
   如果改完展示后，玩家仍大量误解 `frame` 或 `omen`，再考虑机制层微调。

## 9. 非目标

本设计暂不处理：

- `frame` 的数值改动
- `omen` 强度改动
- `appeal / proxy` 的二期方向性扩展
- 外部势力线教学细化
- 战役数值平衡

这些仍属于后续独立议题。
