# 《佞臣》核心系统对齐与深化设计

**日期**：2026-03-28

**目标**
在不推翻当前可玩主循环的前提下，同时完成两件事：

1. 追认当前游戏里已经稳定落地、但策划案尚未同步的机制。
2. 落地三个最关键的缺口：
   - NPC 关系网络与连锁反应
   - 暗线系统真正驱动线索质量
   - 结局分层与终局报告

**范围边界**
- 不重写主循环状态机。
- 不重做整套 UI 风格。
- 不在本轮引入存档、复盘、地图系统。
- 不把 NPC 关系系统做成任意两人全图模拟，而是只实现“关键关系边”。

---

## 1. 当前真源与追认原则

本轮以“当前稳定可玩的游戏机制”为产品真源。凡已稳定落地、且试玩方向明确的内容，策划案应直接追认，不再回退。

本轮需要追认到策划案的内容包括：

- 南陈五维在首页/结算页可见
- 本回合问政回批前置到结算页
- 天道判官结算输入材料扩充
- `谶纬` 为条件限定特殊计谋
- 基础计谋的军事链外溢规则
- 外部人物 `割据 / 造反` 的新门槛与新伤害
- 提前南征改为分回合压力窗口

文档更新原则：

- 策划案追认“玩家体验层”和“规则层”
- 不追认纯实现细节
- 若当前实现已明显违背旧策划，但试玩与新判断都已确认，则旧策划直接修改，不保留并行口径

## 2. NPC 关系网络与连锁反应

### 2.1 设计目标

让《佞臣》的权谋感真正来自“拆结构”，而不是只来自单次信任涨跌。

玩家的计谋应不仅改变某个 NPC 对主角的态度，还应改变：

- 某人与某人的互信
- 某条合作链是否还能运作
- 某个三角结构是否开始失衡
- 这份失衡是否会在回合结算中折算到势力层与国力层

### 2.2 实现范围

不做“任意两人完全图”，只做关键关系边。

首批关系边来自 `NPC角色卡.md` 的：

- 关系矩阵
- 关键可撬结构三角

首批必须落地的结构：

1. 太后 - 祖廷 - 贺拔伯圭
2. 宇文棣 - 宗艾 - 皇帝通道
3. 贺拔伯圭 - 独孤文约
4. 令狐律光 - 草原人物
5. 尉迟暮 - 宇文棣 / 令狐律光 的军政拉扯

### 2.3 数据模型

新增“关系边”而非“全局关系表”：

- `id`
- `fromNpcId`
- `toNpcId`
- `type`
  - 依赖
  - 竞争
  - 借力
  - 忌惮
  - 军政协同
  - 宫中接口
- `strength`
- `visibility`
  - 公开
  - 半公开
  - 暗线

同时补“结构定义”：

- `triangleId`
- `memberNpcIds`
- `description`
- `instability`
- `breakEffects`

### 2.4 连锁反应口径

本轮只做最小可行版连锁反应：

- 当关键关系边被削弱到阈值以下时，触发结构失衡
- 结构失衡会在结算中产生：
  - 额外 faction change
  - 额外 nation change
  - 额外结算叙事材料

例如：

- 拆掉“贺拔伯圭 - 独孤文约”后，西线协同下降，额外打击军权链/粮道链
- 拆掉“宗艾 - 皇帝接口”后，宫中诏令效率下降，额外打击统治穿透力

## 3. 暗线系统驱动线索质量

### 3.1 设计目标

让“试探”不再只是拿一条收藏品式的暗线，而是让玩家在后续页面里明显感觉到：

- 我知道得更多
- 我看到的话更准
- 我更能判断该对谁下什么手

### 3.2 三层情报输出

同一 NPC 在朝局观察页、冯道之锦囊、相关提示中，按 `intelProgress` 输出三层：

1. `0 条暗线`
   - 只显示公开立场式表态
2. `1-2 条暗线`
   - 显示带偏向的线索
   - 能看出此人的真实焦虑点或短期目标
3. `3 条暗线`
   - 显示接近真实算盘的判断
   - 可以直接服务于选计谋与选目标

### 3.3 触发来源

本轮情报增长来源：

- 试探成功：必得 1 条
- 特定回合事件：可自动揭露相关人物 1 条
- 冯道之锦囊：可指向已解锁暗线的使用方向

### 3.4 约束

- 未解锁暗线不能被公开文本直接说穿
- AI NPC prompt 只能使用已解锁暗线
- 冯道之可以“暗示”，不能“明说未解锁真相”

## 4. 结局分层与终局报告

### 4.1 设计目标

让 20 回合的结束不只是一个胜负标题，而是玩家能看懂：

- 我是怎么赢/输的
- 哪几个人最关键
- 哪股势力撑到了最后
- 我的策略风格是什么

### 4.2 输出结构

终局页扩展为“终局报告”，包含：

1. 胜负主标题
2. 胜负层级
   - 大胜 / 稳胜 / 险胜
   - 惨败 / 惜败 / 险败
3. 关键成因
4. 势力终局状态
5. 核心 NPC 命运
6. 本局统计摘要

### 4.3 判定口径

终局分层不另起一套胜负逻辑，而是在已有 `gameResult` 上继续细分：

- `VICTORY`
  - 看南陈反超幅度
  - 看北周是否出现割据/叛乱/秩序崩口
- `DEFEAT_POWER`
  - 看差距大小
- `DEFEAT_INVASION`
  - 强调提前南征败因
- `DEFEAT_DEATH`
  - 强调政治暴露与处置链

### 4.4 数据来源

终局报告主要来自：

- 全局最终国力
- 最终 faction 状态
- 外部人物最终状态
- 本局关键 scheme 统计
- intel 解锁情况

## 7. 风险与控制

### 7.1 最大风险

- 关系网络若做太泛，会让结算复杂度暴涨
- 暗线系统若直接泄露过深，会破坏信息差玩法
- 结局系统若吃不到足够历史数据，只会变成文案扩写

### 7.2 控制方式

- 关系系统只做关键边与关键结构
- 暗线只改“表述层级”，不改“真相真源”
- 终局报告先做最小可行统计，不追求一次到位的全量复盘
