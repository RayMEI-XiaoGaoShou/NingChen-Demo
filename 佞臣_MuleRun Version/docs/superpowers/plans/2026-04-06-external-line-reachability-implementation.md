# 《佞臣》割据 / 叛乱自然可达性与教学增强实现计划

日期：2026-04-06  
关联 spec：`docs/superpowers/specs/2026-04-06-external-line-reachability-design.md`

## 目标

把外部势力线从“只有懂机制的玩家才会追的隐藏链”升级为“普通玩家看得见、学得会、能持续追踪的副路线”，但不直接放松割据 / 造反硬门槛。

## 范围

本轮实现只做体验与教学增强，不动：

- `割据 / 造反` 的硬门槛
- 外部线数值公式
- 外部线新结局
- 主线与战役系统平衡

## 实现任务

### Task 1：为单个外部 NPC 生成“阶段进度摘要”

在 `src/game/` 新增一个专门 helper，例如：

- `externalLineProgress.ts`

职责：

- 输入：
  - 外部 NPC 当前 trust
  - loyaltyToCourt
  - unlockedSecrets
  - currentRound
  - difficulty
  - current externalStatus
- 输出：
  - 当前阶段：
    - `养信`
    - `探暗线`
    - `离心`
    - `等窗口`
  - 关键缺口：
    - 还差多少 trust
    - 还差几层暗线
    - loyalty 是否仍高于危险区
    - 当前回合是否支持明牌
  - 下一手建议：
    - `试探`
    - `献策`
    - `离间`
    - `等待窗口`

要求：

- 这套 helper 只基于玩家可见状态工作
- 不读取玩家未解锁暗线

### Task 2：把首页冯道之锦囊升级成“阶段导师提示”

更新：

- `src/game/externalActionHint.ts`
- `src/game/roundIntelEngine.ts`
- 需要时更新 `src/components/RoundStart/RoundStart.tsx`

目标：

- 现有 `养信 / 探暗线 / 离心 / 等窗口` 提示保留
- 但补上“还差哪一环”的具体信息
- 例：
  - `冯道之密语：【养信】贺拔伯圭已愿听你七分，仍差最后一点实信，莫急于摊牌。`
  - `冯道之密语：【探暗线】安思明仍藏着底牌，先探出第三层暗线，再谈翻旗。`

要求：

- 提示语言仍保持古典风味
- 但比当前版本更可执行

### Task 3：加入“首次接近外部线”专属教学弹窗

建议位置：

- 施计页或回合首页均可，但优先选择玩家准备操作外部人物的时刻

建议新增：

- `ExternalLineTeachingModal.tsx`

触发条件建议：

- 任一外部 NPC 第一次满足以下之一：
  - trust 达到中高区
  - 已解锁第一层暗线
  - loyalty 明显下滑到可疑区

弹窗内容必须讲清：

1. 外部势力线是四阶段链条，不是一回合打成
2. 四阶段分别是什么
3. `割据` 与 `造反` 的区别
4. 这条线需要持续投入

后续要求：

- 首次自动弹出
- 之后支持从施计页右上角复看

### Task 4：在外部人物卡或详情中增加“阶段感”

从以下二选一或组合：

1. 在外部人物卡上显示一个简化阶段标记
2. 在 NPC 详情页中显示更完整的外部线进度摘要

推荐：

- 卡面显示简版：`养信 / 探暗线 / 离心 / 等窗口`
- 详情页显示完整版：
  - 当前阶段
  - 已满足条件
  - 尚缺条件
  - 冯道之建议

这样玩家不需要每回合只靠锦囊猜。

### Task 5：冯道之在外部线中提供更具体的“下一手建议”

在现有 AI 冯道之代拟系统基础上，不一定让他直接代写全部外部线文本，但至少要让他能明确给出：

- 现在更适合用哪种计谋
- 为什么是这一步

例如：

- 现在先 `试探`：因为还缺暗线
- 现在先 `献策`：因为仍差最后一点信火
- 现在适合 `离间`：因为其心已离，只差再添裂缝
- 现在不可明牌：因为当前回合不是窗口

建议新增一个外部线专用 advisor helper，供：

- 锦囊提示
- NPC 详情页
- 冯道之 assist 面板

共同调用，避免多套规则分裂。

### Task 6：中间阶段反馈增强

在以下状态变化发生时，增强反馈文本：

- 解锁新暗线
- trust 接近割据 / 造反阈值
- loyalty 下滑到关键区间
- 外部人物从 `loyal` 变为更警觉 / 更自保

目标：

- 让玩家感到自己正在推进一条线
- 而不是只有最后点出 `割据 / 造反` 时才第一次有成就感

相关落点可能包括：

- `schemeEngine.ts`
- `roundSettlement.ts`
- `battleReport` / 回合总结文本

### Task 7：测试与验证

新增或更新测试，覆盖：

1. 阶段判断正确
2. 缺口判断正确
3. 教学弹窗触发一次后不重复乱弹
4. 冯道之提示确实包含：
   - 当前阶段
   - 缺口
   - 下一手建议

建议测试文件：

- `src/game/externalLineProgress.test.ts`
- `src/game/externalActionHint.test.ts`
- `src/components/SchemePanel/*.test.tsx`
- 必要时更新 store 保存状态相关测试

最终验证：

- `npm.cmd test`
- `npm.cmd run build`

## 实施顺序

推荐顺序：

1. Task 1：阶段进度 helper
2. Task 2：锦囊升级
3. Task 3：首次教学弹窗
4. Task 4：外部人物卡/详情阶段感
5. Task 5：冯道之下一手建议
6. Task 6：中间阶段反馈增强
7. Task 7：测试与全量验证

## 风险与边界

### 风险 1：提示过满，主线信息被淹没

控制办法：

- 首页只显示最重要的一条外部线提示
- 详细信息放在卡面 / 详情页 / 教学弹窗里

### 风险 2：把外部线做得像“自动任务清单”

控制办法：

- 阶段与缺口要明确
- 但不要把每个数字都做成死板 checklist UI
- 仍保留冯道之的古典风味

### 风险 3：冯道之像开天眼

控制办法：

- 严格只用玩家可见状态
- 不让其引用未探出的暗线或隐藏设定

## 完成标准

本轮完成后，应满足：

1. 玩家第一次接触外部线时，能明确理解四阶段链条
2. 玩家看某个外部 NPC 时，能知道自己还差哪一环
3. 冯道之对外部线不再只是谜语，而是具有可执行建议
4. 不修改硬门槛的前提下，普通玩家对 `割据` 的路径感明显增强
