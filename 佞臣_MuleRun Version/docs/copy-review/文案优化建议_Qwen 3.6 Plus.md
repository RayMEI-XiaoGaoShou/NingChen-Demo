## 一、序章

### 1. 纷乱之世 · 第 3 段

- **位置**：`prologueContent.ts` / 纷乱之世 / 第 3 段
- **现在文案**：「全天下无不期待，有位真正的大英雄能站出来，结束这望不到尽头的纷乱之世……」
- **可以改成**：「天下人无不期盼，能出一位真正的大英雄，结束这望不到尽头的纷乱之世……」
- **原因**：「全天下」在古汉语语境里略显口语化，「天下人」更自然；「期待」偏现代书面语，「期盼」更贴合历史叙事语感。

### 2. 女帝之托 · 第 1 段

- **位置**：`prologueContent.ts` / 女帝之托 / 第 1 段
- **现在文案**：「她并非纸上帝王，而是曾与先帝一道平定天下、又在乱世中被毒伤旧躯的人。」
- **可以改成**：「她并非纸上帝王——曾与先帝一道平定天下，又在乱世中旧躯受毒，至今未愈。」
- **原因**：「被毒伤旧躯」语法上有些拧，「旧躯」作为被毒伤的宾语不太自然。改成「旧躯受毒」主谓更顺，「至今未愈」能加强她"寿数有尽"的紧迫感。

### 3. 女帝之托 · 第 4 段

- **位置**：`prologueContent.ts` / 女帝之托 / 第 4 段
- **现在文案**：「你在北周搅动的是刀光剑影，她在南陈操盘的是一国兴衰。」
- **可以改成**：「你在北周搅动的是刀光剑影，她在南陈执掌的是一国兴衰。」
- **原因**：「操盘」来自现代金融语境，放在这段历史叙事里会轻微出戏。

### 4. 十年之诺 · 第 1 段

- **位置**：`prologueContent.ts` / 十年之诺 / 第 1 段
- **现在文案**：「落到这一局里，十年被拆成了一年两回合，共二十回合：每一回合，都是你替南陈争来的半岁光阴」
- **可以改成**：「落到这一局里，十年被拆作二十个回合——一回合，便是半岁光阴」
- **原因**：「一年两回合，共二十回合」读起来像游戏规则说明，打断了小说感。把数字信息融进一句更流畅的叙述里，同时避免与后文「每一回合，都是你替南陈争来的半岁光阴」语义重复。

### 5. 十年之诺 · 第 2 段

- **位置**：`prologueContent.ts` / 十年之诺 / 第 2 段
- **现在文案**：「使南陈在钱、粮、兵、民与号令上逐步追近北朝」
- **可以改成**：「使南陈在钱粮、兵马、民心与号令上逐步追近北朝」
- **原因**：「钱、粮、兵、民」四字并列太碎，且「民」单独一个字语义模糊（民心？民力？人口？）。合并为「钱粮、兵马、民心」三词，节奏更稳，也更符合古代政论语感。

## 二、玩法说明页

### 6. 你的目标 · intro

- **位置**：`prologueContent.ts` / 玩法说明 / 你的目标 / intro
- **现在文案**：「这一局并非只追一个数值。你要同时活下来、拖住北周、削弱其骨架，并让南陈真正变强。」
- **可以改成**：「这一局并非只追一个数值。你要活下来、拖住北周、拆它的骨架，再让南陈真正变强。」
- **原因**：「削弱其骨架」搭配略怪——「骨架」一般说「拆」或「断」，不说「削弱」。同时「同时」和后面的并列动词重复了节奏感，去掉更干脆。

### 7. 每回合流程 · intro ✅

- **位置**：`prologueContent.ts` / 玩法说明 / 每回合流程 / intro
- **现在文案**：「一回合并不长，但信息很多。最好按固定顺序看盘、下手、再验算。」
- **评价**：这段已经足够好。用「看盘、下手、验算」三个词概括回合流程，既有博弈感又简洁。

### 8. 计谋系统 · intro

- **位置**：`prologueContent.ts` / 玩法说明 / 计谋系统 / intro
- **现在文案**：「计谋不是直接扣国力的技能按钮，而是通过朝堂人物去拆结构。」

- **评价**：这段已经足够好。用「红线」这个概念很直观，玩家能立刻理解这是不能碰的底线。

### 10. 天道判官 · intro

- **位置**：`prologueContent.ts` / 玩法说明 / 天道判官 / intro
- **现在文案**：「天道判官不是随意发挥的说书人，而是规则结算之后的叙事汇总者。」

- **原因**：「叙事汇总者」把判官降格成了一个工具角色，和「天道判官」这个有威严感的命名不太匹配。改成「叙事汇总」保留功能说明，同时不削弱角色感。

### 11. 你的文字输入 · intro

- **位置**：`prologueContent.ts` / 玩法说明 / 你的文字输入 / intro

- **原因**：「装饰文字」语义重复——「装饰」本身已足够。删去「文字」更干净。

## 五、20 回合主线文案

> 整体评价：20 回合文案质量很高。北朝风云、南陈暗影、朝局简报、冯道之锦囊四个板块各有明确职责，信息不重复，节奏推进合理。冯道之密语尤其出色——每条都短、准、有洞察感。以下是少数值得推敲的地方：

### 19. 回合 2 · 朝局简报

- **位置**：`rounds.ts` / 回合 2 / briefing
- **现在文案**：「谁在控叙事，谁就在控下一步国家节奏。」
- **可以改成**：「谁掌握了叙事，谁就握住了下一步的国家节奏。」
- **原因**：「控叙事」中「控」+ 双音节名词的搭配偏现代媒体语境（"控制叙事"是近年政治传播术语）。改成「掌握叙事」或「主导叙事」更自然。

### 20. 回合 3 · 朝局简报

- **位置**：`rounds.ts` / 回合 3 / briefing
- **现在文案**：「灾年最见机器与秩序。」
- **可以改成**：「灾年最见国力与秩序。」或「灾年最见朝廷的机器与秩序。」
- **原因**：「机器」单独使用在现代语境里容易让人想到机械/计算机。这里想表达的应该是「国家机器」或「朝廷运转能力」。补全或替换为「国力」更清晰。

### 21. 回合 7 · 北朝风云

- **位置**：`rounds.ts` / 回合 7 / northDescription
- **现在文案**：「贺拔伯圭、独孤文约、祖廷、宇文棣、贺拔琪各有算盘。」
- **可以改成**：「贺拔伯圭、独孤文约、祖廷、宇文棣乃至太后贺拔琪，各有算盘。」
- **原因**：贺拔琪在前面几回合的文案中多以「太后」或「贺拔琪」出现，这里直呼其名且放在最后，读者可能一时反应不过来。加上「太后」头衔，层级感更清楚。

### 22. 回合 11 · 朝局简报

- **位置**：`rounds.ts` / 回合 11 / briefing
- **现在文案**：「真正可怕的，不是打仗，而是战争还没结束，所有人就已经在争战后怎么分。」
- **可以改成**：「真正可怕的，不是打仗，而是仗还没打完，所有人就已经在争战后怎么分。」
- **原因**：「战争还没结束」偏现代书面语，「仗还没打完」更口语化但也更有力，和「打仗」形成呼应。

### 23. 回合 14 · 冯道之密语

- **位置**：`rounds.ts` / 回合 14 / hint
- **现在文案**：「人人都在说名分，真正争的却是接口与节奏。」
- **可以改成**：「人人都在说名分，真正争的却是门路与先后。」
- **原因**：「接口」是技术/开发术语，出现在冯道之的密语里非常出戏。冯道之是南梁旧臣、国子监祭酒，说话应有士大夫的含蓄和精准。「门路与先后」既保留了原意（谁掌握信息通道、谁控制节奏），又符合人物身份。

### 24. 回合 19 · 冯道之密语

- **位置**：`rounds.ts` / 回合 19 / hint
- **现在文案**：「临终之国常最强作一时，也最怕刀子挥得太快太乱。」
- **可以改成**：「将亡之国常最强作一时，也最怕刀子挥得太快太乱。」
- **原因**：「临终」用于人而不用于国。「将亡之国」或「末世之国」更合古汉语习惯。

## 八、南陈问政题库

### 32. Q04 · 题面

- **位置**：`policyQuestions.ts` / Q04 / question
- **现在文案**：「北虏侵扰北周边境，敌人自顾不暇。此喘息期当如何利用？」
- **可以改成**：「北虏犯边，北周自顾不暇。此喘息之机当如何利用？」
- **原因**：「侵扰北周边境」略显冗长。「此喘息期」改为「此喘息之机」更古雅。

### 33. Q05 · 题面 ⚠️

- **位置**：`policyQuestions.ts` / Q05 / question
- **现在文案**：「西贼扰敌河西，正是我朝经营荆益方向之良机。」
- **可以改成**：「西虏扰边，河西不靖，正是我朝经营荆益之良机。」
- **原因**：「西贼扰敌河西」语法不通——「扰敌」后面应该接宾语，但「河西」是地名不是人。应改为「西虏扰边」或「西贼犯河西」。「荆益方向」中「方向」偏现代军事术语，去掉更干净。

### 34. Q13 · topic 与 background 不一致 ⚠️

- **位置**：`policyQuestions.ts` / Q13
- **现在文案**：topic =「灾疫治理」，background =「佛寺借赈济扩张，寺院经济开始侵蚀税基与人口控制。」
- **问题**：topic 叫「灾疫治理」，但 background 和 question 实际聚焦的是「寺院经济」问题。回合 13 的主线事件是「疫疠流行，谶言四起」，但问政题面完全没提疫病和谶言，只谈佛寺。
- **建议**：topic 改为「寺院经济」或「佛产清查」；或在 background 中补一句「疫疠之际，佛寺借赈济扩张势力」来建立和主线事件的关联。这是**信息架构问题**。

### 35. Q13 · aiScoringFocus
