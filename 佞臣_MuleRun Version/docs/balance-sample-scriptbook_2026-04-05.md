# 佞臣 Live Balance 样本库重写剧本手册（2026-04-05）

> 说明：这是一份给 live balance harness 使用的样本库重写草案，不是已经落进代码的最终版本。
> 
> 目标：
> 1. 每条线都提升 `计谋丰富度` 和 `NPC 选择丰富度`
> 2. 所有 `advise / omen` 样本都显式覆盖“利国”与“利人害国/利名分裂缝”两种方向
> 3. 让 `expert / average / rookie` 真正体现话术质量差异，而不只是走不同路线
> 4. 让后续用 DeepSeek 跑 live balance 时，更容易判断问题出在 `样本库 / parse rubric / 系统公式`

## 一、全局设计规则

### 1. 当前要覆盖的 9 条样本线
- `expert-mainline`
- `expert-omen`
- `expert-external`
- `average-mainline`
- `average-omen`
- `average-external`
- `rookie-mainline`
- `rookie-omen-misuse`
- `rookie-aggressive`

### 2. 全局丰富度要求
- 每条线 20 回合都重做
- 每条线至少覆盖 5 名以上 NPC
- 每条线至少覆盖 3 种以上计谋
- `mainline` 至少覆盖：`试探 / 献策 / 谗言 / 少量离间`
- `external` 至少覆盖：`试探 / 献策 / 少量离间 / 割据或造反链路铺垫`
- `omen` 至少覆盖：`谶纬 / 献策 / 试探`
- `rookie-aggressive` 保持高压，但不能只会一味 `离间`

### 3. `advise` 方向性覆盖规则
- `pro_state`：利国之策，测“玩家误帮北周”的情况
- `pro_target_anti_state`：利人害国之策，测“真正有效的佞臣式献策”
- `neutral_or_vague`：模糊建议，测弱影响

每条主线与外部线，前 10 回合至少要出现：
- 2 次 `pro_state advice`
- 2 次 `pro_target_anti_state advice`
- 1 次 `neutral_or_vague advice`

### 4. `omen` 方向性覆盖规则
- `legitimizing`：借灾异劝修德、安民、补法统
- `destabilizing`：借灾异放大天命/名分/法统裂口
- `vague_or_ceremonial`：空泛不祥感、礼仪化说辞

`expert-omen / average-omen / rookie-omen-misuse` 三条线必须都显式覆盖这三类。

### 5. 南陈线写法规则
- 这里不强绑具体 `A/B/C/D`，而写成 `偏治理 / 偏军粮 / 偏转运 / 偏整军 / 偏接管 / 偏民生` 的选项倾向
- 附言必须能看出：
  - `expert`：更完整地考虑接管、后勤、节奏、代价
  - `average`：知道方向，但不够极致精准
  - `rookie`：会保守、会空泛、会押错轻重

## 二、样本线 1：expert-mainline

**定位**：高手主线。能稳步撬动中枢、顺手卡前线调度，理想结果应更接近 `蜀地得手，淮南较有机会得手`。

**NPC 池**：祖廷、令狐律光、宗艾、宇文棣、独孤文约、贺拔琪

**计谋池**：试探、献策、谗言、离间、少量谶纬（仅在能用回合）
