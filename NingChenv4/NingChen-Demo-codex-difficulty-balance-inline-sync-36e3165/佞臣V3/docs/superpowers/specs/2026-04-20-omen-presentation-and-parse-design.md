# 谶纬表现层与解析链路增强设计

## 背景

当前版本中，谶纬已经具备专属输入结构、AI 解析字段和国力转化逻辑。玩家需要先输入“谶辞 / 征兆”，再输入“解释 / 指向”，系统会判断这段话是在稳固北周法统，还是在拆解北周名分。

但当前体验仍有三类问题：

1. 计谋回报页主要呈现“被施计对象的即时回应”，谶纬作为一种会在朝堂、宫禁、军中扩散的政治神秘主义手段，其“回响”没有被表现出来。
2. 谶纬仍走通用成功率公式，会吃目标 NPC 对主角的信任加成。这与谶纬的玩法语义不一致，因为玩家不是靠目标信任自己，而是在散布和解释一个可被朝堂利用的征兆。
3. 地方军头暂时不能作为谶纬对象。即使后续开放，当前 AI 解析字段也不足以稳定表达“中枢因谶纬怀疑地方军头，削减粮饷军资，导致军力小降、忠诚明显下降”的因果链。

本设计目标是把谶纬推进成更鲜明的特色玩法：成功率相对较高，使用机会有限，但最终效果取决于玩家是否真正写出一条能被朝堂利用的谶纬。

## 设计目标

1. 让谶纬回报不再只是单个 NPC 对话，而是同时呈现“目标即时反应”和“朝堂回响”。
2. 让谶纬成功率脱钩目标信任，改为高基础成功率加文本质量修正。
3. 增强 AI 解析链路，使其能判断谶纬是否明确指控某人或某势力，以及是否足以引发中枢制裁动作。
4. 开放地方军头谶纬的第一版轻量数值链路，让玩家理解军力、忠诚度变化的原因。
5. 保留数值裁判的稳定性：DeepSeek 负责解析和沉浸式文案，本地规则负责最终数值落地。

## 非目标

1. 不在本阶段全面重构地方军头的军力、忠诚度、信任度三数值体系。
2. 不让 DeepSeek 直接决定军力、忠诚度、国力的具体增减数值。
3. 不改变谶纬的两栏输入结构。
4. 不改变追问玩法的一次追问规则。
5. 不把所有灾异回合都无条件开放谶纬。开放回合仍应由配置明确控制。

## 开放规则

### 回合

当前谶纬只在 13、14、19、20 回合开放。建议扩展为：

1. 第 3 回合：河北、河南春旱，灾年可被解释为朝政失德或路线失当。
2. 第 8 回合：邺城与关中秋涝，仓廪清查可与天灾、粮政、法统解释相连。
3. 第 13 回合：疫疠与谶言四起，是谶纬核心回合。
4. 第 14 回合：归政暗斗，谶纬可被用于解释皇权与摄政名分。
5. 第 15 回合：流民滋生、地方控制力下降，适合用灾异牵动地方与中枢关系。
6. 第 19 回合：清洗与党争高压，谶纬可推高处置链和名分危机。
7. 第 20 回合：终局摊牌，谶纬可作为最后的名分震荡手段。

### 对象

谶纬对象分两类：

1. 朝堂角色：宗艾、贺拔琪、宇文棣、祖廷，以及后续配置中明确加入的朝堂角色。
2. 地方军头：仅在适合“中枢疑地方”的灾异、流民、边患、地方失控回合开放。

第 13 回合应把祖廷加入可选对象。剧情文本已经写明祖廷参与解释灾疫谶言，当前配置排除祖廷缺乏机制理由。

地方军头开放不是为了让谶纬直接“说服军头”，而是制造中枢对军头的猜疑。

## 成功率设计

### 当前问题

当前成功率走通用公式：

1. 读取难度基础成功率。
2. 按目标 NPC 信任度加成。
3. 应用计谋类型修正，其中谶纬有固定负修正。
4. 再叠加解析字段中的 characterFit、executability、eventFit、exposureRisk。

这导致谶纬会受到目标信任影响。对朝堂人物尚可勉强解释为“他愿不愿听”，但对谶纬的核心语义并不准确；对地方军头更不准确，因为真正起效的是朝堂如何解释和传播，而非军头是否信任主角。

### 新规则

新增谶纬专属成功率计算，脱离目标信任。

建议基础成功率：

1. 简单：0.82
2. 普通：0.74
3. 困难：0.68
4. 地狱：0.62

成功率修正主要来自：

1. `omenAnchorStrength`：征兆是否像一个真实可传播的锚点。
2. `legitimacyCrack`：解释是否引向名分、法统、天命裂缝。
3. `suspicionDirection`：是否把怀疑导向某人、某关系线或某权力结构。
4. `eventFit`：是否贴合本回合灾异、流民、边患、归政、清洗等时局。
5. `exposureRisk`：是否过于露骨，导致反噬或被识破。

地方军头谶纬还额外看：

1. `omenAccusationClarity`：是否明确把征兆指向某个地方军头的异心。
2. `centralSanctionLeverage`：是否足以让中枢借题发挥，采取削粮饷、缓发军资、派监军、查账册等动作。

成功率高不等于一定利好玩家。若 AI 判断为 `legitimizing`，成功后仍可能稳固北周法统；若为 `vague_or_ceremonial`，成功后也可能只有很弱的风声。

## AI 解析链路

### 保留字段

当前已有谶纬字段继续保留：

1. `legitimacyDirection`：对北周名分、法统、天命叙事的净方向。
2. `omenPolarity`：`legitimizing | destabilizing | vague_or_ceremonial`。
3. `omenAnchorStrength`：征兆锚点强度。
4. `legitimacyCrack`：是否把征兆引向名分裂缝。
5. `suspicionDirection`：是否把怀疑导向某人、某关系线或某结构。

这些字段足以支撑朝堂谶纬的国家层影响和处置链推进。

### 新增字段

新增两个谶纬专属字段：

1. `omenAccusationClarity`
   - 范围：0 到 1。
   - 含义：这段谶纬是否明确把灾异、征兆、谶辞指向某个具体人物、地方军头、派系或权力集团的异心。
   - 低分：只是说“不祥”“天意不佳”。
   - 高分：明确暗指“某外镇拥兵自重”“某宗室图谋飞升成龙”“某中枢越分干政”。

2. `centralSanctionLeverage`
   - 范围：0 到 1。
   - 含义：这段谶纬是否足以让朝堂中枢采取实际制裁、约束或审查动作。
   - 低分：只有流言，没有动作抓手。
   - 中分：能引发怀疑，但没有明确制裁方式。
   - 高分：明确导向削粮饷、缓发兵器甲胄、查军需账册、派监军、收调兵符、限制互市或切断补给。

### Prompt 增补

`buildNorthSchemeParsePrompt` 需要在谶纬分支中加入：

1. 对朝堂目标：判断谶纬如何影响名分、法统、皇帝恩宠、太后眷顾、朝堂派系解释权。
2. 对地方军头：判断谶纬是否会让中枢怀疑其异心，并是否会造成削供给、查军需、派监军等后续动作。
3. 提供目标类型：`powerBase` 是 `court` 还是 `external`。
4. 若目标是地方军头，提供 `militaryPower`、`loyaltyToCourt`、`trust`、`alignmentBias`、`externalStatus`。

输出 JSON 增加：

```json
{
  "omenAccusationClarity": 0,
  "centralSanctionLeverage": 0
}
```

### Fallback 增补

本地 fallback 需要补地方军头谶纬关键词：

1. 指控对象词：`外镇`、`边镇`、`节度`、`军头`、`拥兵`、`坐大`、`异心`、`叛心`、`不臣`、`割据`。
2. 中枢动作词：`削饷`、`停饷`、`缓发粮草`、`军资`、`兵器`、`甲胄`、`监军`、`查账`、`清查军需`、`收兵符`。

Fallback 也要输出 `omenAccusationClarity` 与 `centralSanctionLeverage`。

### AI / Fallback 合并

当前逻辑只有在 AI 五维相关度全为 0 时，才用 fallback 补五维。新增逻辑应包括谶纬专属兜底：

1. 若 AI 输出的 `omenAnchorStrength`、`legitimacyCrack`、`suspicionDirection`、`omenAccusationClarity`、`centralSanctionLeverage` 近乎全 0。
2. 且 fallback 明显识别到了征兆锚点、名分裂缝、怀疑导向或中枢制裁抓手。
3. 则使用 fallback 补齐这些谶纬字段。

这样 DeepSeek 偶尔漏判时，谶纬不会变成完全无效的空字段。

## 计谋回报页表现

### 双层回报

谶纬回报卡显示两层：

1. 目标 NPC 即时反应。
2. 谶纬回响。

目标 NPC 即时反应仍然对应玩家选择的施计对象。它回答“这个人听到谶纬后如何反应”。

谶纬回响则回答“这段谶纬如何被朝堂中其他人解释、利用、放大，或者压下去”。

### 目标 NPC 即时反应 Prompt

谶纬应有专属 NPC 回应指导，而不是完全沿用普通计谋回应。

Prompt 要求：

1. 回应必须体现人物性格，而不是只说“我知道了”。
2. 要体现角色面对谶纬时的具体心理动作：信、疑、惧、怒、借题发挥、急于撇清、压住流言。
3. 不能让所有人都用问句收束。
4. 对地方军头，重点表现其对中枢猜疑的敏感，而不是让他像朝臣一样讨论法统。

示例方向：

1. 宗艾：惶恐，极力解释，试图把自己缩回皇帝名分之后。
2. 宇文棣：暴怒，认为有人借天象构陷宗室。
3. 祖廷：冷静拆解，把谶辞转成可操作的制度材料。
4. 贺拔琪：压住情绪，先问谁在传、谁要夺解释权。
5. 地方军头：表面不认，实则警觉朝廷是否要削粮饷、派监军。

### 谶纬回响 Speaker 选择

谶纬回响使用 DeepSeek 生成，以一位朝堂 NPC 的口吻发声。

选择规则不是纯随机，而是打分选择：

1. 只从活着、未被罢黜、未被处决的朝堂 NPC 中选择。
2. 如果谶纬目标是地方军头，speaker 必须来自朝堂势力。
3. 优先选择与目标存在派系冲突、利益冲突、上下游权力关系的人。
4. 优先选择本回合公开表态与谶纬主题相关的人。
5. 优先选择能顺着谶纬采取动作的人。
6. 同分时使用回合数、计谋序号、目标 id 做稳定伪随机，避免读档后变化。

地方军头谶纬的 speaker 候选倾向：

1. 贺拔琪：要求压住粮饷、调兵权限或地方节制。
2. 祖廷：主张查军需、查账册、重整粮道。
3. 令狐律光：主张缓发兵器甲胄，防止边镇坐大。
4. 宗艾：以内廷名义传达皇帝疑心。
5. 宇文棣：若可借题攻击外镇或后党安排，则上奏压制。

### 谶纬回响 Prompt

DeepSeek 生成的回响应满足：

1. 以选中 speaker 的口吻写。
2. 结合玩家谶辞、解释文本、目标人物、目标与 speaker 的关系、speaker 自身利益、本回合时局。
3. 不直接罗列数值。
4. 若目标是地方军头，必须写出中枢怀疑后的具体动作倾向，例如削粮饷、缓发兵器甲胄、查账、派监军。
5. 若谶纬质量不足，则回响应显示为“风声止于怪谈，未能入朝议”，而不是强行制造效果。

## 地方军头数值链路

### 设计语义

地方军头谶纬不是直接让地方军头相信天命，而是让朝堂中枢怀疑他有异心。

玩家通过谶纬牺牲一小部分地方军头军力，换取更显著的忠诚度下降，从而更容易在后续触发煽动割据或煽动造反。

链路如下：

1. 玩家输入灾异 / 征兆。
2. 玩家解释此征兆暗指某地方军头异心。
3. AI 判断是否有清晰指控与中枢制裁抓手。
4. 谶纬回响选择一位朝堂 speaker。
5. Speaker 表达怀疑，并暗示或提出削粮饷、缓发军资、派监军等动作。
6. 本地规则小幅降低该地方军头 `militaryPower`。
7. 本地规则更显著降低该地方军头 `loyaltyToCourt`。
8. 后续割据 / 造反门槛更容易被满足。

### 数值方向

初版建议：

1. `militaryPower`：小幅下降，约 -1 到 -3。
2. `loyaltyToCourt`：明显下降，约 -6 到 -12。
3. 失败或泛泛玄学：不触发军力下降，可能只有信任损失与反噬风险。

军力下降由以下字段决定：

1. `centralSanctionLeverage`
2. `militaryRelevance`
3. `grainRelevance`
4. `governanceRelevance`

忠诚下降由以下字段决定：

1. `omenAccusationClarity`
2. `centralSanctionLeverage`
3. `suspicionDirection`
4. `eventFit`

军力下降不能过大。地方军头线的收益应主要来自忠诚下降，而不是提前把军头打废。

## 朝堂谶纬数值链路

朝堂谶纬保留当前核心方向：

1. `legitimizing`：可能提升北周 `socialOrder` 和 `governance`。
2. `vague_or_ceremonial`：轻微扰动，影响有限。
3. `destabilizing`：打击北周 `socialOrder` 和 `governance`，高质量时推进皇帝恩宠 / 太后眷顾下降。

新增字段也可辅助朝堂谶纬：

1. `omenAccusationClarity` 高时，更容易影响具体人物的皇帝恩宠 / 太后眷顾。
2. `centralSanctionLeverage` 高时，更容易解释为朝堂动作，而不只是民间流言。

## 记忆与后续影响

谶纬造成的关键结果应进入现有记忆系统：

1. 目标 NPC 长期记忆：记住玩家曾借谶纬影射自己或自己所在权力线。
2. NPC-NPC 关系记忆：若谶纬明确挑拨 A 对 B 的怀疑，应沉淀为关系旧账。
3. 地方军头线：若中枢因谶纬削减某军头供给，该军头后续应记得“朝廷因谶言疑我、卡我粮饷军资”。

本阶段不新增完整记忆系统，只要求把谶纬结果接入已有记忆记录入口。

## UI 呈现

### 计谋回报页

谶纬卡片中新增“谶纬回响”模块，位置在目标 NPC 即时反应下方、追问模块上方。

建议结构：

1. 原有 NPC 回应正文。
2. 新增小标题：`谶纬回响`。
3. 显示 speaker 姓名与一句身份标签。
4. 显示 DeepSeek 生成的回响文本。

地方军头谶纬回响中，应自然体现“中枢削供给”动作，使玩家能理解后续军力与忠诚度变化。

### 结算页

计谋筹算结果中，地方军头谶纬的结果文案应明确写出：

1. 该军头军力小降的原因是粮饷、兵器、甲胄、补员等供给被削。
2. 忠诚度明显下降的原因是他意识到中枢已经疑他、防他。

避免只写“军力 -2、忠诚 -10”这种裸数值变化。

## 测试要求

### 单元测试

1. 谶纬成功率不受信任值影响。
2. 谶纬成功率仍受谶纬质量、时局贴合、暴露风险影响。
3. AI parse normalization 支持 `omenAccusationClarity` 与 `centralSanctionLeverage`。
4. Fallback 能识别地方军头指控词与中枢制裁词。
5. AI 解析漏掉谶纬专属字段时，fallback 能补齐。
6. 地方军头谶纬成功时，`militaryPower` 小降、`loyaltyToCourt` 更明显下降。
7. 泛泛谶纬不会触发地方军头供给削减。
8. 第 3、8、13、14、15、19、20 回合开放规则符合预期。
9. 第 13 回合祖廷可被选择为谶纬对象。
10. 地方军头终局状态为割据 / 叛乱 / 已死亡时，不应作为谶纬对象。

### 组件测试

1. 谶纬回报卡渲染“谶纬回响”模块。
2. 非谶纬计谋不渲染“谶纬回响”模块。
3. 地方军头谶纬回响显示朝堂 speaker，而不是地方军头自己。
4. 回响生成失败时显示稳定 fallback 文案，不阻塞计谋回报页继续。

### 回归测试

1. `npm test`
2. `npm run build`

## 风险与缓解

### 风险：新增 DeepSeek 调用导致计谋回报页变慢

缓解：

1. 只对谶纬计谋调用回响生成。
2. 回响可以与目标 NPC 即时反应并行生成。
3. 生成失败时使用本地 fallback，不让页面卡死。

### 风险：谶纬成功率过高导致数值过强

缓解：

1. 成功率高只代表谶纬传播成功，不代表必然利好玩家。
2. 通过 `omenPolarity` 控制正反效果。
3. 地方军头谶纬的军力下降保持小幅，收益主要体现在忠诚下降。
4. 高质量地方军头谶纬仍需 `omenAccusationClarity` 与 `centralSanctionLeverage` 达标。

### 风险：AI 回响文案与本地数值不一致

缓解：

1. AI 回响 prompt 只允许依据本地解析结果与目标信息生成文案。
2. 本地规则先确定效果类型，再把效果摘要喂给回响 prompt。
3. fallback 文案从同一套本地效果类型生成。

## 实施边界

本 spec 适合拆为一个 implementation plan：

1. 类型与解析字段扩展。
2. 谶纬成功率专属公式。
3. 开放回合与目标规则更新。
4. 地方军头谶纬数值链路。
5. 谶纬回响 speaker 选择与 prompt。
6. 计谋回报页 UI 呈现。
7. 测试与文档更新。

不在本 plan 中处理完整地方军头数值体系重构。该项应另开 spec。
