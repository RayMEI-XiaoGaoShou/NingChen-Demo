# 《佞臣》朝臣恩宠轴与人事处置链重构设计

日期：2026-04-19  
范围：北周朝堂角色的 `谗言 / 离间 / 设局嫁祸 / 谶纬 / 借刀` 处置链重构  
状态：设计稿

## 1. 背景

当前《佞臣》北周线已经有一条较完整的权谋递进链：

- `试探`：摸口风、探暗线、找心结
- `献策`：建立信任，并在特定语义下制造“利人害国”
- `谗言`：对某个具体人物种下不满与怀疑
- `离间`：把裂缝从情绪层推向权力合作层
- `设局嫁祸 / 谶纬`：制造嫌疑、名分裂缝与公共正当性压力
- `借刀`：收网

但当前“借刀处置链”的底层逻辑仍然偏抽象：

- 被处置对象由固定名单与 `disposalStage` 决定
- 谁能当“刀”，取决于 `trust + canExecute / militaryPower`
- 这导致令狐律光、尉迟暮、宇文棣等朝臣，都可能在机制上充当正式处置他人的执行者

这套逻辑虽然在游戏系统层能跑通，但不够贴近北周朝廷现实，也不够符合玩家对“谁有资格动手处置朝臣”的直觉。

用户提出的新方向更接近真实朝廷逻辑：

- 朝臣不是因为“被推进了一个抽象阶段”而死
- 朝臣是因为同时失去皇帝与太后两边的庇护，才有可能被正式罢黜或处决
- 真正有资格完成收网的，只能是掌握帘前实权的太后贺拔琪，或能代表御前意志的宗艾

本设计即基于这一方向，重做北周朝臣的人事处置链。

## 2. 设计目标

本轮重构要解决四件事：

1. 让“朝臣为何会被罢黜或处决”更符合历史语境与玩家直觉。
2. 让 `谗言 / 离间 / 设局嫁祸 / 谶纬 / 借刀` 的递进关系更清晰。
3. 让“罢黜”和“处决”成为两个不同层级的结果，并对北周综合国力造成不同伤害。
4. 保留现有系统中可复用的部分：第二目标机制、关系边冲击、五维国力伤害、派系向量与回合反馈。

玩家体验目标：

- 玩家会理解：自己不是在“把某人推进抽象处决条”，而是在系统性地削弱其御前与帘前庇护。
- 玩家会理解：`借刀` 不是谁都能借，而是只能借真正握有人事裁断权的人。
- 玩家会理解：`谗言 / 离间` 的价值，是帮助某名朝臣失去某一边的信任；`设局嫁祸 / 谶纬` 的价值，是让其两边同时失分。

## 3. 方案对比

### 方案 A：仅限制借刀执行者

做法：

- 保留当前 `disposalStage`
- 只把 `借刀` 的执行者限制为 `贺拔琪 / 宗艾`

优点：

- 改动小
- 能快速修复“谁都能杀人”的不合理感

缺点：

- 核心问题没解决：朝臣为何进入“可处置状态”仍然太抽象
- 玩家依然难理解“谗言 / 离间 / 谶纬 / 设局嫁祸”究竟在给谁施加什么政治后果

不推荐作为最终方案。

### 方案 B：新增双态度轴，借刀只用于收网

做法：

- 给可被处置的朝臣新增两条数值轴：`皇帝恩宠`、`太后眷顾`
- `谗言 / 离间` 按听话者阵营打击单边态度
- `设局嫁祸 / 谶纬` 可在特定条件下同时打击双边态度
- `借刀` 不再推进抽象阶段，而是检测是否达到“可罢黜 / 可处决”的双阈值
- `贺拔琪 / 宗艾` 是唯一的正式收网入口

优点：

- 最符合历史语境与玩家直觉
- 最容易解释“为什么这一手有效”
- 便于后续把 NPC 记忆、关系记忆、冯道之代拟都接到同一套规则上

缺点：

- 需要新增角色状态、终态、伤害表与 UI 表达

推荐采用。

### 方案 C：直接用帝党/后党 faction 数值替代个人态度

做法：

- 不给角色加新轴
- 直接用 `emperor / empress` faction 的势头变化推导个体是否失势

优点：

- 最省字段

缺点：

- faction 是派系宏观势头，不是具体某个朝臣的御前或帘前处境
- 会把“宇文棣失势”和“帝党整体失势”混成一件事
- 很难解释“为什么这次只针对尉迟暮，不是整个帝党一起遭殃”

不推荐。

## 4. 推荐方案

采用 **方案 B：双态度轴 + 单一收网入口**。

该方案的核心是：

- 把“处置朝臣”改写为“先削其御前恩宠与帘前眷顾，再由御前或帘前正式收网”
- 把 `借刀` 从“人人都能用的抽象执行技”改成“只能借真正掌权者之手完成的人事裁断”

## 5. 核心机制定义

### 5.1 前台名称

- `皇帝恩宠`
- `太后眷顾`

### 5.2 建议内部字段

为避免和 faction 向量混淆，内部字段建议使用：

- `emperorFavor`
- `empressDowagerFavor`

前台始终显示为：

- 皇帝恩宠
- 太后眷顾

### 5.3 适用对象

本机制首版仅对以下 4 名北周朝堂角色生效：

- 祖珽
- 宇文棣
- 令狐律光
- 尉迟暮

说明：

- 贺拔琪、宗艾是执行入口，不作为本机制的被收网对象。
- 地方军头不适用本机制，仍走外部势力线。

## 6. 初始值与阈值

### 6.1 初始值原则

- 后党角色：开局 `太后眷顾` 高，`皇帝恩宠` 低
- 帝党角色：开局 `皇帝恩宠` 高，`太后眷顾` 低
- 若角色人设有明显摇摆、但 `factionId` 已确定，则首版仍以 `factionId` 决定初始高低与单边打击落点

### 6.2 首版初始值

| 角色 | factionId | 皇帝恩宠 | 太后眷顾 | 说明 |
| --- | --- | ---: | ---: | --- |
| 祖珽 | empress | 26 | 82 | 太后政务中枢，御前观感本就不高 |
| 令狐律光 | empress | 40 | 74 | 虽偏后党，但不是纯私党，故不做极端差值 |
| 宇文棣 | emperor | 78 | 22 | 宗室帝党核心，天然为太后所忌 |
| 尉迟暮 | emperor | 72 | 28 | 帝党军头，御前器重高于帘前信任 |

### 6.3 双阈值

首版建议复用项目里已存在的危险阈值感知，统一为：

- 阈值 A：`35`
- 阈值 B：`18`

语义如下：

- 当某角色 `皇帝恩宠 <= 35` 且 `太后眷顾 <= 35` 时：进入 `可罢黜`
- 当某角色 `皇帝恩宠 <= 18` 且 `太后眷顾 <= 18` 时：进入 `可处决`

这样做的好处是：

- 与现有外部线 `35 / 18` 的危险阶梯一致
- 玩家更容易理解“先失势，再到死局”

## 7. 新的朝臣终态

当前朝堂角色只有“活着 / 死了”，不足以表达“被撤职但未死”。

因此需要新增朝臣终态字段。

### 7.1 建议字段

建议新增：

- `courtStatus: 'active' | 'dismissed' | 'executed'`

语义：

- `active`：仍在位、仍可互动
- `dismissed`：已被罢黜，仍存活，但退出可互动朝堂
- `executed`：已被正式处决

### 7.2 与现有字段关系

- `dismissed`：`isAlive = true`
- `executed`：`isAlive = false`
- `deathCause` 可为 `court_execution`

### 7.3 玩家可见状态

前台建议统一为：

- `可罢黜`
- `可处决`
- `已被罢黜`
- `已被处决`

## 8. 收网权力的重新定义

### 8.1 唯一可借刀对象

朝堂角色中，只有：

- 贺拔琪
- 宗艾

可以作为 `借刀` 的施计对象。

语义：

- 对贺拔琪用 `借刀`：借帘前权力收网
- 对宗艾用 `借刀`：借御前诏意收网

### 8.2 不再允许的旧逻辑

以下角色不再承担“正式处置朝臣”的执行权：

- 祖珽
- 宇文棣
- 令狐律光
- 尉迟暮

他们仍可作为：

- `谗言 / 离间` 的听话者
- `设局嫁祸 / 谶纬` 的施计对象
- 关系链与派系链上的关键节点

但不再能成为“正式把另一个朝臣下狱或处决”的刀。

## 9. 各计谋在新模型中的作用

### 9.1 谗言

定义：

> 对 A 说 B 的坏话，先让 A 对 B 生疑、生厌、生防。

新机制下的作用：

- 保留现有关系边冲击
- 额外对 **B 的单边庇护值** 造成伤害

落点规则：

- 若 A 的 `factionId = emperor`，则降低 B 的 `皇帝恩宠`
- 若 A 的 `factionId = empress`，则降低 B 的 `太后眷顾`

建议幅度：

- 成功时：单边 `-8`
- 极高传导时可放大到 `-10`

首版不直接打双边。

### 9.2 离间

定义：

> 借 A 之疑，主动把 A 与 B 的合作裂缝撕开。

新机制下的作用：

- 保留现有关系边冲击
- 额外对 **B 的单边庇护值** 造成更强伤害

落点规则同谗言：

- A 属帝党入口，则打 B 的 `皇帝恩宠`
- A 属后党入口，则打 B 的 `太后眷顾`

建议幅度：

- 成功时：单边 `-12`
- 极高裂解传导时可放大到 `-14`

### 9.3 设局嫁祸

定义：

> 诱使目标自己失言、失态或落入嫌疑，令其同时在御前与帘前都变得难以辩白。

新机制下的作用：

- 不依赖第二目标
- 保留其“让目标自己背嫌疑”的核心语义
- 可同时打击目标的双边庇护值
- 直接国力伤害仅应为轻到中档，重点是更快把目标推进到 `可罢黜 / 可处决` 区间

建议幅度：

- 成功时：`皇帝恩宠 -7`、`太后眷顾 -7`
- 高质量成功时可到 `-8 / -8`

设计说明：

- `设局嫁祸` 的强项是“做实案、做口实、做责任归属”，因此它对单个目标的双边失分应强于 `谶纬`
- 它更像“做掉一个人”，不应在未收网前就对北周综合国力造成过大的直接损伤

### 9.4 谶纬

定义：

> 借灾异、征兆、名分裂缝去重写朝堂对某人的正当性判断。

新机制下的作用：

- 仍不要求第二目标
- 不再被视为直接推进抽象处置阶段
- 改为对目标形成“御前、帘前都觉得此人在名分上不稳”的公共损伤
- 合理命中时，除双边失分外，还应对北周综合国力造成比 `设局嫁祸` 更显著的直接冲击

建议幅度：

- 仅在 `omenPolarity = destabilizing` 且 `legitimacyCrack` 足够高时生效
- 成功时：`皇帝恩宠 -5`、`太后眷顾 -6`
- 高质量命中可到 `-6 / -7`

设计说明：

- `谶纬` 的强项不是“做实罪”，而是“制造名分裂缝、灾异解释与政治气候”
- 因此它对双边恩宠/眷顾的压低应弱于 `设局嫁祸`
- 但它对北周五维的直接影响应高于 `设局嫁祸`，优先打击 `统治穿透力 / 民生秩序`
- 在战役、灾异、归政、名分敏感回合，可额外波及 `军事 / 粮务 / 财政`

### 9.5 借刀

定义：

> 借真正掌权者之手，把已失去双边庇护的朝臣正式收网。

新机制下的作用：

- 不再推进旧 `disposalStage`
- 不再制造“轻度 / 重度 / 极成”的抽象阶段
- 改为直接检查目标是否已满足 `可罢黜 / 可处决`

结算规则：

- 对贺拔琪或宗艾施计 `借刀`
- 第二目标必须是 4 名可收网朝臣之一
- 若第二目标达到 `双边 <= 35`，则本次借刀可触发 `罢黜`
- 若第二目标达到 `双边 <= 18`，则本次借刀可触发 `处决`
- 若未达到双阈值，则借刀失败或仅形成口头压制，不改变终态

## 10. “听谁说”决定打哪一边

这是本设计的核心规则之一。

### 10.1 规则

当玩家执行 `谗言 / 离间` 时，单边态度的受损方向由 **听话者的 `factionId`** 决定，而不是由被说坏话的人决定。

即：

- 对帝党角色 A 谗言 / 离间 B：打 B 的 `皇帝恩宠`
- 对后党角色 A 谗言 / 离间 B：打 B 的 `太后眷顾`

### 10.2 首版取舍

首版不再额外引入“摇摆派单独判定规则”，统一使用：

- `听话者 factionId 决定落点`

这样做的好处：

- 规则稳定
- 玩家容易学
- UI 容易解释
- 测试组合爆炸更可控

## 11. 4 名目标角色的国力伤害表

本设计要求：

- `罢黜` 与 `处决` 的伤害分开预设
- `处决` 对北周综合国力的伤害显著高于 `罢黜`
- 军事统帅的军事伤害高于文臣

### 11.1 祖珽

#### 罢黜

- 财政 `-2.0`
- 粮务 `-1.4`
- 军事 `-0.4`
- 民生秩序 `-0.9`
- 统治穿透力 `-2.5`

#### 处决

- 财政 `-3.1`
- 粮务 `-2.1`
- 军事 `-0.7`
- 民生秩序 `-1.5`
- 统治穿透力 `-4.2`

### 11.2 宇文棣

#### 罢黜

- 财政 `-0.6`
- 粮务 `-0.8`
- 军事 `-1.8`
- 民生秩序 `-1.0`
- 统治穿透力 `-1.2`

#### 处决

- 财政 `-1.0`
- 粮务 `-1.2`
- 军事 `-3.1`
- 民生秩序 `-1.8`
- 统治穿透力 `-1.8`

### 11.3 令狐律光

#### 罢黜

- 财政 `-0.8`
- 粮务 `-1.0`
- 军事 `-2.6`
- 民生秩序 `-1.0`
- 统治穿透力 `-1.2`

#### 处决

- 财政 `-1.2`
- 粮务 `-1.5`
- 军事 `-4.2`
- 民生秩序 `-1.8`
- 统治穿透力 `-2.1`

### 11.4 尉迟暮

#### 罢黜

- 财政 `-0.7`
- 粮务 `-0.9`
- 军事 `-2.8`
- 民生秩序 `-1.2`
- 统治穿透力 `-1.0`

#### 处决

- 财政 `-1.0`
- 粮务 `-1.4`
- 军事 `-4.4`
- 民生秩序 `-2.0`
- 统治穿透力 `-1.8`

### 11.5 设计说明

- 尉迟暮、令狐律光属于军政统帅，军事损伤应明显高于祖珽、宇文棣。
- 祖珽作为中枢行政枢纽，被拿掉后治理与财政后果更重。
- 宇文棣偏政治与主战名分，处决对朝局与战意的打击大于对财政粮储的打击。
- `罢黜` 的综合国力伤害目标区间应在约 `-1.1 ~ -1.4`
- `处决` 的综合国力伤害目标区间应在约 `-1.9 ~ -2.3`
- 军事统帅被处决时，其即时冲击应接近或略高于“一场单次战役失利”的即时损伤体感

### 11.6 派系连带损伤

除直接国力伤害外，关键朝臣被 `罢黜 / 处决` 时，还应同步施加与其角色性质相匹配的 `factionPenalty`：

- 祖珽：优先打击后党的 `courtInfluence / internalStability`
- 宇文棣：优先打击帝党的 `courtInfluence / internalStability`，并轻伤主战军心
- 令狐律光：优先打击后党的 `militaryPower / courtInfluence`
- 尉迟暮：优先打击帝党的 `militaryPower / courtInfluence`

实现时，`处决` 对派系的连带打击也必须显著高于 `罢黜`。

## 12. 与现有系统的关系

### 12.1 保留的部分

以下现有系统应保留：

- `谗言 / 离间` 的第二目标结构
- 关系边冲击与结构崩塌
- 五维综合国力伤害
- faction 向量变化
- 施计反馈、暗线、NPC 记忆、冯道之代拟

### 12.2 被替换的部分

以下旧机制应被视为待退场：

- `disposalStage`
- `BORROWED_BLADE_TARGET_IDS`
- “已被盯上 / 已被孤立 / 已成可处置目标”这一套旧借刀链提示
- “谁 trust 高、谁 canExecute，就能当正式处置执行者”的逻辑

### 12.3 推荐保留但改语义的部分

当前 `borrowedBladeReports` 可保留数据出口，但语义要改为：

- 本回合是否发生了 `御前收网 / 帘前收网`
- 收网结果是 `罢黜` 还是 `处决`

## 13. UI 与教学影响

### 13.1 施计页

- `借刀` 只在选中 `贺拔琪 / 宗艾` 时显示为可用
- 对其他朝堂角色：
  - 要么隐藏 `借刀`
  - 要么显示 `未解锁` 并提示“借刀只能借太后或御前之手”

推荐首版做法：

- 对其他角色显示 `未解锁`
- hover 说明机制

### 13.2 角色卡

4 名可处置朝臣需展示：

- 皇帝恩宠
- 太后眷顾

可选表达方式：

- 双条形刻度
- 双 chip 数值
- 达到阈值时出现 `可罢黜 / 可处决` 标识

### 13.3 终态卡

被罢黜或被处决后：

- 退出可施计名单
- 不再有朝堂公开表态
- 朝堂页保留终态卡
- 终态卡覆盖层分别显示：
  - `已被罢黜`
  - `已被处决`

### 13.4 锦囊与简报

冯道之锦囊不再使用旧借刀链表述：

- 删除“已被盯上 / 已被孤立 / 已成可处置目标”
- 改为：
  - “某人御前失势已深”
  - “某人帘前眷顾将尽”
  - “某人已近双失其主，可图罢黜”
  - “某人两边庇护俱裂，可图重手”

## 14. 对 NPC prompt 与记忆系统的意义

本设计完成后，NPC 和冯道之的 prompt 将更容易变得“有政治语言感”，因为它们终于有了明确可引用的状态：

- 某人近来御前恩宠下滑
- 某人仍受太后庇护
- 某人已是两边都不愿保的人

这比当前的抽象 `disposalStage` 更适合：

- NPC 对玩家的追问与反馈
- 冯道之代拟对“这手该继续挑哪边”的建议
- 后续要做的“关系记忆第二支线”

## 15. 实现边界与迁移建议

### 15.1 首版实现边界

首版只做：

- 4 名朝臣的双态度轴
- 2 名正式执行入口
- 罢黜 / 处决双终态
- 4 张固定 penalty 表
- UI 与提示链改口径

暂不做：

- 贺拔琪、宗艾自己被收网
- 所有朝堂角色普遍拥有双态度轴
- 更复杂的“因 faction collapse 自动拖低恩宠 / 眷顾”
- 更细的随机事件反噬联动

### 15.2 迁移顺序

推荐顺序：

1. 数据层新增双态度轴与 `courtStatus`
2. 借刀执行权收缩到 `贺拔琪 / 宗艾`
3. `谗言 / 离间 / 设局嫁祸 / 谶纬` 改为作用于双态度轴
4. 用双阈值替换旧 `disposalStage`
5. 接入 4 张国力伤害表
6. 改前端显示、锦囊提示、结算文案
7. 最后处理旧测试与样本脚本

## 16. 验收标准

当该设计落地后，至少应满足以下结果：

1. 玩家不能再借令狐律光、尉迟暮、宇文棣、祖珽之手正式处置别的朝臣。
2. 玩家能明确看懂：某人当前是“皇帝恩宠低”“太后眷顾低”还是“两边都低”。
3. `谗言 / 离间` 的效果可以清楚解释为“伤某一边的庇护”。
4. `设局嫁祸 / 谶纬` 的效果可以清楚解释为“双边失分，但强度弱于单边撕裂”。
5. `借刀` 的结果只有三种：
   - 条件不足，未能收网
   - 达到 A 阈值，罢黜
   - 达到 B 阈值，处决
6. 四名朝臣被罢黜/处决后，对北周五维国力造成预设差异化伤害。
7. 冯道之锦囊、朝堂页、施计页、结算页，不再出现旧 `disposalStage` 口径。

## 17. 非目标

本设计暂不处理：

- 外部军头线重做
- 朝臣互相处置的另一套非常规宫变事件
- faction collapse 与个人恩宠/眷顾的自动映射细化
- 第二层长期记忆筛选优化
- AI 样本路线的重新校准
- 谶纬计谋回报页的“双层表现”重构（目标 NPC 即时反应 + 朝议回响）

这些均属于本设计落地后的后续工作。
