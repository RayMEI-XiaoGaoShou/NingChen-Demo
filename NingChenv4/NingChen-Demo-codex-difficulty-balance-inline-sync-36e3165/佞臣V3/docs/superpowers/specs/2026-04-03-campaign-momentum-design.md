# 战役筹备势能设计稿

日期：2026-04-03

## 背景

当前 `normal` 难度下，真实 DeepSeek live 样本已经出现了比较合理的 `expert / average / rookie` 梯度：

- `expert-mainline` 可赢
- `average-mainline` 窄胜
- `rookie-mainline` 失败
- `rookie-aggressive` 明显失败

但同时出现了另一个不理想的结果：若干最终胜利样本在第 10 回合和第 16 回合的战役结算上，仍然同时落入 `蜀地 failed / 淮南 failed`。这会造成体验上的割裂：

- 玩家感觉自己“大局已经赢了”
- 但地图与战役反馈没有给出“权谋影响前线”的回应

这与《佞臣》希望呈现的“朝堂布局 -> 前线形势变化”不完全一致。

## 现状问题

### 1. 战役结算与终盘胜负错位

蜀地在第 10 回合结算，淮南在第 16 回合结算，而终盘胜负在第 20 回合结算。当前样本里，许多胜利样本在第 10 回合仍明显落后，因此终盘翻盘并不能自然转化为早期战役得手。

### 2. 战役吃到的动态输入过窄

当前战役公式只直接吃两类动态输入：

- `policyBoost`
- `northPressurePenalty`

其中：

- `policyBoost` 主要来自南陈问政效果总和
- `northPressurePenalty` 主要来自外部军头状态、两党稳定、边镇低信任

这意味着很多“主线权谋成功”的成果，并不会直接传导到战役结算里。

### 3. 当前普通档战役阈值偏严

当前 `normal` 配置里，战役公式带有较强的负偏置和较高的得手门槛。它确实压住了“战役白送”，但也把“成功主线 -> 战役得手”这条链压得过窄。

## 设计目标

本次设计目标不是让战役重新变成默认白送，而是让以下体验成立：

1. 玩家若持续做出与战役相关的高质量朝堂布局，前线应当逐步积累“得手势能”。
2. 普通主线胜利不一定双战全收，但至少应更容易出现“单战得手 / 双战一得一持 / 双持”而不是稳定双失败。
3. 谶纬、军政、粮道、调度类强输入，应该比泛化的日常磨损更容易转化为战役突破。
4. `normal` 下仍应保留压力感，不能回到“前十回合轻松把战役打穿”的旧状态。

## 方案对比

### 方案 A：补“战役筹备势能”层

在第 1-10 回合累计 `shuMomentum`，在第 11-16 回合累计 `huainanMomentum`。这些势能不等于总国力，而是从主线中抽取“真的和战役准备有关”的成果，在第 10/16 回合额外加到战役 score 上。

优点：

- 最符合《佞臣》的题材表达
- 能解释“为什么这几回合的朝堂布局会改变前线”
- 可以强调特色玩法（谶纬、粮道、军令、中枢节制）

缺点：

- 需要新增一层状态或派生计算
- 需要补规则说明与测试

### 方案 B：仅回调战役阈值

直接下调 `scoreBias`、`gainedThreshold` 或 `stalemateThreshold`。

优点：

- 最快
- 风险小

缺点：

- 只是在放门槛，没有增强“主线成果如何传导到战役”的解释力
- 容易变成单纯调表

### 方案 C：仅重写样本路线

通过调整样本库，让胜利样本写更多偏军粮调度的说辞，从而更容易在现有公式下进入战役得手。

优点：

- 不改系统
- 能快速改善测试报告

缺点：

- 是让样本适应系统，而不是让系统更合理
- 不适合长期设计

## 推荐方案

推荐 **A 为主，B 为辅**。

也就是：

1. 增加“战役筹备势能”
2. 再对 `normal` 战役阈值做小幅回拉
3. 先不下调谶纬线强度

## 战役筹备势能设计

### 势能类型

- `shuMomentum`
- `huainanMomentum`

### 累积时间窗

- `shuMomentum`：第 1-10 回合
- `huainanMomentum`：第 11-16 回合

### 势能来源

只统计“和战役准备明确相关”的成功施计，不统计所有主线成功。

优先来源：

- 高 `militaryRelevance`
- 高 `grainRelevance`
- 高 `governanceRelevance`
- 成功打到调度、军令、粮道、兵权、中枢节制、战区协调

可被放大的特殊类型：

- `omen`
  - 仅当其命中法统、名分、军心或天命焦虑，并与当回合局势直接呼应时
- `advise`
  - 仅当内容明确涉及秩序、后勤、转运、军令、中枢节奏时
- `slander / alienate / frame`
  - 仅当明确点出谁借谁上位、谁替谁背锅、谁与谁互相牵制，导致前线指挥链松动时

不应大量计入的情况：

- 泛化危机感
- 单纯“局势不稳”“人心会散”
- 没有执行链条的空泛朝议评论

### 势能表现形式

建议不用单独做给玩家看的复杂数值条，而是在内部累积，在回合提示/锦囊里用更轻的方式反馈：

- “西线筹备已见眉目”
- “蜀地方向仍欠一口粮道与中枢节次”
- “淮南可乘之隙尚未坐实”

这样既保留系统性，也不把界面做成后台面板。

## 势能如何进入战役结算

### 方案建议

在现有 `campaign score` 上增加一个额外项：

- `score = southPrep - northCommitment + scoreBias + momentumBonus`

其中：

- `shuMomentumBonus` 只用于蜀地
- `huainanMomentumBonus` 只用于淮南

### 建议原则

- 势能加成应当是“有帮助，但不足以单独决定战果”
- 真正的得手仍要看：
  - 南陈基础准备度
  - 北周压力
  - 问政是否配合

也就是说，势能应更像“把原本双失败中的部分胜利样本，推成单战得手或双持偏一得”，而不是直接把所有成功主线都推成双战全收。

## 普通档阈值回调建议

在引入势能后，再考虑对 `normal` 做一档小回拉：

- `scoreBias` 略微回升
- 或 `gainedThreshold` 略降
- 或 `stalemateThreshold` 略降

推荐原则：

- 先上线势能层
- 再根据实测报告决定阈值只回拉一项，不要三项一起动

## 与谶纬的关系

本设计不建议先砍谶纬。

原因：

- 谶纬是《佞臣》的特色玩法
- 它本来就应比普通主线更有“撬动战局”的潜力

更合理的做法是：

- 让谶纬的高质量输入，成为更容易积累战役势能的路径之一
- 但仍要求其命中法统、名分、军心、正统焦虑，而非泛化危言耸听

## 样本库补充建议

当前样本库缺少 `expert-omen`。建议后续补上，以便形成完整梯度：

- `expert-omen`
- `average-omen`
- `rookie-omen-misuse`

否则谶纬线只能看到中位和低位，缺少高手上边界，不利于长期平衡。

## 验证标准

设计落地后，希望 `normal + live DS` 大致出现以下分布：

- `expert-mainline`：多数可赢，且更常见 `单战得手`
- `average-mainline`：应常见 `单战得手 / 双持`
- `average-omen`：应比 `average-mainline` 更容易转出 `单战得手`
- `rookie-mainline`：多数仍输或窄负
- `rookie-aggressive`：应维持明显失败

核心目标：

- 不再出现“所有胜利样本都双战失败”
- 也不回到“多数成功样本双战全收”

## 实施顺序建议

1. 设计并实现 `shuMomentum / huainanMomentum` 的累积规则
2. 将势能接入第 10 / 16 回合战役评分
3. 补 `expert-omen` 样本
4. 跑 live DS smoke matrix
5. 必要时再对 `normal` 的 campaign 阈值做小回拉
