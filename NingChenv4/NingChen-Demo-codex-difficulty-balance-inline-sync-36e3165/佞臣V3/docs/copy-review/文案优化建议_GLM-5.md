# 《佞臣》文案优化建议

**审稿日期**：2026-03-31  
**审稿模型**：GLM-5  
**审稿范围**：玩家可见文案全局审稿

---

## 一、整体评价

整体文案质量较高，历史感基本稳定，信息架构清晰，功能页文案能有效服务玩家决策。以下分"已足够好"与"需优化"两部分。

---

## 二、已足够好的部分

1. **序章"纷乱之世"段落**：开篇气势足，历史背景交代清晰，"分久必合，合久必分"的收束有史诗感。

2. **20回合主线事件文案**：每回合的北朝风云/南陈暗影/朝局简报/锦囊四件套，信息密度适中，语气统一，历史感稳定。

3. **冯道之锦囊**：每条锦囊都是金句，既有策略指导又有历史语境，如"灾年好挑拨，却也最易露出谁真护国、谁只护权"。

4. **南陈问政题库**：题面有时代感，选项风险提示清晰，分支题逻辑自洽。

5. **结算页模块标题**：如"天道判官卷""余波暗动""关系链失衡"等，命名有历史感且功能明确。

## 三、需优化的问题清单

### 【序章部分】

---

**问题 1**

- **位置**：序章 / 女帝之托 / 第4段
- **现在文案**：「她在南陈操盘的是一国兴衰。」
- **可以改成**：「她在南陈执掌的，是一国兴衰。」
- **原因**："操盘"略偏现代商业/股市语境，放在历史权谋叙事中会轻微出戏。

---

**问题 2**

- **位置**：序章 / 你为何入周 / 第2段
- **现在文案**：「甚至不惜借姿色与姿态博取北周文明太后贺拔琪的信任。」
- **可以改成**：「甚至不惜以姿色与姿态，博取北周文明太后贺拔琪的信任。」
- **原因**："借姿色与姿态"中"借"字略显口语化，"以"字更古雅；另"文明太后"是谥号，若此处是玩家初见，可考虑加注或保持，视设计意图而定。

---

**问题 3**

- **位置**：序章 / 十年之诺 / 第1段
- **现在文案**：「落到这一局里，十年被拆成了一年两回合，共二十回合」
- **可以改成**：「此局之中，十年被拆作一年两回合，共二十回合」
- **原因**："落到这一局里"略偏口语，"此局之中"更稳。

---

### 【玩法说明部分】

---

**问题 4**

- **位置**：玩法说明 / 你的目标 / intro
- **现在文案**：「这一局并非只追一个数值。你要同时活下来、拖住北周、削弱其骨架，并让南陈真正变强。」
- **可以改成**：「此局并非只追一个数值。你要同时保全自身、拖住北周、削弱其根基，并让南陈真正壮大。」
- **原因**："这一局"→"此局"；"活下来"→"保全自身"（与后文目标列表统一）；"骨架"→"根基"更符合国力语境；"变强"→"壮大"更有历史感。

---

**问题 5**

- **位置**：玩法说明 / 每回合流程 / intro
- **现在文案**：「一回合并不长，但信息很多。最好按固定顺序看盘、下手、再验算。」
- **可以改成**：「一回合虽短，信息却多。最好按固定顺序观局、出手、再验算。」
- **原因**："看盘"是股市/博彩术语，易出戏；"观局"更贴合权谋语境。

---

**问题 6**

- **位置**：玩法说明 / 计谋系统 / intro
- **现在文案**：「计谋不是直接扣国力的技能按钮，而是通过朝堂人物去拆结构。」
- **可以改成**：「计谋并非直接削减国力的技能，而是借朝堂人物之手，拆解北周的权力结构。」
- **原因**："扣国力""技能按钮"是游戏开发术语，玩家能理解但历史感弱；"拆结构"略口语。

---

**问题 7**

- **位置**：玩法说明 / 势力与风险 / intro
- **现在文案**：「北周不是一个铁板一块的国家。」
- **可以改成**：「北周并非铁板一块。」
- **原因**："不是一个铁板一块的国家"有同义堆叠（"铁板一块"已含"整体"之意），精简后更有力。

---

**问题 8**

- **位置**：玩法说明 / 天道判官 / intro
- **现在文案**：「天道判官不是随意发挥的说书人，而是规则结算之后的叙事汇总者。」
- **可以改成**：「天道判官并非随意发挥的说书人，而是依规则结算后的叙事汇总者。」
- **原因**："不是"→"并非"更古雅；"规则结算之后"→"依规则结算后"更流畅。

## 四、总结建议

### 1. 历史感稳定度

整体良好，主要问题集中在少量现代口语（"操盘""看盘""现实主义者"）和游戏开发术语（"技能按钮""扣国力"）。

### 2. 语气统一性

序章、回合首页、锦囊语气高度统一；玩法说明和第一回合引导略偏口语，可适度调整。

### 3. NPC文案

部分角色公开文案有"作者旁白感"（如"是当朝第一能臣"），可考虑改为更客观的描述；secretThreads整体质量高。

### 4. 信息架构

维度命名不一致（社会秩序 vs 民生秩序）需统一；风险提示格式可标准化。

### 5. 无需大改

20回合主线事件、冯道之锦囊、问政题库核心内容已足够好，只需局部润色。
