# 《佞臣》NPC 角色卡 AI 生图 Prompt

> **目标模型**：AIART (Nano Banana)
> **美术风格锚点**：《全面战争：三国 (Total War: Three Kingdoms)》官方角色立绘
> **输出规格**：竖版半身像，建议 512×768 或 768×1024，PNG/WebP
> **时代背景**：架空南北朝（约公元 550 年代），北周朝廷

---

## 全局风格前缀 (每条 Prompt 前统一加)

```
In the style of Total War Three Kingdoms official character portraits. Semi-realistic Chinese historical painting with dramatic cinematic lighting. Rich dark background with subtle fog or silk texture. Upper body portrait, 3/4 view. Detailed armor/robes with period-accurate Northern and Southern Dynasties (6th century) aesthetics. Oil painting quality, highly detailed face with intense expression.
```

## 附录：使用建议

### 批量生成策略
1. **先生成 2-3 张试水**（推荐先做贺拔琪 + 宇文棣 + 尔朱烈，覆盖三种风格极端）
2. 确认风格满意后再批量出剩余角色
3. 每个角色建议生成 **4 张** 取最佳，挑选标准：
   - 面部清晰、五官自然
   - 服饰与身份匹配
   - 整体色调与游戏深色 UI 协调

### AIART 参数建议
| 参数 | 推荐值 |
|---|---|
| 宽高比 | 2:3 (竖版半身像) |
| 引导强度 (CFG) | 7-9 |
| 步数 | 30-50 |
| 负向提示词 | `low quality, blurry, anime style, cartoon, modern clothing, Western features, deformed hands, extra fingers, watermark` |

### 色调统一性
游戏 UI 是深色系 (`#0a0e1a` 到 `#1a1e2e`)，角色卡底色应偏暗。如果生成的图背景太亮，可以后期在 Photoshop/Figma 中加一层渐变蒙版过渡到游戏背景色。
