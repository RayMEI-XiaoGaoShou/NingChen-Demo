## 1. 目标

本轮接入三类现成资源：

- BGM
- 地图
- NPC 角色图

目标不是重做界面，而是在**不破坏当前主循环与信息结构**的前提下，让素材真正进入玩家体验。

本轮优先级：

1. 让不同页面有明确音画气质区分
2. 让地图真实反映战役推进结果
3. 让 NPC 识别度显著提升

本轮明确不做：

- 群臣列传重做成半身像大卡
- 施计页、朝堂页的大规模视觉重构
- 单独的音效系统
- 多轨音频混音

## 3. 设计选择

本轮采用“平衡接入”方案：

- 接入全局 BGM 控制
- 用真实地图替换回合首页中的“历史辅助 + 方位示意”组合区
- 在背景序章页加入地图
- NPC 图像采用“列表页小头像 + 详情页大图”
- 施计页与暗线回报页同步使用小头像

不采用“整卡半身像主视觉”方案，原因是：

- 当前页面已经跑顺
- 信息密度较高
- 大图重排会显著增加版式风险

## 4. BGM 设计

### 4.1 页面与曲目映射

- `BGM 4`
  - 背景序章页
  - 玩法介绍页
  - 每回合天道结算页
- `BGM 1`
  - 每回合首页
  - 朝局观察页
- `BGM 2`
  - 施计页
  - 暗线回报页
- `BGM 3`
  - 女帝问政页

### 4.2 播放策略

- 整个应用只保留一个全局音频实例
- 页面切换时自动换曲
- 同一组页面之间切换时不重复强制重置
- 默认循环播放
- 初次进入页面时尝试自动播放
- 若浏览器拦截自动播放，则等待用户第一次交互后恢复

### 4.3 控件策略

- 页面右上或全局 utility 区增加一个轻量按钮：
  - `静音`
  - `开声`
- 不做音量滑杆
- 静音状态写入本地存档或本地存储

## 5. 地图设计

### 5.1 序章页

在背景序章页中，“纷乱之世”段落下方新增地图卡。

作用：

- 让玩家在进入故事前先建立地理认知
- 和叙事文字形成对应

此处固定使用：

- `map_1_initial.png`

### 5.2 回合首页

当前首页中：

- `历史辅助`
- `方位示意`

将合并为一张新卡，保留“历史辅助”的解释功能，但主视觉改为地图。

新的结构为：

- 标题：`历史辅助`
- 地图主图
- 下方保留三条说明：
  - 地理提示
  - 势力提示
  - 战略提示

即：

- 不再显示现在的简化点位示意图
- 不再拆成两张卡
- 改成“一张地图主导的辅助卡”

### 5.3 地图切换规则

以战役 `得手` 为唯一换图条件；`stalemate / failed` 不切占领态地图。

规则如下：

- 默认：
  - `map_1_initial.png`
- 若 `shuCampaign.state === 'gained'` 且 `huainanCampaign.state !== 'gained'`
  - `map_2_bashu.png`
- 若 `shuCampaign.state === 'gained'` 且 `huainanCampaign.state === 'gained'`
  - `map_3_bashu_huainan.png`
- 若 `shuCampaign.state !== 'gained'` 且 `huainanCampaign.state === 'gained'`
  - `map_4_huainan.png`

### 5.4 设计理由

采用“只认得手”的规则，是为了保证：

- 地图语义清晰
- 不把 `僵持` 误画成既成事实
- 玩家一眼能看懂“领土格局有没有变”

## 6. NPC 图像设计

### 6.1 列表页小头像

使用位置：

- 朝局观察页的群臣列传
- 施计页目标选择区
- 暗线回报页反馈卡

策略：

- 使用透明底 PNG
- 以小尺寸裁切方式展示
- 保留原有文字信息层级
- 图像只负责强化识别，不承担主要信息表达

### 6.2 详情页大图

使用位置：

- NPC 详情弹窗

策略：

- 作为详情头部主视觉
- 与姓名、官职、阵营信息组合展示
- 使用 `contain` 优先，避免把人物裁坏

### 6.3 文件映射

当前需要做一层静态映射。

特别映射：

- 代码中的 `宇文棣` 使用图片 `拓跋棣.png`
- 女帝页面可使用 `陈倩.png`

其余角色按姓名直接映射。

### 6.4 缺图降级

若某角色图缺失或加载失败：

- 回退到当前占位样式
- 不影响页面功能

## 8. 技术设计

### 8.1 新增媒体配置层

建议新增一层统一配置：

- BGM 路径映射
- NPC 图片路径映射
- 地图路径与战役状态映射

这样可以避免把文件名判断散落在各页面里。

### 8.2 全局音频管理

建议新增一个轻量媒体管理模块，负责：

- 根据当前 phase / 页面切换 BGM
- 处理播放、暂停、静音
- 处理浏览器自动播放失败回退

### 8.3 地图选择函数

建议将地图逻辑写成单独纯函数：

- 输入：`shuCampaign.state`、`huainanCampaign.state`
- 输出：当前应显示的地图资源与文案标签

这样便于后续扩展。

## 10. 风险与控制

### 风险 1：浏览器自动播放限制

控制方式：

- 捕获播放失败
- 在第一次用户交互后重试
- 提供静音/开声按钮

### 风险 2：PNG 透明图尺寸不一，挤乱布局

控制方式：

- 列表页统一用固定容器
- 使用 `object-fit`
- 大图页使用 `contain`

### 风险 3：地图卡过大导致首页拥挤

控制方式：

- 用单张卡替换原两张卡
- 保持说明文案精简
- 先按桌面优先、移动端自适应处理
