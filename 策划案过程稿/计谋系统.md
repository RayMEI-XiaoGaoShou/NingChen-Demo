# 《佞臣》计谋系统

> 本文档定义玩家可用的 8 类计谋、信任度解锁逻辑与详细使用口径。

---

## 1. 总原则

- 每回合最多 3 次计谋
- 采用"选框架 + 补一句说辞"的混合交互
- 玩家话术有影响，但只做小幅修正，不能压过规则
- 计谋不是技能树，而是关系解锁
- 高阶计谋需要：
  - 足够的信任度
  - 以及暗线 / 既有矛盾 / 宏观事件等条件标签

---

## 2. 信任度解锁逻辑

- **0–29：防备 / 敌意**
  - 可用：试探、基础献策

- **30–49：可接近**
  - 可用：试探、献策、谗言

- **50–69：愿意听你**
  - 可用：离间、放风构陷

- **70–89：可被利用**
  - 可用：借刀、求援

- **90+：深信 / 庇护**
  - 可触发：
    - 强保命
    - 深层专属动作
    - 关键支线入口

---

## 3. 8 类已定版计谋

| 编号 | 计谋 | 一句话定位 |
|------|------|-----------|
| 1 | 试探 | 拿信息 |
| 2 | 献策 | 养关系 |
| 3 | 谗言 | 埋刺 |
| 4 | 离间 | 拆盟 |
| 5 | 放风构陷 | 造压 |
| 6 | 借刀 | 杀招 |
| 7 | 求援 | 保命 |
| 8 | 谶纬 | 改叙事（特殊计谋，不常驻） |

---

## 4. 计谋详细口径

### 4.1 试探

- 定位：摸清 NPC 的立场、野心、恐惧、倾向、暗线线索
- 解锁：信任度 >= 0
- 风险：低，但连续试探同一人会加警觉
- 作用：前期核心信息获取动作

### 4.2 献策

- 定位：建立"你对他有用"的印象，涨信任、微调立场
- 解锁：信任度 >= 0
- 风险：低到中，越位献策会引发反感
- 作用：前期最稳定的关系动作

### 4.3 谗言

- 定位：向 A 单点灌输对 B 的负面观感
- 解锁：对 A 信任度 >= 30
- 风险：中，若 A 与 B 关系过近会反伤自己
- 作用：为离间 / 借刀铺垫

### 4.4 离间

- 定位：主动破坏两名 NPC 或两股势力之间的关系
- 解锁：对执行对象信任度 >= 50，且存在矛盾点/暗线/事件支点
- 风险：中到高
- 作用：中期核心局势技

### 4.5 放风构陷

- 定位：合并造谣 / 诬陷，用舆论与政治成本压目标
- 解锁：对传播节点信任度 >= 50，最好有事件支点
- 风险：高
- 作用：中后期造势、压人、启动调查 / 弹劾链条

### 4.6 借刀

- 定位：借别人之手打击目标
- 解锁：对出手者信任度 >= 70，且对方有行动能力与既有矛盾
- 风险：很高
- 作用：最强权谋爽点之一，可造成实质伤害与角色死亡

### 4.7 求援

- 定位：生存技，让高信任角色替你保举、遮掩、站台、传话
- 解锁：对目标信任度 >= 70，且当前存在危险/高风险行动需求
- 风险：中
- 作用：对冲主角生存压力，解锁更高层渠道

### 4.8 谶纬

- 定位：利用灾异、天命、名分重塑政治正当性
- 解锁：特殊事件回合才出现
- 风险：很高且特殊
- 作用：在谶言、疫病、归政、灾异等回合改变叙事框架
