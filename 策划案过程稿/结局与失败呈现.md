# 《佞臣》结局与失败呈现

> 本文档定义所有胜利/失败结局的触发条件、文案风味与结算页反馈设计。

---

## 1. 结局总览

| 编号 | 类型 | 触发条件 | 基调 |
|------|------|----------|------|
| E1 | 💀 死亡 | 单 NPC 触发制 | 悲剧 |

## 2. E1：被看穿处死

### 2.1 触发条件

某 NPC 同时满足：朝堂影响力 ≥ 60 + 对主角信任 ≤ 10 + 具备处置能力

### 2.2 结局风味（按 NPC 分类）

| 处死者 | 结局名 | 基调 | 核心文案方向 |
|--------|--------|------|-------------|
| **祖廷** | "鸟尽弓藏" | 阴冷 | 以"通敌叛国"罪名呈上密奏，你在深夜被禁卫拿下，连太后也来不及保你 |
| **宇文棣** | "宗室清道" | 凛烈 | 燕王在朝堂上当面撕开你的伪装，摔出证据，皇帝默许处置 |
| **令狐律光** | "国法无私" | 沉重 | 以"窥探军机、图谋不轨"之名拿人，令狐不带私情，只说"国法在上" |
| **贺拔琪** | "弃子求安" | 心寒 | 太后亲手抛弃你——她发现你的真实身份或你不再有利用价值，赐鸩一杯 |
| **贺拔伯圭** | "蝼蚁之死" | 暴烈 | 甚至不走朝廷程序，直接以"军法从事"在西线就地处决 |

## 3. E2：北周提前南伐

### 3.1 触发条件

政治意愿（南征派 ≥ 安内派 × 1.3）+ 可战能力（4 维中 ≥ 3 达标）同时满足

### 3.2 结局文案

一段简短叙事：南征大军渡江，南陈仓促应战，未能挡住北周铁骑。

| 要素 | 内容 |
|------|------|
| 标题 | "大江东去" |
| 基调 | 惨烈与无力 |
| 核心文本 | "建文X年秋，北周水陆三十万大军南下。南陈虽有长江天险，终因国力未复，不能抵挡。三月而下建康，女帝陈倩自焚含章殿，南陈亡。" |
| 主角命运 | "萧宝颖的身份在战乱中暴露，被押解邺城。此后史书再无一字提及此人。" |

## 6. 结算页反馈数据

无论胜负，结局页均展示以下分析数据：

| 数据项 | 说明 |
|--------|------|
| **五维对比雷达图** | 南北两国终局五维的蛛网图叠加 |
| **关键成因/败因** | 天道判官自动分析最大的 1-2 个转折点 |
| **势力终局状态** | 四大势力的最终格局：谁得势、谁崩盘、谁边缘化 |
| **关键 NPC 命运** | 存活/死亡/得势/失势/叛变的列表 |
| **统计摘要** | 使用最多的计谋类型、最信任的 NPC、最大一次国力变动 |
