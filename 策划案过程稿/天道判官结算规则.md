# 《佞臣》天道判官与结算映射规则

> 天道判官是每回合结算的核心裁判系统。本文档定义其输入输出规范、行动-数值映射规则与结算优先级。

---

## 1. 天道判官的三项核心职责

| 职责 | 说明 |
|------|------|
| **① 行动结算** | 判断本回合所有行动（计谋+宏观事件+问政）对二级指标→主维度→综合国力的影响 |
| **② 关系结算** | 判断 NPC 对主角信任度变化、NPC 之间关系变化、势力朝堂影响力变化 |
| **③ 危险判定** | 判断是否触发主角死亡、提前南伐、势力崩盘、连锁事件 |

## 2. 计谋→数值映射表

### 2.1 八类计谋对北周五维的影响方向

| 计谋 | 财政 | 粮赋 | 军事 | 社会秩序 | 统治穿透力 | 特殊影响 |
|------|------|------|------|----------|------------|----------|
| **试探** | — | — | — | — | — | 主要作用于信息获取与信任度，不直接改国力 |
| **献策** | ○ | ○ | ○ | ○ | ○ | 作用于单体信任+个别二级指标，取决于献策方向 |
| **谗言** | — | — | — | ○ | ○ | 削弱目标声望→影响社会秩序/统治穿透力 |
| **离间** | — | — | ○ | ○ | ● | 拆盟→统治穿透力核心受损；若涉军事盟友则影响军事 |
| **放风构陷** | ○ | — | — | ● | ● | 舆论压力→社会秩序/统治穿透力；若涉及财政则影响财政 |
| **借刀** | ○ | ○ | ● | ○ | ● | 最强打击：可能导致角色死亡/势力重组/军事格局剧变 |
| **求援** | — | — | — | — | — | 主要作用于主角生存，不直接改国力 |
| **谶纬** | — | — | — | ● | ● | 改变叙事框架→社会秩序/统治穿透力；影响法统修正 |

> ● = 主要影响维度 &ensp; ○ = 可能影响维度 &ensp; — = 通常不影响

### 2.2 计谋结算的数值区间

| 计谋 | 对北周国力影响（综合） | 对信任度影响 | 对势力值影响 |
|------|----------------------|-------------|-------------|
| 试探 | 0 | 对目标 +2~+5 / 失败 -3~-8 | 无 |
| 献策 | -0.5 ~ +0.5（间接） | 对目标 +3~+8 / 越位 -2~-5 | 微调 ±1~±3 |
| 谗言 | -0.5 ~ -1.5 | 对 A 微增或不变；A/B 关系 -3~-8 | ±2~±5 |
| 离间 | **-1 ~ -3** | 对执行者 +2；两方互降 -5~-15 | ±3~±8 |
| 放风构陷 | **-1 ~ -3** | 不定 | ±3~±8 |
| 借刀 | **-2 ~ -5** | 对出手者 +5~+10；对目标 -10~-20 | ±5~±15 或触发崩盘 |
| 求援 | 0 | 对保护者微降（消耗人情） | 无 |
| 谶纬 | **-1 ~ -4** | 不定 | ±3~±10 |

> [!IMPORTANT]
> **借刀**是对北周综合国力伤害最大的计谋（单次 -2 ~ -5），也是最核心的"主杠杆"动作。但需要信任度 ≥ 70 才能解锁，玩家前期必须投入大量试探/献策铺路。

### 2.3 计谋成功率修正因素

天道判官在判定计谋成功程度时，参考以下因素：

| 修正因素 | 方向 | 说明 |
|----------|------|------|
| 信任度高于解锁阈值越多 | ↑ 成功率 | 解锁阈值只是最低要求 |
| 存在匹配的宏观事件支点 | ↑ 成功率 | "借势"比凭空操作更容易成功 |
| 存在匹配的暗线/矛盾点 | ↑ 成功率 | 命中 NPC 痛点 |
| 玩家说辞与 NPC 人设/诉求匹配 | ↑ 成功率 | AI 判定说辞质量，±10% 修正 |
| 目标 NPC 内部稳定度高 | ↓ 成功率 | 稳定的关系更难撬动 |
| 同一回合对同一 NPC 多次操作 | ↓ 成功率 | 会引发警觉 |
| 连续多回合对同一 NPC 用同类计谋 | ↓ 成功率 | 逐次递减 |

## 3. 宏观事件→数值映射表

### 3.1 事件对北周五维的影响方向

|----------|------|------|------|----------|------------|
| 旱灾/水灾 | -1~-2 | -2~-4 | — | -1~-3 | -1 |
| 疫疠 | -1 | -1 | -1~-2 | -2~-4 | -1~-2 |
| 突厥侵边 | -1 | -1 | -1~-3 | -1 | -1~-2 |
| 吐谷浑侵扰 | -1 | — | -1~-2 | — | -1~-2 |
| 益州叛乱 | -1~-2 | -1 | -1~-2 | -2~-3 | -2~-4 |
| 归政之争 | — | — | — | -1~-2 | -1~-3 |

## 4. 问政→数值映射表

问政的数值影响详见 `南陈问政题库.md`。此处仅列出问政结算的通用规则：

| 规则 | 说明 |
|------|------|
| 选项影响 | 占最终结果的 **80%** |
| 理由修正 | 占最终结果的 **±20%** |
| 结算时机 | **延迟一回合**：本回合作答 → 本回合后台记入 → 下回合来信中反馈 |
| 累积效应 | 连续多回合投入同一维度会产生复利效应（连续 3 回合同维度 +1 额外加成） |

## 5. 结算优先级

### 5.1 单回合结算顺序

```
┌──────────────────────────────────────────────────────────┐
│                    回合结算流程                           │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  第一步：宏观事件结算                                     │
│  → 事件对北周五维的基础影响写入                           │
│  → 事件对势力值的基础影响写入                             │
│                                                          │
│  第二步：玩家三次计谋结算                                 │
│  → 按玩家执行顺序逐一结算                                │
│  → 每次计谋对信任度、势力值、五维的影响写入               │
│  → NPC Agent 生成回应文本（不改数值，只生成文本）         │
│                                                          │
│  第三步：连锁反应结算                                     │
│  → 检查是否有 NPC 因信任度/势力值变化触发连锁行为         │
│  → 连锁行为的数值影响写入                                │
│                                                          │
│  第四步：危险判定                                         │
│  → 检查死亡条件（NPC 影响力≥60 + 信任≤10 + 处置能力）    │
│  → 检查提前南伐条件（政治意愿 + 可战能力）               │
│  → 若触发，立即中止后续结算，进入对应流程                 │
│                                                          │
│  第五步：南陈问政结算（上一回合的选择）                    │
│  → 上一回合的问政选项+理由修正 → 南陈五维变化写入         │
│                                                          │
│  第六步：自然增长                                         │
│  → 南陈基线增长写入                                      │
│  → 北周基线增长写入                                      │
│                                                          │
│  第七步：综合国力折算                                     │
│  → 二级指标 → 主维度 → 短板惩罚 → 综合国力               │
│                                                          │
│  第八步：生成回合摘要                                     │
│  → 为下回合开始的朝局简报准备材料                         │
│  → 为冯道之锦囊准备提示方向                               │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 5.2 冲突解决规则

| 冲突情形 | 解决方案 |
|----------|----------|
| 同回合触发死亡+提前南伐 | **死亡优先**——玩家先看到"被杀"结局 |
| 多 NPC 同时满足死亡条件 | 取**朝堂影响力最高**的 NPC 触发 |
| 计谋结果相互矛盾 | 按执行顺序结算，后续计谋基于前面的结果 |
| 事件与计谋影响同一维度 | **叠加**，不抵消。先写事件，再写计谋 |
| 自然增长与短板惩罚冲突 | 先计算自然增长，再应用短板惩罚 |

## 7. 特殊结算规则

### 7.1 借刀杀人的特殊结算

当借刀成功且目标为关键 NPC 时，可能触发以下连锁：

| 后果 | 条件 | 影响 |
|------|------|------|
| NPC 死亡 | 出手者军事实力 ≥ 50 且目标无保护 | 目标从 NPC 列表移除；其势力值剧变 |
| NPC 贬黜 | 出手者朝堂影响力 ≥ 60 | 目标朝堂影响力 -20~-30；信任度重置 |
| NPC 叛变 | 目标内部稳定度 ≤ 20 且存在外部诱因 | 目标转变势力归属；可能引发内战事件 |
| 误伤 | 出手者/目标关系复杂 | 可能伤及无辜第三方，触发连锁信任崩塌 |

### 7.2 谶纬的特殊结算

谶纬不直接改数值，而是改变"叙事框架"，从而在后续回合产生持续影响：

| 效果类型 | 说明 | 持续时长 |
|----------|------|----------|
| 法统动摇 | 北周正统性受到质疑 → 社会秩序/统治穿透力自然增长暂停 | 2 回合 |
| 天命转移 | "天命在南"叙事扩散 → 北周精英服从度下降 | 3 回合 |
| 名分之争 | 触发归政/立储辩论 → 帝党/后党冲突加剧 | 直至事件解决 |

### 7.3 南陈征蜀/征淮南的特殊结算

大规模战役跨越多回合，结算规则特殊：

| 规则 | 说明 |
|------|------|
| 战役准备度 | 由前几回合的投入（军事/粮赋/统治穿透力）综合判定 |
| 战役成功率 | 准备度 + 问政方略选项 + 北周同期内部状况 综合计算 |
| 战果分档 | 大胜 / 小胜 / 僵持 / 小败 / 大败 |
| 后续影响 | 大胜：军+5, 统+3；僵持：军-1, 粮-2；大败：军-5, 社-3, 粮-3 |
