# 佞臣策划案v1

## 0. 文档定位

本文档是在用户原始策划案《AI 游戏 佞臣》基础上，结合本轮完整共创结果整理出的 **Agent 可直接继续工作的高信息密度版本**。  
目标不是一次性写到最终上线版，而是作为后续继续完善角色卡、问政题库、数值初值、前台交互、天道判官规则与 Demo 原型的统一底稿。

本文档重点覆盖：
- 产品定义与体验目标
- 世界观与双线叙事框架
- 北周势力与关键 NPC 结构
- 单局规则、回合流程、胜负条件
- 计谋系统
- 生存 / 南伐 / 问政三大核心规则
- 综合国力系统
- 20 回合主线事件表
- 20 回合结构化事件表
- 20 回合核心 NPC 的事件动机层

## 1. 项目一句话定义

《佞臣》是一款运行于 **H5 网页端** 的 **强文本 / 强系统 / 单局制回合策略叙事模拟游戏**。  
玩家扮演潜伏于北周朝堂的萧宝颖，在北周多方势力之间以权谋手段拨动局势、拖慢其南伐节奏，同时通过与南陈女帝的密信往返参与治国决策，最终追求“南陈综合国力在第 20 回合结束时超过北周”的结局。

---

## 2. 产品定位与核心体验

### 2.1 产品定位
- 形态：H5 网页端
- 风格：低美术、强文本、强系统
- 体验：单局制、20 回合、Roguelike 感
- 节奏：每回合约 5–8 分钟，偏阅读和判断
- Demo 目标：先做一个 **可快速试玩的 MVP**，不追求重美术和超复杂系统

### 2.2 第一爽点
核心爽点是：**操纵权臣、挑拨离间、拨动朝局的权谋爽感**。

### 2.3 开局前三回合体验目标（按优先级）
1. 我能操控局势  
2. 我在刀尖上跳舞，随时会死  
3. 这些 NPC 真的像活人  
4. 这个世界很复杂，我得慢慢摸

### 2.4 总体设计原则
1. **规则主导，AI 增味**  
   - 大战略、数值结算、胜负判定由规则系统决定  
   - AI 负责措辞、态度、临场理由、人物感与文本风味

2. **宏观主线收束 Agent 自由度**  
   - 二十回合内重要历史/架空事件按固定波次发生  
   - 玩家无法阻止事件发生，但可以改变：谁受益、谁失势、谁背锅、谁借机坐大

3. **关系网络即资本**  
   - MVP 阶段不做庞杂资源系统  
   - 主角核心资本是：**信任度 + 关系网络**

4. **政治意愿与国家能力并重**  
   - 北周是否提前南伐，不由单一数值决定  
   - 南陈是否北伐成功，也不由单一数值决定

## 3. 世界观与故事框架

### 3.1 大背景
- 舞台：架空化南北朝晚期，北周 vs 南陈
- 格局：
  - 北周占尽长江以北与蜀地，国力明显强于南陈
  - 南陈历经战乱，实力孱弱，但仍有恢复与北伐意志
- 主角：**萧宝颖**
  - 参考南齐萧宝夤、南梁宗室等元素
  - 幼年因战乱失亲，被南陈先帝收养
  - 与女帝陈倩既是义弟，也有近乎“亦臣亦家人”的关系
- 核心使命：
  - 借南梁宗室身份投靠北周
  - 以美色与政治姿态取得北周文明太后贺拔琪的信任
  - 在北周朝堂中扮演“看似攀附权势、实则暗助南陈”的棋子

### 3.2 女帝陈倩与南陈长期战略
- 女帝陈倩（参考陈文帝）
- 在平天下过程中中毒受伤，只剩约十五年寿命
- 长期目标：
  - 用十年恢复国力
  - 逐步收复蜀地与淮南
  - 十年后开始全面北伐

### 3.3 双线任务结构
#### 北周线（主线，8 成）
- 周旋于四大势力之间
- 操作信任、关系、派系矛盾
- 延缓北周南伐
- 尽可能削弱北周综合国力
- 保全自身

#### 南陈线（辅线，2 成）
- 通过冯道之转交女帝秘信
- 回答问政问题
- 让南陈在财政、粮赋、军事、社会秩序、统治穿透力上逐步变强

### 3.4 宏观故事线的作用
宏观主线由固定发生的事件构成，如：
- 旱灾、疫病、秋涝
- 突厥侵边
- 吐谷浑侵扰河西
- 益州叛乱
- 南陈征蜀
- 南陈征淮南

其作用有三：
1. 为各派系与 NPC 的反应提供共同背景
2. 为玩家计谋制造“借题发挥”的操作空间
3. 收束 Agent 的自由度，使其在合理框架内发挥

## 4. 北周势力格局与关键 NPC

### 4.1 北周势力结构
北周并非高度一体化国家，而是由多个互相牵制、借力的政治—军事集团构成。  
每个势力未来都用以下三项描述：
- **军事实力**
- **朝堂影响力**
- **内部稳定度**

### 4.2 势力列表

#### A. 帝党（综合实力第二）
代表人物：
- 左丞相、燕王 **宇文棣**
- 上柱国、梁国公、都督河南诸军事 **尉迟暮**
- 中常侍 **宗艾**

总体特点：
- 以宗室、前线将帅、皇帝近臣为核心
- 主张对陈强硬，倾向南征
- 容易借“国家危机”抬升自身话语权

#### B. 后党（综合实力最强）
代表人物：
- 太后 **贺拔琪**
- 右丞相、文安侯 **祖廷**
- 上柱国、秦国公、都督河北诸军事 **令狐律光**

总体特点：
- 当前中枢执政集团
- 更强调安内、掌控财政与诏令
- 内部也并非完全同质：祖廷偏权术，令狐律光偏“忠于国家秩序”

#### C. 陇右勋贵
代表人物：
- 卫将军、上柱国、北地公、都督河西陇右诸军事 **贺拔伯圭**
- 后将军、上柱国、澜侯 **独孤文约**

总体特点：
- 有明显地方性与半独立倾向
- 在关西、河西军队与财源上有实际影响力
- 表面结义兄弟，实则彼此提防

#### D. 内附草原势力
代表人物：
- 北庭节度使、上柱国 **尔朱烈**
- 卢龙节度使、上柱国 **安思明**

总体特点：
- 原为草原战败势力，内附北周求庇护
- 以骑兵见长，但甲具、军备弱于北周官军
- 对中原朝廷有依附，也有独立心思

## 5. 关键 NPC（阶段性版本）

### 5.1 冯道之
- 身份：南朝暗庄之首，国子监祭酒，表面不参与政治
- 背景：原南梁南豫州太守，后出仕北朝，在各方左右逢源
- 与南朝关系：与南朝先帝陈霸先相识于微末，实际心向南朝
- 功能：
  - 每回合开始前，根据上回合结算提供“锦囊妙策”
  - 是主角在北周最重要的暗线辅助者

### 5.2 宇文棣
- 势力：帝党
- 身份：左丞相、燕王，皇帝亲叔叔
- 公开人设：聪慧、有大志、锋芒毕露、强硬主战
- 公开立场：主张趁南陈未稳尽快南征
- 固定暗线：
  - 对宇文氏一片忠心
  - 小皇帝也会担心其坐大
  - 主角可以挑拨其与侄子关系

### 5.3 尉迟暮
- 势力：帝党
- 身份：上柱国、梁国公、都督河南诸军事
- 公开人设：忠于皇族的大将与封疆大吏
- 公开立场：南征派，掌 10 万野战军，驻寿春
- 固定暗线：待后续补完，但当前定位为“前线军功与前线资源”的核心承压点

### 5.4 宗艾
- 势力：帝党 / 保皇线接口
- 身份：中常侍，皇帝近侍与代言人
- 公开人设：地位低微、表面逢迎各方
- 公开立场：负责传递皇帝声音
- 固定暗线：
  - 宦官传统上地位低，长期受排挤
  - 表面对各派阿谀奉承，实则有自己的野心和盘算
  - 是主角间接接触皇帝的关键通道

### 5.5 祖廷
- 势力：后党
- 身份：右丞相、文安侯
- 公开人设：政务能力强、专权、睚眦必报
- 公开立场：支持后党中枢运转，强调秩序与行政能力
- 与主角关系：初始信任度较低，对主角轻视
- 固定暗线：待完善

### 5.6 令狐律光
- 势力：后党
- 身份：上柱国、秦国公、都督河北诸军事
- 公开人设：重臣、老成、持重、掌 20 万禁卫军
- 公开立场：安内派，主张攘外必先安内
- 固定暗线：
  1. 希望先平定表里不一的内附草原势力
  2. 虽属后党，但本质忠于北周朝廷，也担心太后与贺拔伯圭做大

### 5.7 贺拔琪
- 势力：后党
- 身份：北周太后
- 公开人设：摄政五年，笼络汉人门阀与寒门军官制衡传统鲜卑贵族
- 公开立场：掌控朝局、维持摄政秩序
- 与主角关系：太后对主角初始信任极高，是主角最初保护伞

### 5.8 贺拔伯圭
- 势力：陇右勋贵
- 身份：卫将军、上柱国、北地公、都督河西陇右诸军事
- 公开人设：骄横跋扈、看不起主角、以护商道为由大肆揽权
- 军力：天琅卫 5 万，屯金城郡
- 固定暗线：待定，但当前共创方向明确为“借西线危机将战时权固化为长期地方权”

### 5.9 独孤文约
- 势力：陇右勋贵
- 身份：后将军、上柱国、澜侯
- 公开人设：圆滑、会做人，与帝党、后党都能往来
- 军力：私军 3 万
- 固定暗线：
  - 主动与主角交好
  - 想谋求更大利益
  - 不愿成为贺拔伯圭附庸

### 5.10 尔朱烈
- 势力：内附草原势力
- 身份：北庭节度使、上柱国
- 公开人设：边帅、强悍、现实主义者
- 军力：约 2 万骑兵，屯雁门
- 固定暗线：
  - 保皇派想借草原势力清君侧
  - 有长期在中原发展的打算，希望获得高位

### 5.11 安思明
- 势力：内附草原势力
- 身份：卢龙节度使、上柱国
- 公开人设：实利主义、看重军备
- 军力：约 2 万骑兵，屯辽东
- 固定暗线：
  - 更希望借北周朝廷支持重新打回草原

## 6. NPC Agent 设计原则

1. 每个关键 NPC 都拥有：
   - 公开人设
   - 固定暗线
   - 对主角信任度
   - 派系归属
   - 局中能力（兵权、政权、信息渠道等）

2. NPC 的大战略与底层利益由规则系统给定  
   Agent 负责在宏观事件与玩家行为面前生成更鲜活的回应

3. 当前版本优先使用 **固定秘密**，而不是动态欲望  
   这样更利于：
   - 探索
   - 试探
   - 挑拨
   - 借题发挥
   - 剧情反转

## 7. 单局结构、胜负与总体目标

### 7.1 核心目标
1. 保全自身  
2. 给北周南伐拖后腿，为南陈争取时间  
3. 在 20 个回合内尽可能削弱北周综合国力  
4. 通过给女帝问政，提升南陈综合国力

### 7.2 胜利条件
- 到第 20 回合结束时，由天道判官结算南北综合国力
- 若南陈综合国力 > 北周，则触发“南陈北伐成功”胜利结局

### 7.3 失败条件
1. 主角被关键高权重 NPC 看穿并处死  
2. 北周在第 20 回合前触发提前南伐（MVP 阶段直接判负）  
3. 第 20 回合结束时南陈综合国力仍弱于北周，北伐失败

### 7.4 局制定位
- 单局制
- 20 回合
- 偏 Roguelike 感
- 不走“长期养成存档叙事线”路线

## 8. 每回合标准流程（玩家感知层）

### 流程总览
1. **回合开始：朝局简报**
   - 上回合摘要
   - 本回合宏观事件播报
   - 冯道之锦囊

2. **朝局观察**
   - 可互动 NPC 列表
   - 派系格局
   - 当前风险提示
   - 南征派 vs 安内派态势

3. **玩家阶段：3 次计谋**
   - 最多与 3 名 NPC 深度互动
   - 每次操作 = 选 NPC → 选计谋 → 补一句说辞

4. **南陈阶段：女帝来信问政**
   - 玩家回答女帝问题
   - 前台继续有事可做
   - 后台开始跑北周结算

5. **北周结算揭晓**
   - NPC 正式反馈
   - 派系与关系变化
   - 国力变化
   - 生存风险 / 南伐风险变化

6. **回合收束**
   - 一句局势总结
   - 下回合钩子

### 系统后台流程
- 在南陈阶段同步运行：
  - 北周计谋完整结算
  - NPC 信任变化
  - 势力值变化
  - 国力维度变化
  - 是否触发提前南伐 / 连锁事件 / 死亡风险
- 南陈问政结果建议延迟一回合揭示：
  - 本回合作答
  - 本回合后台记入
  - 下回合来信中反馈

## 9. 计谋系统

### 9.1 总原则
- 每回合最多 3 次计谋
- 采用“选框架 + 补一句说辞”的混合交互
- 玩家话术有影响，但只做小幅修正，不能压过规则
- 计谋不是技能树，而是关系解锁
- 高阶计谋需要：
  - 足够的信任度
  - 以及暗线 / 既有矛盾 / 宏观事件等条件标签

### 9.2 信任度解锁逻辑
- **0–29：防备 / 敌意**
  - 可用：试探、基础献策

- **30–49：可接近**
  - 可用：试探、献策、谗言

- **50–69：愿意听你**
  - 可用：离间、放风构陷

- **70–89：可被利用**
  - 可用：借刀、求援

- **90+：深信 / 庇护**
  - 可触发：
    - 强保命
    - 深层专属动作
    - 关键支线入口

### 9.3 8 类已定版计谋
1. 试探  
2. 献策  
3. 谗言  
4. 离间  
5. 放风构陷  
6. 借刀  
7. 求援  
8. 谶纬（特殊计谋，不常驻）

### 9.4 计谋摘要
- **试探**：拿信息  
- **献策**：养关系  
- **谗言**：埋刺  
- **离间**：拆盟  
- **放风构陷**：造压  
- **借刀**：杀招  
- **求援**：保命  
- **谶纬**：改叙事

### 9.5 计谋详细口径

#### 试探
- 定位：摸清 NPC 的立场、野心、恐惧、倾向、暗线线索
- 解锁：信任度 >= 0
- 风险：低，但连续试探同一人会加警觉
- 作用：前期核心信息获取动作

#### 献策
- 定位：建立“你对他有用”的印象，涨信任、微调立场
- 解锁：信任度 >= 0
- 风险：低到中，越位献策会引发反感
- 作用：前期最稳定的关系动作

#### 谗言
- 定位：向 A 单点灌输对 B 的负面观感
- 解锁：对 A 信任度 >= 30
- 风险：中，若 A 与 B 关系过近会反伤自己
- 作用：为离间 / 借刀铺垫

#### 离间
- 定位：主动破坏两名 NPC 或两股势力之间的关系
- 解锁：对执行对象信任度 >= 50，且存在矛盾点/暗线/事件支点
- 风险：中到高
- 作用：中期核心局势技

#### 放风构陷
- 定位：合并造谣 / 诬陷，用舆论与政治成本压目标
- 解锁：对传播节点信任度 >= 50，最好有事件支点
- 风险：高
- 作用：中后期造势、压人、启动调查 / 弹劾链条

#### 借刀
- 定位：借别人之手打击目标
- 解锁：对出手者信任度 >= 70，且对方有行动能力与既有矛盾
- 风险：很高
- 作用：最强权谋爽点之一，可造成实质伤害与角色死亡

#### 求援
- 定位：生存技，让高信任角色替你保举、遮掩、站台、传话
- 解锁：对目标信任度 >= 70，且当前存在危险/高风险行动需求
- 风险：中
- 作用：对冲主角生存压力，解锁更高层渠道

#### 谶纬
- 定位：利用灾异、天命、名分重塑政治正当性
- 解锁：特殊事件回合才出现
- 风险：很高且特殊
- 作用：在谶言、疫病、归政、灾异等回合改变叙事框架

## 10. 三大关键规则

### 10.1 “被看穿处死”的触发逻辑
采用 **单 NPC 触发制**。  
当某一 NPC 同时满足以下三项时，可在回合结算中直接触发主角死亡：

1. 朝堂影响力达到高位阈值  
2. 对主角信任度跌破危险阈值  
3. 具备实际处置能力  
   - 兵权  
   - 政务中枢  
   - 诏令渠道  
   - 能直接影响皇帝 / 太后

MVP 阶段不加入：
- 被弹劾 → 被软禁 → 被审讯的缓冲态
- 一次性保命兜底

这些可以作为未来扩展方向。

### 10.2 北周“提前南伐”的阈值
采用 **政治意愿 + 可战能力** 的双门槛机制。

#### A. 政治意愿门槛
- 当南征派总朝堂影响力显著高于安内派时
- 北周进入“具备南征政治意愿”状态

#### B. 可战能力门槛
MVP 阶段看四项：
- 军事
- 财政
- 粮赋
- 社会秩序（或稳定度）

当四项中达到可战标准的维度不少于 3 项时，北周进入“具备南征能力”状态。

#### 触发规则
- 两项同时满足 → 触发提前南伐
- MVP 阶段直接判负

#### 额外修正
若当回合存在：
- 边患
- 叛乱
- 灾荒
- 疫病  
则南伐阈值提高

### 10.3 南陈问政如何避免变成“AI 主观作文比赛”
采用：
**预设题目 + 四选一 + 理由小修正**

规则如下：
1. 每回合问政题预设
2. 每题有 4 个选项
3. 每个选项已预写其五维影响倾向
4. 玩家补充理由，只做小幅修正
5. AI 只负责判断：
   - 相关性
   - 与所选项的一致性
   - 与当前国情的贴合度
6. AI 不直接决定政策本身优劣

建议评分：
- 选项决定 80%
- 理由修正最多 20%

## 11. 综合国力系统

### 11.1 五维主指标（已定版）
综合国力采用五个 mutually exclusive 的主维度：

1. **财政能力**
2. **粮赋基础**
3. **军事能力**
4. **社会秩序**
5. **统治穿透力**

说明：
- 原“法统合理性”不再作为主维度
- 改为隐性修正项，用于影响：
  - 社会秩序
  - 统治穿透力
  - 特殊事件判定
  - 谶纬类计谋效果

### 11.2 五维定义

#### 财政能力
朝廷可直接动用的税赋、商税、国库与财政余裕。

#### 粮赋基础
国家土地、户口、粮产、仓储与漕运基础。

#### 军事能力
可投入战争的兵员、武备、训练与机动能力。

#### 社会秩序
国家内部的治安、民变、叛乱与整体社会稳定状态。

#### 统治穿透力
中央朝廷对地方、军队、官僚与资源的调度、执行和控制能力。

### 11.3 二级指标设计

#### 财政能力
- 岁入能力（50%）
- 国库余裕（25%）
- 财政汲取效率（25%）

#### 粮赋基础
- 土地与户口基础（45%）
- 粮食产出与仓储（35%）
- 漕运与转运能力（20%）

#### 军事能力
- 可战兵力规模（40%）
- 武备与战斗质量（35%）
- 战略部署与机动性（25%）

#### 社会秩序
- 民生压力（35%）
- 地方动荡风险（40%）
- 精英阶层服从度（25%）

#### 统治穿透力
- 官僚执行力（30%）
- 对地方/边镇/军头的控制力（40%）
- 资源动员能力（30%）

### 11.4 单回合变动规则
#### 二级指标变动
- 普通行动：-1 到 +1
- 关键行动 / 问政策略：-2 到 +3
- 宏观事件 / 叛乱 / 战争：-4 到 +6
- 极端事件（少见）：-8 到 +8

#### 主维度变动（汇总后）
- 常规回合：单项主维度通常不超过 ±3
- 重大事件回合：可达到 ±5 或 ±6
- 平衡原则：
  - 一回合通常只有 1–2 个主维度显著变化
  - 超过 ±3 的主维度最好不超过 1 个

### 11.5 综合国力折算公式
设：
- F = 财政能力
- G = 粮赋基础
- M = 军事能力
- O = 社会秩序
- T = 统治穿透力

则：

**综合国力底分 = 0.18F + 0.22G + 0.24M + 0.16O + 0.20T**

### 11.6 短板惩罚
- 任一主维度 < 40：综合国力 -2
- 任一主维度 < 25：额外 -4
- 若社会秩序 < 25 或统治穿透力 < 25：再额外 -3

#### 最终公式
**综合国力 = 五维加权底分 - 短板惩罚**

### 11.7 法统 / 正统性处理
法统不进入五维主指标，而作为隐性修正项存在。  
建议 MVP 阶段仅分三档：
- 高
- 中
- 低

其影响：
- 社会秩序波动幅度
- 统治穿透力恢复效率
- 谶纬 / 名分相关事件
- 部分南陈问政题效果修正

## 15. 核心 NPC 的“公开诉求 / 隐性诉求 / 易被何种计谋撬动”摘要

> 注：此处不是完整角色卡，而是基于 20 回合事件推进中已经提炼出的动机骨架。

### 15.1 宇文棣
- 公开诉求：对陈强硬、抢占南征主导权、维护宗室与国家威势
- 隐性诉求：压后党、维持自己作为宇文氏最能担国难之人的位置
- 最容易被撬动：
  - 献策（顺着其强硬路线设计赢法）
  - 谗言（放大后党拖延、误国）
  - 离间（挑其与皇帝、后党的微妙互疑）

### 15.2 尉迟暮
- 公开诉求：前线需要更多兵、粮、授权
- 隐性诉求：将自己从边帅抬升为国家柱石，避免久战后背锅
- 最容易被撬动：
  - 献策（前线务实方案）
  - 求援（将其转为保护者/渠道）
  - 借刀（高信任后逼资源、压制掣肘者）

### 15.3 宗艾
- 公开诉求：替皇帝感知群臣忠诚、传递皇帝意志
- 隐性诉求：把自己做成皇帝与各派之间不可替代的接口
- 最容易被撬动：
  - 试探
  - 求援
  - 借刀
  - 谶纬（在宫中叙事/名分回合）

### 15.4 祖廷
- 公开诉求：维持中枢秩序、掌后勤、掌财政、掌诏令
- 隐性诉求：将“无祖廷则国政不行”坐实，防军头、宗室、边镇抢走机器
- 最容易被撬动：
  - 献策（制度、财政、接管方案）
  - 放风构陷（谁在侵吞、谁在借战乱揽权）
  - 试探（辨其是护国还是护权）

### 15.5 令狐律光
- 公开诉求：先安内，后攘外；边镇、草原势力、地方失控都比仓促大战危险
- 隐性诉求：证明自己的路线从头到尾是对的，同时防任何一派借战乱吞并国家
- 最容易被撬动：
  - 谗言（主战派谋私）
  - 离间（帝党、草原势力与后党之间的互疑）
  - 献策（如何稳国家而非稳派系）

### 15.6 贺拔琪
- 公开诉求：稳定摄政秩序，任何大战略都必须在自己手里展开
- 隐性诉求：既要利用宇文棣、贺拔伯圭等人，又不能让他们借国难坐大到失控
- 最容易被撬动：
  - 求援（天然保护伞）
  - 献策（如何平衡各方）
  - 借刀（危机回合借其手清理问题人物）

### 15.7 贺拔伯圭
- 公开诉求：西线需要自己总领，护河西、护商道、护蜀地
- 隐性诉求：把战时权变成长期地方权，构筑河西—关西—蜀地的连续影响圈
- 最容易被撬动：
  - 献策（如何更名正言顺地揽权）
  - 离间（中枢不信你、独孤抢你）
  - 借刀（高信任后逼他主动压人）

### 15.8 独孤文约
- 公开诉求：自己也能平西线、也能为朝廷分忧
- 隐性诉求：绝不当贺拔伯圭的附庸，要做西线第二中心乃至替代方案
- 最容易被撬动：
  - 试探
  - 离间（贺拔独吞功劳）
  - 献策（你其实比贺拔更能和中枢合作）

### 15.9 尔朱烈
- 公开诉求：边地要兵、要封赏、要地位
- 隐性诉求：从依附草原首领升级为中原权力人物
- 最容易被撬动：
  - 献策
  - 求援
  - 离间（朝中谁真正看不起他、谁想压他）

### 15.10 安思明
- 公开诉求：要军资、要甲具、要信任
- 隐性诉求：借北周资源为未来重返草原做准备
- 最容易被撬动：
  - 献策
  - 试探
