# 《佞臣》前台交互与信息可见性设计

> 本文档定义 8 个核心页面的信息架构、信息可见性规则与新手引导方案。

---

## 1. 页面总览

```
回合开始页 → 朝局观察页 → NPC详情页（可选）
    ↓
计谋操作页（×3）→ 女帝来信页 → 北周结算页 → 回合收束页
    ↓（第20回合后）
结局页
```

---

## 2. 各页面信息架构

### 2.1 回合开始页

| 区域 | 内容 | 说明 |
|------|------|------|
| 回合标题 | "第 X 回合 · 建文X年/天嘉X年" | 增强时代沉浸感 |
| 上回合摘要 | 2-3 句话概括上回合关键变化 | 由天道判官第八步生成 |
| 宏观事件播报 | 本回合发生的全局事件卡片 | 1 个主事件，带简短描述 |
| 冯道之锦囊 | 1 段暗示性提示 | 不直接说答案，提供方向 |
| 进入按钮 | "入朝" | 进入朝局观察页 |

### 2.2 朝局观察页

这是玩家每回合决策前的"仪表盘"。

| 区域 | 内容 | 优先级 |
|------|------|--------|
| **北周国力仪表** | 北周综合国力（标签制，见 3.1） | 必显 |
| **南征风险条** | 当前南征风险等级（见 3.3） | 必显 |
| **自身安全** | 当前生存风险等级（见 3.4） | 必显 |
| **四方势力概况** | 各势力的朝堂影响力条形图 | 必显 |
| **可互动 NPC 列表** | 当前可交互的 NPC 头像+信任标签 | 必显 |
| **南征/安内态势** | 两派力量对比条 | 必显 |
| 剩余计谋次数 | "今日可用计谋：3/3" | 必显 |

### 2.3 NPC 详情页（点击 NPC 进入）

| 区域 | 内容 | 可见性 |
|------|------|--------|
| 头像与称号 | 姓名、官职、势力标签 | 公开 |
| 信任状态 | 标签制（见 3.2） | 公开 |
| 公开立场 | 1-2 句话 | 公开 |
| 已知情报 | 通过试探获取的暗线片段 | 逐步解锁 |
| 关系网络 | 该 NPC 与其他 NPC 的已知关系 | 逐步解锁 |
| 可用计谋列表 | 当前信任度下可对其使用的计谋 | 动态 |
| 行动按钮 | "施计" | — |

### 2.4 计谋操作页

| 步骤 | 内容 |
|------|------|
| ① 选择目标 NPC | 从可互动列表中选择 |
| ② 选择计谋类型 | 展示当前信任度下可用的计谋，灰显不可用的 |
| ③ 选择关联角色（部分计谋需要） | 如离间需指定第二个 NPC |
| ④ 补一句说辞 | 文本输入框，限 50 字以内 |
| ⑤ 确认执行 | "行事" 按钮 |
| ⑥ 即时简要反馈 | NPC 的一句话简短反应（表情+一句话） |

> 完整结果在"北周结算页"揭晓。即时反馈只给氛围，不给具体数值变化。

### 2.5 女帝来信页

| 区域 | 内容 |
|------|------|
| 来信人 | "南陈女帝 · 陈倩" |
| 上回合问政反馈 | 上一回合选择的成效简述（回合 1 无此项） |
| 本回合问政题 | 背景描述 + 题干 |
| 四个选项 | 选项卡/按钮形式 |
| 理由输入 | 选定选项后出现文本框，限 100 字 |
| 递交按钮 | "奏上" |

### 2.6 北周结算页

| 区域 | 内容 | 展示方式 |
|------|------|----------|
| 计谋结果 | 3 次计谋的逐条结果 | 依次展开，NPC 完整回应+信任度变化标签 |
| 势力变化 | 四方势力的关键变动 | 变化箭头（↑↓—） |
| 北周国力变化 | 综合国力标签变化 | 标签色彩变化 |
| 南征风险变化 | 风险等级变化 | 色彩变化 |
| 危险预警 | 若接近死亡/南伐阈值 | 红色警报弹窗 |

### 2.7 回合收束页

| 区域 | 内容 |
|------|------|
| 一句局势总结 | "本回合：XXX" |
| 下回合钩子 | "下回合预告：XXX" |
| 继续按钮 | "翻月" → 进入下回合 |

### 2.8 结局页

详见 `结局与失败呈现.md`。

## 3. 信息可见性规则

### 3.1 北周综合国力——标签制

玩家**不可见**具体数值，只能看到分段标签：

| 综合国力范围 | 显示标签 | 颜色 |
|-------------|---------|------|
| ≥ 75 | 鼎盛 | 深红 |
| 60–74 | 强盛 | 红 |
| 45–59 | 中平 | 黄 |
| 30–44 | 衰弱 | 绿 |
| < 30 | 崩塌 | 灰 |

> 北周初始 65.5 → 显示"强盛"。玩家需要将其打到"中平"以下才有胜算。

### 3.2 NPC 信任度——标签制

| 信任度范围 | 显示标签 | 图标 |
|-----------|---------|------|
| 0–14 | 敌意 | 🔴 |
| 15–29 | 戒备 | 🟠 |
| 30–49 | 平淡 | 🟡 |
| 50–69 | 信赖 | 🟢 |
| 70–89 | 倚重 | 🔵 |
| 90–100 | 深信 | 💜 |

> 不显示具体数字。玩家只能感受到大致区间，通过 NPC 的措辞变化判断微妙变化。

### 3.3 南征风险——三级信号

| 等级 | 条件 | 显示 |
|------|------|------|
| ✅ 安全 | 南征派影响力 < 安内派 × 0.8 | 绿色"安内占优" |
| ⚠️ 警戒 | 南征派影响力介于 0.8× ~ 1.3× 安内派 | 黄色"南征议起" |
| 🚨 危急 | 接近触发阈值（≥ 1.2× 且可战能力达标中） | 红色闪烁"南征在即" |

### 3.4 自身安全——三级信号

| 等级 | 条件 | 显示 |
|------|------|------|
| ✅ 安稳 | 无 NPC 满足死亡条件的前两项 | 绿色"朝中无虞" |
| ⚠️ 有人盯上你 | 存在 NPC 影响力≥60 且信任≤25 | 黄色"暗流涌动" |
| 🚨 命悬一线 | 存在 NPC 影响力≥60 且信任≤15 且有处置能力 | 红色"祸在旦夕" |

### 3.5 南陈国力——完全不可见

玩家**无法直接看到**南陈综合国力数值或标签。只能通过：
- 女帝来信中的措辞感受国力变化
- 冯道之锦囊中的侧面暗示
- 自身对问政选择的记忆

> 这是核心设计意图：**玩家只能见北周，不见南陈**，保持信息不对称的紧张感。

### 3.6 势力值与朝堂影响力

| 信息 | 可见性 | 显示方式 |
|------|--------|----------|
| 各势力朝堂影响力 | **可见** | 条形图（相对比例，不显示数字） |
| 各势力军事实力 | **部分可见** | 标签制（强/中/弱） |
| 各势力内部稳定度 | **不可见** | 需通过试探获取信息碎片 |

### 3.7 暗线揭露规则

| 途径 | 说明 |
|------|------|
| 试探成功 | 获取 1 条暗线碎片，存入该 NPC 详情页的"已知情报" |
| 宏观事件触发 | 部分事件自动揭露 1 条相关暗线 |
| 冯道之锦囊 | 偶尔包含 1 条暗线提示 |
| 关系升级 | 信任度跨过新层级时可能自动揭露 1 条 |

> 暗线碎片是永久的——一旦获取，终局可用。

## 4. 新手引导设计

### 4.1 引导时间线

| 回合 | 引导内容 |
|------|----------|
| **回合 1** | 半教学回合：引导玩家完成第一次试探+第一次献策，教会基本操作 |
| **回合 1** | 强制显示冯道之对话教学：解释朝局观察页各模块含义 |
| **回合 2** | 第一次问政引导：手把手说明选项+理由的操作方式 |
| **回合 2** | 解锁谗言提示：若有 NPC 信任度达到 30，弹出"新计谋可用" |
| **回合 3–4** | 自由探索，不再强制引导 |
| **回合 4** | 第一次明确提示死亡风险："冯道之密语：小心某某对你的态度……" |
| **回合 5–6** | 第一次明确提示南征风险："冯道之密语：南征之议又起……" |

### 4.2 引导原则

- **不要信息过载**：回合 1 只教操作，不讲数值
- **通过冯道之传递教学**：保持叙事沉浸感，避免 UI 弹窗说教
- **逐步开放**：前 2 回合限制可用计谋数量（仅试探+献策），回合 3 起全面开放
- **风险提示靠叙事**：不用系统弹窗说"你可能会死"，而是通过 NPC 态度变化和冯道之暗示来表达
