# 计谋筹算结果默认反馈整理

## 一句话结论

“计谋筹算结果”里的短句，例如“宇文棣略作沉吟，显然已被你的献策拨动了算盘”，不是计谋回报页的 AI NPC 长回复，而是结算引擎在每条计谋结算后生成的本地默认反馈。

它的定位是：快速告诉玩家“这条计谋成了还是没成”，再配合下方的“国力影响 / 朝堂政局”解释玩家为什么会看到这些数值变化。

## 当前所有计谋类型

当前北周计谋类型包括：

| 内部类型 | 玩家看到的名称 |
| --- | --- |
| `probe` | 试探 |
| `advise` | 献策 |
| `slander` | 谗言 |
| `alienate` | 离间 |
| `frame` | 设局嫁祸 |
| `proxy` | 借刀 |
| `appeal` | 求援 |
| `omen` | 谶纬 |
| `secession` | 煽动割据 |
| `rebellion` | 煽动造反 |

## 通用成功反馈

除特殊计谋外，大多数计谋成功后会从以下三句中随机选择一句：

1. `{NPC}略作沉吟，显然已被你的{计谋名}拨动了算盘。`
2. `{NPC}不曾明言应允，但神色一松，你知道这步{计谋名}已押中其心结。`
3. `{NPC}听罢只淡淡应了一声，话没说透，路却已悄悄转了方向。`

这组文案的特点是：

- 比较通用，适配多种计谋。
- 重点表达“已被说动”。
- 不负责解释具体数值为什么变化，解释工作交给后面的“国力影响 / 朝堂政局”。

## 通用失败反馈

除特殊计谋外，大多数计谋失败后会从以下三句中随机选择一句：

1. `{NPC}听后并未接茬，反倒多看了你一眼，你知道这步{计谋名}落空了。`
2. `{NPC}面色微冷，显然已对你的意图起了戒心。`
3. `{NPC}既不应承也不发怒，只把话题轻轻拨开，这比翻脸更说明问题。`

这组文案的特点是：

- 表达“没接住 / 看穿了 / 不愿接话”。
- 不直接说明损失原因。
- 如果失败导致朝局反噬，后续会在“朝局反噬”板块体现。

## 设局嫁祸的特殊反馈

设局嫁祸有一层专门判断：如果 AI 解析认为玩家输入具备一定“自陷潜力”或“嫌疑回落清晰度”，成功或失败时会优先使用特殊文案。

### 成功时

可能出现：

1. `{NPC}先是一怔，旋即像是意识到自己话说得过了，你知道这步设局嫁祸已逼他露了口风。`
2. `{NPC}神色微变，像是忽然察觉自己正往你设下的局里走去，可已来不及全身而退。`
3. `{NPC}话里那点破绽已被你轻轻带出来，这步设局嫁祸最要命的嫌疑，终究还是会落回他自己身上。`

### 失败时

可能出现：

1. `{NPC}没有顺着你的话失态，反而把口风收得更紧，你知道这步设局嫁祸没能把他逼进局里。`
2. `{NPC}神色一沉便不再接话，显然已觉出你想借题让他背嫌疑。`

### 设计含义

设局嫁祸的重点不是“说服目标相信某事”，而是“引诱目标失言、失态、失措，使嫌疑回落到目标自己身上”。

所以它比通用计谋更需要在结算页呈现：

- 目标为什么露破绽。
- 朝堂为什么会把这个破绽理解为嫌疑。
- 这个嫌疑如何影响皇帝恩宠、太后眷顾、派系稳定或国力五维。

## 谶纬对外部军头的特殊反馈

当计谋类型是谶纬、计谋成功、目标是地方军头时，会优先使用特殊文案。

可能出现：

1. `{NPC}听罢便知中枢已起疑，粮道与军需多半要先紧一圈，御史监军也会跟着盯得更密；边镇兵势只是受了小挫，真正更重的是他心里那口怨气。`
2. `{NPC}虽未当场失色，却已明白中枢这道谶纬会把朝里的猜忌引到边镇上来：先卡粮道与军需，再加御史监军，兵势只挨一点折，忠心却更难再稳。`
3. `{NPC}一下就听出这不是空泛天象，而是中枢要借疑心收紧粮道、军需与眼线，再把御史监军压下去；边镇兵势未必大损，心里却先松了一层。`

### 设计含义

这组文案已经在解释“地方军头为什么会军力下降、忠诚下降”：

- 谶纬让中枢起疑。
- 中枢收紧粮饷、军需、监军。
- 军力小幅受损。
- 忠诚度更明显下降。

这和我们之前讨论的地方军头数值可解释性是一致的。

## “国力影响 / 朝堂政局”的当前解释层

每张计谋筹算卡目前除了短反馈，还会显示两段解释：

1. `国力影响`
2. `朝堂政局`

### 国力影响

这一段解释本回合是否直接伤到北周五维。

当前逻辑大致是：

- 如果计谋失败：提示这手没能咬住目标心思，也未直接削弱北周国力。
- 如果计谋成功但没有国力伤害：提示说动了目标，但没有直接削弱北周国力。
- 如果目标是地方军头且造成国力伤害：提示借外部筹码发力，导致某些北周五维亏空。
- 如果目标是朝堂人物且造成国力伤害：提示顺着目标所在权力位置发力，导致某些北周五维被削弱。

### 朝堂政局

这一段解释计谋如何撬动中间层结构。

不同计谋当前有不同的结构解释：

| 计谋 | 当前结构解释方向 |
| --- | --- |
| 谗言 | 命中施计对象对相关 NPC 的疑虑，顺水推了一把 |
| 离间 | 顺着两名 NPC 之间原有裂痕再往深处推 |
| 设局嫁祸 | 逼得目标自己露马脚，嫌疑回落到目标身上 |
| 谶纬 | 打的不是人，而是名分；天命之说裂开后，目标根基松动 |
| 献策等其他计谋 | 如果提升信任，则提示目标更愿意听你说话，后续沿线施压更顺手 |
| 地方军头相关计谋 | 解释信任、忠诚、军力如何变化 |

## 对当前默认反馈的判断

当前默认反馈有两个优点：

- 足够稳定，不依赖额外 AI 调用。
- 能快速告诉玩家成败，不会抢走天道卷轴和 NPC 回报页的叙事空间。

但也有三个问题：

- 通用成功反馈覆盖面太广，导致献策、谗言、离间、借刀、煽动割据等计谋的“手感”不够分明。
- 设局嫁祸和谶纬虽然已有特殊逻辑，但主要还是短句，尚未充分体现“朝堂如何理解这件事”。
- 计谋卡目前解释“数值层变化”还可以，但没有把这些变化编织成具体事件。

## 是否需要给谶纬、设局嫁祸呈现朝堂视角

建议：需要。

### 设局嫁祸

设局嫁祸至少需要两层呈现：

1. 被施计对象的即时反应：他如何失言、失态、失措。
2. 朝堂视角：旁人或上层权力如何把这个破绽理解成嫌疑。

如果只写目标“露了口风”，玩家能理解目标中计，但不一定理解为什么皇帝恩宠、太后眷顾、派系值或国力会变化。

### 谶纬

谶纬更需要朝堂视角。

谶纬不是普通私下说服，而是把灾异、征兆、天命、名分拿来制造政治解释。因此它天然应该有“传播后的第二视角”：

- 若目标是朝堂人物，应呈现皇帝、太后、帝党、后党如何借题审视此人。
- 若目标是地方军头，应呈现中枢如何因此起疑，并进一步收紧粮道、军需、甲械、御史、监军。

当前计谋回报页已有“谶纬余音”机制，但结算页还可以进一步把它并入天道卷轴或计谋筹算卡，让玩家看到这段谶纬如何从话术变成朝政动作。
