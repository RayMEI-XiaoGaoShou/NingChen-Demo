# 回合结算页可解释性优化建议

## 总体目标

回合结算页下一步优化的核心目标不是增加更多数值，而是让玩家清楚理解：

> 我刚才施的计，究竟通过什么人、什么朝政动作、什么中间环节，变成了眼前这些数值变化。

理想链路应当是：

> 玩家施计 -> 施计对象反馈 -> 追问或余音补充 -> 天道卷轴阐述实际发生的事 -> 计谋筹算卡展示成败与关键数值 -> 大局推演汇总本回合大势。

## 一、天道结算卷轴的优化建议

### 当前问题

当前天道卷轴主要基于摘要生成，容易写成“局势有变、暗流涌动、朝堂生隙”这类气氛句。

这些句子有沉浸感，但玩家未必能看懂：

- 谁做了什么。
- 哪个 NPC 被谁影响。
- 哪个权力动作导致哪个数值变化。
- 地方军头为什么军力下降或忠诚下降。
- 朝堂角色为什么皇帝恩宠或太后眷顾下降。

### 建议定位

建议把天道卷轴定位为“本回合因果落地叙事”。

它不需要罗列所有数值，但应该把本回合最关键的 1 到 3 条计谋结果写成具体事件。

### 建议输入材料

建议新增一个结算叙事上下文，至少包含：

| 信息 | 用途 |
| --- | --- |
| 施计对象 | 知道是谁被玩家说动或没说动 |
| 计谋类型 | 决定事件表达方式 |
| 相关对象 | 谗言、离间、借刀、谶纬、设局嫁祸需要知道被牵连者是谁 |
| 玩家原始输入 | 保留玩家参与感 |
| NPC 初次回应摘要 | 承接计谋回报页 |
| 玩家追问与 NPC 最终回批 | 若发生追问，应进入天道卷轴 |
| 谶纬余音 | 若发生谶纬，应作为“朝堂视角”进入 |
| 具体数值变化 | 不直接展示数值，但用来决定叙事重点 |
| 结构变化 | 如皇帝恩宠、太后眷顾、派系值、地方军头忠诚/军力/信任 |
| 国力五维变化 | 用来把事件落到财政、粮赋、军事、社会秩序、治理穿透力 |

### 建议输出规则

天道卷轴可以改成 220 到 320 字左右，要求如下：

- 不直接罗列数值。
- 每条成功计谋至少说明“谁被说动 -> 转化成什么动作 -> 谁受影响”。
- 若计谋失败，应说明“为什么没落地”或“是否留下反噬”。
- 若涉及地方军头，应解释粮饷、甲械、军需、监军、边镇怨气等中间环节。
- 若涉及朝堂人物，应解释御前/帘前态度、上书、谏言、查账、收诏、派系攻讦等中间环节。
- 若涉及谶纬，应解释“征兆如何被解释为政治疑心”。
- 若涉及设局嫁祸，应解释“目标露出何种破绽，朝堂如何理解这道破绽”。

### 示例

玩家对祖廷施离间，离间对象是贺拔伯圭，计谋成功。

理想天道卷轴可以写成：

> 祖廷受萧宝颖离间之言所动，转而向帘前进言，称陇右勋贵跋扈难制，尤以贺拔伯圭为甚。太后虽未明言疑之，却借核查军需之名收紧西线粮饷。贺拔伯圭表面奉诏，心中却与中枢更疏了一层；西线兵势未崩，粮道与人心已先被削薄。

玩家从这段能直接理解：

- 祖廷被说动了。
- 祖廷影响了太后。
- 太后削减或核查了贺拔伯圭资源。
- 贺拔伯圭军力、忠诚度下降。
- 北周粮赋、军事或治理受到影响。

## 二、计谋筹算结果的优化建议

### 当前问题

当前计谋筹算卡已经有“短反馈 + 国力影响 + 朝堂政局 + 数值标签”，但短反馈偏通用，具体事件性不足。

例如：

> 祖廷略作沉吟，显然已被你的献策拨动了算盘。

这类文案能表达成败，却无法告诉玩家“祖廷之后做了什么”。

### 建议定位

建议计谋筹算结果继续保持短，不要变成第二个天道卷轴。

它更适合承担三件事：

1. 显示成败。
2. 用一句短反馈表达目标反应。
3. 用“国力影响 / 朝堂政局 / 数值标签”说明该计谋撬动了哪一层。

真正的“故事落地”，建议交给天道卷轴。

### 建议增强点

可以针对不同计谋逐步增加更有差异的短反馈：

| 计谋 | 短反馈应该强调 |
| --- | --- |
| 试探 | 目标多露半层口风，或拒绝交底 |
| 献策 | 目标觉得这主意对自己有利，但可能暗损北周整体 |
| 谗言 | 目标对相关对象疑心加重 |
| 离间 | 两者旧裂被重新撕开 |
| 设局嫁祸 | 目标失言、失态、失措，嫌疑回落自身 |
| 借刀 | 实权人物愿意收网、罢黜、处决或继续观望 |
| 求援 | 目标愿意给玩家留后路，或拒绝卷入 |
| 谶纬 | 目标急于自辩，或朝堂开始借征兆生疑 |
| 煽动割据 | 地方军头觉得坐大比继续受制更有利 |
| 煽动造反 | 地方军头被推向公开反叛或被平叛反噬 |

## 三、谶纬与设局嫁祸是否需要朝堂视角

### 结论

需要，而且这两类计谋最应该补“朝堂视角”。

### 设局嫁祸

设局嫁祸的第一视角是目标本人：

- 他被诱导。
- 他失言、失态、失措。
- 他意识到自己踩进局里。

但它的数值影响通常不是由“他说错一句话”直接产生，而是由朝堂如何理解这句话产生。

因此结算页最好补第二层：

- 御前或帘前如何看待这道破绽。
- 派系如何借题攻讦。
- 目标的皇帝恩宠或太后眷顾为何下降。
- 若牵涉地方军头，中枢为何因此收紧资源。

### 谶纬

谶纬更天然需要第二视角。

谶纬不是私下劝说，而是“把灾异/征兆解释成政治方向”。所以它的关键不是目标本人信不信，而是朝堂中谁拿它当理由，准备如何行动。

建议结算页形成三层呈现：

1. 目标即时反应：目标惶恐、自辩、愤怒、压谣或反咬。
2. 谶纬余音：由另一位朝堂人物或中枢代表给出解释。
3. 天道卷轴：总结这段解释如何转化为诏令、查账、军需、监军、削饷、派系攻讦或名分压力。

如果目标是地方军头，尤其要写清楚：

- 朝堂因谶纬起疑。
- 中枢收紧粮饷、甲械、军需、监军。
- 地方军头军力小降。
- 地方军头忠诚度更明显下降。

## 四、大局推演是否要呈现地方军头和朝堂势力数值变化

### 结论

建议呈现，但不要做成全量流水账。

现在结算页已经在计谋筹算卡里显示了单条计谋的数值标签，也在大局推演里显示北周/南陈综合国力雷达图。如果大局推演再把所有 NPC、所有派系、所有数值完整列出，玩家会被信息淹没。

更适合的方案是：

> 默认展示“本回合关键变化”，只呈现变化明显或达到阈值的地方军头、朝堂势力、角色处置状态。

### 地方军头建议呈现规则

建议在大局推演中新增或折叠一个“地方军头动向”板块。

只在以下情况出现：

- 地方军头忠诚度发生明显变化。
- 地方军头军力发生明显变化。
- 地方军头信任度发生明显变化。
- 地方军头进入已割据、已造反、被平叛等状态。
- 谶纬、设局嫁祸、离间、煽动割据、煽动造反等计谋影响了地方军头。

推荐呈现格式：

> 贺拔伯圭：忠诚 -8，军力 -3。原因：朝中借谶纬起疑，收紧西线粮饷与军需，他手中兵势受损，对中枢怨气更深。

不要只写：

> 贺拔伯圭 忠诚 -8，军力 -3。

因为后者仍然没有解决可解释性。

### 朝堂势力建议呈现规则

建议在大局推演中新增或折叠一个“朝堂势力消长”板块。

只在以下情况出现：

- 帝党或后党任一派系值发生明显变化。
- 派系出现裂口或崩盘。
- 借刀导致罢黜、处决、施压。
- 某角色皇帝恩宠/太后眷顾进入可罢黜或可处决阈值。

推荐呈现格式：

> 后党：朝堂影响 -2.1，内部稳定 -1.4。原因：祖廷借帘前进言压制陇右，短期稳住太后权柄，却使后党内部对西线调度更难达成一致。

### 不建议常驻展示的内容

以下内容不建议在大局推演里常驻全量展示：

- 所有 NPC 的信任值明细。
- 所有朝堂角色的皇帝恩宠、太后眷顾明细。
- 所有派系的完整三维数值表。
- 没有变化的地方军头数值。

这些内容更适合留在朝堂页、角色卡、debug 或策划调试界面。

## 五、推荐的信息层级

建议回合结算页形成以下层级：

1. 天道结算卷轴：讲本回合 1 到 3 条最关键因果事件。
2. 计谋筹算结果：逐条显示成败、短反馈、国力影响、朝堂政局、数值标签。
3. 大局推演：显示南陈相对北周、自身安危、南征风向、战役记录、国力雷达图。
4. 关键变化摘要：只在有变化时显示地方军头动向、朝堂势力消长、朝堂收网、关系链失衡、外部势力明牌、朝局反噬、问政余波。

这样玩家阅读路径会比较自然：

- 先看故事上发生了什么。
- 再看每条计谋成败。
- 再看数值总局。
- 最后看关键细账。

## 六、建议实施优先级

### P0：天道卷轴接入因果事件链

这是最能提升结算页可解释性的改动。

目标是让天道卷轴能写出“祖廷进言、太后削饷、贺拔伯圭离心”这类具体事件。

### P1：把计谋回报页内容接进天道上下文

包括：

- NPC 初次 AI 回复摘要。
- 追问后的最终回批。
- 谶纬余音。

这样能让玩家感觉前一页发生的对话真的被后一页承接了。

### P1：谶纬与设局嫁祸补朝堂视角

建议先做谶纬，因为它是特色玩法，而且天然需要“余音 / 传播 / 中枢动作”。

设局嫁祸可以随后补“嫌疑如何被朝堂接收”。

### P2：大局推演增加关键变化摘要

不要做全量数值表，先做变化驱动的摘要：

- 地方军头动向。
- 朝堂势力消长。
- 关键角色恩宠/眷顾阈值变化。

### P3：计谋筹算短反馈进一步差异化

这是体验优化，但优先级低于天道卷轴因果链。因为短反馈不适合承载全部解释，真正的解释主战场应当是天道卷轴和大局推演。
