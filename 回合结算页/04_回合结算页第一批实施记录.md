# 回合结算页第一批实施记录

## 本批改动范围

本批按照此前建议优先级，先落地 P0 到 P2 中风险较低、收益较明显的部分：

1. 天道结算卷轴接入“计谋落地链”。
2. 计谋回报页中的 NPC 回复、追问回应、谶纬余音进入天道判官上下文。
3. 大局推演后新增“关键变化”板块，用于解释地方军头、朝臣处境、朝堂势力的显著变化。

本批没有改动底层成功率、数值结算公式、战役公式或 AI 调用次数。

## 1. 天道结算卷轴

新增本地派生的“计谋落地链”，每条计谋会汇总：

- 施计对象。
- 计谋类型。
- 相关对象。
- 玩家说辞。
- 计谋成功或失败。
- 计谋如何转成朝政动作。
- NPC 回报页的回复摘要。
- 追问后的最终回批。
- 谶纬余音。
- 本回合直接产生的关键数值后果。
- “国力影响 / 朝堂政局”的解释摘要。

这些内容会进入天道判官 prompt，帮助天道卷轴从“泛泛判辞”转向“具体因果落地叙事”。

## 2. 天道判官 prompt 调整

天道判官 system prompt 已从“150 字以内的局势概括”调整为“180 到 320 字左右的因果叙事”。

新的写作重点是：

- 写清楚萧宝颖施了什么计。
- 谁被说动、被挑疑、被诱导或露出破绽。
- 这件事如何转成朝政动作。
- 谁因此受损。
- 用具体事件解释数值变化，而不是直接罗列数值。

## 3. 关键变化板块

结算页“大局推演”后新增“关键变化”板块。

它不是全量数值表，而是只在出现明显变化时展示：

- 地方军头的信任、忠诚、军力、状态变化。
- 朝臣的皇帝恩宠、太后眷顾、罢黜/处决状态变化。
- 帝党/后党的朝堂影响、内部稳定、军事实力变化。

外部势力明牌、朝堂收网、关系链失衡、派系裂口等已有独立板块，本批没有把它们重复塞进“关键变化”，避免结算页重复展示同一件事。

这样玩家能更直观看到“本回合真正发生了哪些关键变化”，但不会被所有角色的完整数值表淹没。

## 4. 对谶纬与设局嫁祸的影响

谶纬现在更容易被天道卷轴承接：

- 如果计谋回报页生成了谶纬余音，余音会进入天道判官上下文。
- 如果目标是地方军头，落地链会强调粮道、军需、监军、忠诚和军力之间的因果。

设局嫁祸也会进入落地链：

- 重点说明目标如何失言、失态或露破绽。
- 天道卷轴可以据此写出朝堂如何接收这道嫌疑。
