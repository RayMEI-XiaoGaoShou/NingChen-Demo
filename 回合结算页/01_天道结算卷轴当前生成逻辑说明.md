# 天道结算卷轴当前生成逻辑说明

## 一句话结论

当前“天道结算”卷轴确实会调用 DeepSeek 生成，但它吃到的上下文主要是“本回合结算后的结构化摘要”，不是完整的“施计页输入 -> 计谋回报页 NPC 反应 -> 追问回应 -> 具体数值变化原因”的全链路材料。

因此，它现在更像“回合局势判辞”，还不是理想中的“把每条计谋如何落地为具体朝政动作讲清楚的天道史官”。

## 当前触发时机

进入回合结算页时，结算页组件会根据 `lastSettlement` 生成顶部卷轴。

当前逻辑大致分三种情况：

1. 如果没有本回合结算结果，就显示兜底文案：“结算文书正在整理，请稍候。”
2. 如果有结算结果但没有 `judgeFacts`，就直接使用本地 `summaryText` 作为卷轴内容。
3. 如果有完整 `judgeFacts`，就调用 DeepSeek，通过 `buildJudgePrompt` 生成“天道结算”文案。

DeepSeek 调用参数目前是：

- `temperature: 0.9`
- `maxTokens: 300`
- `tag: judge`

如果 DeepSeek 调用失败，会回退到本地摘要：

> 本回合 X 次计谋中 Y 次奏效。外部势力如何变化。北周综合国力上升/下降，南陈综合国力上升/下降。

## 当前 system prompt

天道卷轴使用的 system prompt 核心要求如下：

- 角色是《佞臣》中的“天道判官”。
- 负责把每回合朝堂结算写成一段古典白话叙事。
- 不超过 150 字。
- 只能依据输入事实概括，不得虚构未提供的人物、事件与后果。
- 第三人称叙事，主角一律称“萧宝颖”。
- 不直接罗列数值，要用局势与气氛表达变化。
- 直接输出正文，不加标题、引号或列表。

这个 prompt 的优点是稳，不容易胡编；缺点是篇幅偏短，并且“不得虚构”会让它更倾向于概括，而不是把计谋结果展开成一个具体事件。

## 当前 user context

进入天道判官的 user prompt 里，主要包含这些字段：

| 字段 | 当前内容 | 说明 |
| --- | --- | --- |
| 回合与事件 | 第几回合、事件名 | 来自当前回合事件 |
| 主线局势 | `eventImpactSummary` | 当前回合大事件和简报 |
| 计谋结果 | 每条计谋的对象、计谋类型、成功/失败、玩家说辞、默认反馈 | 注意这里的“对方反应”不是计谋回报页的 AI NPC 长回复，而是结算引擎里的短模板反馈 |
| 信任变化 | 本回合各 NPC 对玩家信任值变化 | 以“祖廷 +5”这类摘要形式进入 |
| 党争局面 | 帝党/后党/派系数值变化摘要 | 含朝堂影响、稳定、军权变化，以及关系链/派系裂口摘要 |
| 关系结构 | NPC-NPC 关系链变化摘要 | 如果本回合没有关键变化则为空 |
| 外部军头 | 割据/造反等外部明牌动作摘要 | 没有明牌时显示观望试价类文案 |
| 北周变化 | 北周五维变化摘要 | 财政、粮赋、军事、民生秩序、治理穿透力 |
| 南陈回批 | 南陈问政结果摘要 | 有问政则说明选项和效果；无问政则说明无额外收益 |
| 南征态势 | 南征窗口/压力/可战条件摘要 | 用于描述大势 |
| 综合国力 | 当前北周综合国力数值 | 只给最终综合国力，不给完整变化链 |

## 施计页与计谋回报页的信息是否进入卷轴

### 已进入的部分

- 玩家在施计页输入的 `playerSpeech` 会进入天道 prompt。
- 玩家选的施计对象、计谋类型、成功/失败会进入 prompt。
- 结算引擎生成的短反馈 `feedbackText` 会进入 prompt。
- 本回合结算后的信任、派系、国力、关系、外部势力摘要会进入 prompt。

### 尚未充分进入的部分

- 计谋回报页中北周 NPC 的完整 AI 回复，目前没有作为核心材料进入天道卷轴。
- 追问玩法里的“玩家追问”和“NPC 最终回批”，目前没有被天道卷轴充分承接。
- 谶纬玩法中的“余音 / 谶纬回响”，目前主要呈现在计谋回报页，并没有稳定进入天道卷轴。
- 每条计谋具体造成了哪些“中间事件”，例如“祖廷向太后进言”“太后削减贺拔伯圭粮饷”“贺拔伯圭忠诚下降”，当前没有一个专门的因果事实数组喂给天道判官。

## 当前 judgeFacts 的来源

`judgeFacts` 是结算系统在本回合结算完成后生成的一组结构化事实，主要来自以下计算结果：

- 回合主线事件。
- 帝党/后党的朝堂影响、内部稳定、军事实力变化。
- NPC-NPC 关系链报告。
- 地方军头割据/造反等外部明牌报告。
- 北周五维变化。
- 南陈问政选择和问政余波。
- 南征风向、自身安危、战役状态。
- AI Native 结算提示，例如某步说辞是否贴住人物心绪、是否穿透权力链条。

它的优点是覆盖面广；缺点是偏“摘要型事实”，还没有形成“每条计谋的可解释性事件链”。

## 当前天道卷轴的能力边界

当前卷轴能做到：

- 把本回合大势写成一段较有气氛的判辞。
- 提到本回合谁的计谋成功或失败。
- 间接吸收国力、党争、外部势力、南陈问政等变化。

当前卷轴不擅长：

- 明确解释“某个数值为什么变了”。
- 承接计谋回报页中 NPC 说过的具体话。
- 把玩家的计谋落地为具体朝政动作。
- 对谶纬、设局嫁祸这类需要“旁观者视角 / 朝堂传播链”的计谋做充分展开。

## 理想优化方向

理想中的天道卷轴应该从“回合判辞”升级为“本回合因果落地叙事”。

建议新增一个专门的 `schemeCausalEvents` 或类似结构，让每条计谋在结算后生成一条可供天道判官使用的事实链：

| 字段 | 示例 |
| --- | --- |
| 施计对象 | 祖廷 |
| 计谋类型 | 离间 |
| 被牵连对象 | 贺拔伯圭 |
| 玩家说辞 | 指出贺拔伯圭跋扈、陇右勋贵难制 |
| NPC 初次反应 | 祖廷听后顺势接话，认为陇右勋贵不可不压 |
| 追问/最终回批 | 如有，则记录玩家补充和 NPC 最终态度 |
| 实际朝政动作 | 祖廷向太后进言，建议压制陇右勋贵 |
| 数值结果 | 贺拔伯圭忠诚下降、军力下降；后党朝堂影响变化；北周粮赋/治理受损 |
| 玩家可见解释 | 太后削减本该拨给贺拔伯圭的粮饷，贺拔伯圭与中枢关系疏离 |

这样天道卷轴就可以写出类似：

> 祖廷受萧宝颖离间之言所动，转而向帘前进言，称陇右勋贵跋扈难制，尤以贺拔伯圭为甚。太后遂借查军需之名收紧粮饷，贺拔伯圭虽未明叛，却已对中枢多了一层怨气。

这类文本能够明确告诉玩家：

- 我刚才的计谋为什么有效。
- 谁被说动了。
- 他转身做了什么。
- 哪个 NPC 或派系受了影响。
- 为什么最终反映为军力、忠诚度、派系值或国力五维变化。

## 建议优先级

1. 先让天道 prompt 接入每条计谋的“因果事件链”，解决可解释性问题。
2. 再把计谋回报页的 AI NPC 回复、追问回应、谶纬余音接进卷轴上下文。
3. 最后调整卷轴长度限制，从当前不超过 150 字，放宽到约 220 到 320 字，确保有空间讲清楚因果。
