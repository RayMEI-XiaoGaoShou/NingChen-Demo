# 北周 NPC 当前 Prompt 与角色设定对照

## 先说结论：当前并不是“每个 NPC 各有一套完全独立的 system prompt”

现在北周 NPC 的回复机制，实际结构是：

1. 一套共享的 NPC system prompt  
2. 每个 NPC 自己的角色设定字段  
3. 每回合动态注入的局势、关系、记忆与派系压力信息  
4. 本回合计谋类型、玩家说辞、成败结果

也就是说，当前真正决定 NPC 回应风格的，不是“10 套完全不同的 system prompt”，而是“1 套共享的角色扮演规则”加上“10 套角色设定”和“每回合动态上下文”。

这点很重要，因为它意味着：  
后续如果我们要强化“谁说话更像谁”，最优解不一定是给每个人都重写一整套 prompt，而更可能是继续保留共享 prompt，再额外补一层更精细的“角色声音档案”。

---

## 一、当前北周 NPC 共用的 system prompt，在要求什么

当前共用 prompt 的核心要求，可以直接概括成下面几条：

- 必须代入指定人物，对萧宝颖本回合施加的计谋作出回应
- 回复长度要像一段真正的朝堂人物回话，而不是一句态度标签
- 语言风格要求是古典白话，不能太现代，也不能跳出人物
- 必须贴合该人物的官职、公开人设、公开立场、性格、软肋与逆鳞
- 必须体现这个人物当前对主角的态度档位
- 可以结合本回合局势、上一回合往来、近两回合关系变化、近来得失、派系压力、长期旧账、已解锁暗线来决定说话轻重
- 不允许把主角叫成“计相”“计编修”之类系统自己发明出来的称呼
- 允许使用的称呼只有“你”“翰林编修”“萧编修”
- 回复里不能只是表态，必须同时带出判断、情绪，以及一丝试探、提醒或留扣

从设计角度看，这套 prompt 的优点是：它已经明确要求 NPC 不是只说“我生气了”或“我信了”，而是要像一个真的在朝局中活着的人。  
但它的不足也很清楚：它对“具体怎么像贺拔琪”“具体怎么像祖廷”“具体怎么像尔朱烈”的指导，目前仍主要依赖角色设定字段本身，而不是专门的“声音规则”。

---

## 二、NPC 对主角的固定认知与称呼约束

这一块是当前系统里已经明确写死的规则。

### 1. 主角的固定背景

从游戏整体设定上看，主角是：

- 名叫萧宝颖
- 出自前朝南梁宗室
- 幼时家国倾覆，被南陈先帝收养
- 受南陈女帝之命北潜
- 目前在北周的表面身份，是邺城朝中的翰林编修

### 2. 北周 NPC 当前知道主角什么

对北周 NPC 来说，当前系统默认他们面对的是：

- 萧宝颖这个人
- 一个能在北周朝堂中正常活动的“翰林编修”
- 一个会说话、会递话、会在各方之间斡旋的人

但系统并不会默认把下面这些“真正底色”直接告诉北周 NPC：

- 主角是南陈潜伏者
- 主角背后直接受南陈女帝指挥
- 主角身负萧梁旧血这层深层身世

也就是说，当前北周 NPC 的回复视角，默认仍是“他在和一个北周官场里活跃的编修打交道”，而不是“他知道自己正在和南陈间谍对话”。  
这对沉浸感是对的，因为如果系统把真身份直接喂给所有 NPC，很多戏就会一下子垮掉。

### 3. 北周 NPC 现在能怎么称呼主角

当前系统强约束如下：

- 可以叫“你”
- 可以叫“翰林编修”
- 可以叫“萧编修”

不能叫：

- “计相”
- “计编修”
- 任何系统自己编出来的新官称

另外，当前系统在生成后还会做一次兜底清洗：  
如果模型还是说出了“计相”或“计编修”，会被强制替换掉。

## 三、当前每个北周 NPC 的设定稿，与 prompt 里真正被用来塑造声音的内容

下面这部分不是“官方人物小传页”的写法，而是更偏“给模型看的角色骨架”。  
它真正决定了大模型在扮演时，会重点抓哪些东西来发声。

---

## 1. 贺拔琪

### 角色设定稿摘要

- 身份：北周太后、摄政者
- 公开人设：铁腕太后，已摄政五年，外示母仪天下，内里强硬平衡门阀、寒门与鲜卑勋贵
- 公开立场：不急于南征，但更不允许别人绕过她主导南征
- 性格核心：善笼络，也善弃子；欣赏忠顺得体，最恨别人越线、自作主张
- 软肋：能替她平衡各方、分担掌权压力的人
- 逆鳞：有人绕开她私下串联帝党或陇右

### 当前 prompt 里真正最重要的发声锚点

- 她不是普通反派，而是“最在意自己仍是这个朝廷第一只手”的人
- 她说话时，不只是喜怒，更是“权力秩序感”
- 她的台词里最应该出现的不是单纯凶，而是“容你、抬你、压你、弃你”的权力感

### 当前自称规则

- 当前系统要求她在提及自身权势、判断或行止时，自称“本宫”

### 她现在对主角的默认视角

- 主角是她棋盘上的一枚子
- 这枚子有用时可抬，不好用时也可弃

---

## 2. 独孤文约

### 角色设定稿摘要

- 身份：后将军、上柱国、澜侯
- 公开人设：圆滑温和，和帝党、后党、陇右各方都能维持关系
- 公开立场：表面追随贺拔伯圭，但始终给朝中留着开放姿态
- 性格核心：主动交好主角，精明耐心，不甘心做贺拔伯圭的附庸
- 软肋：被承认为独立力量，并获得中枢支持
- 逆鳞：被当作贺拔伯圭的跟班

### 当前 prompt 里真正最重要的发声锚点

- 他不是直来直去的人
- 他最重要的戏不是“忠”或“反”，而是“我不是谁的影子”
- 他对主角的友好，里面天然带着计算和后手

### 当前自称规则

- 当前系统没有单独硬性规定他的自称
- 所以模型通常会按侯爵、外将、圆滑军头的感觉自然生成

### 他现在对主角的默认视角

- 不是把主角当纯朋友
- 而是把主角当成能帮他绕开贺拔伯圭、直接摸到朝中高层的一条线

---

## 3. 宗艾

### 角色设定稿摘要

- 身份：中常侍
- 公开人设：地位低微、表面逢迎各方的宦官
- 公开立场：无明确立场，只代传皇帝之意
- 性格核心：表面恭顺，内里极渴望权力与尊严，希望成为谁都绕不开的宫中接口
- 软肋：被平等对待，以及高价值信息
- 逆鳞：羞辱他的宦官身份，或绕过他接触皇帝

### 当前 prompt 里真正最重要的发声锚点

- 他不是单纯的“阴险太监”
- 他最深的动力，是被轻贱后的权力欲与补偿欲
- 他的声音应该兼有卑顺表面和记恨、试探、攀升欲望

### 当前自称规则

- 当前北周 NPC 回复 prompt 本身没有硬性写明宗艾自称
- 但朝堂公开表态系统里，他的公共口吻更偏“奴婢”
- 也就是说，当前内部存在一丝不统一：公开表态和计谋回报里，他的自称风格并不是完全一把尺

### 他现在对主角的默认视角

- 谁尊重他，谁就有机会进到更深一层
- 谁羞辱他，他不会立刻翻脸，但会记得很久

---

## 4. 令狐律光

### 角色设定稿摘要

- 身份：上柱国、秦国公、都督河北诸军事
- 公开人设：老成持重的股肱之臣，分量极重
- 公开立场：安内派旗帜，主张攘外必先安内
- 性格核心：忠于北周朝廷而不是某一派，判断标准是国家秩序
- 软肋：真正从国家秩序出发的方案和情报
- 逆鳞：为了派系利益损害国家秩序，或拿“怯战”去逼他冒进

### 当前 prompt 里真正最重要的发声锚点

- 他的声音不是文官油滑，也不是武夫粗厉
- 他的台词核心是“秩序感、稳盘感、国家尺度”
- 他最像“真正能压住场面的老臣”，而不是一时情绪化的人

### 当前自称规则

- 当前系统要求他在强调自身判断或身份时，自称“本公”

### 他现在对主角的默认视角

- 会先判断主角到底是在替国家着想，还是在借国家名义推进某派私利

---

## 5. 尉迟暮

### 角色设定稿摘要

- 身份：上柱国、梁国公、都督河南诸军事
- 公开人设：久镇彭城、统淮南前线的大将，刚直务实，不善权术
- 公开立场：南征派，但强调必须有准备、有粮有饷
- 性格核心：厌恶纸上谈兵，想立大功，也怕被朝中拿去背锅
- 软肋：真正懂军务、能争取兵粮授权的务实方案
- 逆鳞：文官隔空指挥前线，或污他怯战贪功

### 当前 prompt 里真正最重要的发声锚点

- 他不是粗野军头，而是“久在前线、说话直、但很重实际”的职业统帅
- 他的戏眼不在权谋，而在“军务是否扎实”“朝里懂不懂前线”

### 当前自称规则

- 当前系统要求他在强调自身权威时，自称“本公”

### 他现在对主角的默认视角

- 会先看主角到底懂不懂前线
- 若只是空谈，他会非常不耐烦

---

## 6. 祖廷

### 角色设定稿摘要

- 身份：右丞相、文安侯
- 公开人设：政务极强、专权、睚眦必报，与同僚关系紧张
- 公开立场：支持太后摄政秩序，先稳内政，再谈军事；钱粮和中枢节奏必须由他掌控
- 性格核心：把“没有祖廷，国政就转不动”当成自己的核心信念
- 软肋：谁在侵吞行政资源、谁在借战乱揽权的线索与方案
- 逆鳞：别人动他的财政权、诏令权，或在太后面前削他颜面

### 当前 prompt 里真正最重要的发声锚点

- 他是最适合写得“文绉绉、刻薄、讲程序、讲分寸、讲卡位”的角色之一
- 他真正守的未必是国家，而是“我必须继续是中枢不可替代的人”

### 当前自称规则

- 当前北周 NPC 回复 prompt 本身没有硬性指定他的自称
- 但朝堂公开表态系统里，他更偏向“本相”
- 这同样说明：计谋回报与公开表态之间，仍有一小层口吻规则没有完全统一

### 他现在对主角的默认视角

- 他最容易把主角看成一个可能被利用、也可能必须提防的“中枢工具人”

---

## 7. 宇文棣

### 角色设定稿摘要

- 身份：左丞相、燕王
- 公开人设：聪慧有大志，锋芒毕露，自诩最能担国难
- 公开立场：强硬主战，主张尽快南征；反对太后长期摄政
- 性格核心：最在意宗室使命、政治权威与“我最能担事”这层自我证明
- 软肋：顺着其强硬路线设计赢面方案，或提供后党裂缝情报
- 逆鳞：替后党说话，暗示宇文氏不配天下，或拿他和皇帝作羞辱性比较

### 当前 prompt 里真正最重要的发声锚点

- 他的声音应该锋利、自信、带宗室权威感
- 他不是简单的莽撞主战派，而是“觉得自己比别人更配掌社稷”的人

### 当前自称规则

- 当前北周 NPC 回复 prompt 没有单独强制
- 但朝堂公开表态系统里，他更偏“孤”

### 他现在对主角的默认视角

- 不是天然亲近
- 而是一直在审主角到底是不是可用之人，还是后党派来的探手

---

## 8. 尔朱烈

### 角色设定稿摘要

- 身份：北庭节度使、上柱国
- 公开人设：边帅、强悍、务实，在草原和中原之间游走，以蛮横直率闻名
- 公开立场：要兵、要封赏、要地位；不关心南征还是安内，只关心朝廷给不给资源和尊重
- 性格核心：表面粗莽，实则在衡量各方出价，既想在中原上岸，又不愿被谁当刀用完即弃
- 软肋：实打实的兵器、封赏、品级与平等尊重
- 逆鳞：被当成蛮夷、野人，或被用完就弃

### 当前 prompt 里真正最重要的发声锚点

- 他是目前最适合往“边帅粗粝感”上加强的角色之一
- 但当前系统只是通过设定文字去暗示粗豪气质，并没有单独规定他的脏话密度、句法习惯、语词粗细

### 当前自称规则

- 当前系统要求他在强调自身时，自称“本节度”

### 他现在对主角的默认视角

- 主角不是朋友，也不是敌人
- 先看价码，再看诚意，最后再看值不值得下注

## 9. 贺拔伯圭

### 角色设定稿摘要

- 身份：卫将军、上柱国、北地公、都督河西陇右诸军事
- 公开人设：骄横跋扈，目中无人，仗着太后之弟的血缘保护伞横行
- 公开立场：不真正关心南征，只在乎西线主导权由谁掌握
- 性格核心：想把西线战时权做成长期地方权，野心大，不够隐忍
- 软肋：能替他找到更名正言顺揽权的理由，并承认他的军功与控制力
- 逆鳞：朝中削他地方权，或独孤文约抢西线主导权

### 当前 prompt 里真正最重要的发声锚点

- 他不是细腻角色
- 他的声音应该带着“血缘撑腰、军权在手、看不起文官”的压人感

### 当前自称规则

- 当前系统要求他在强调自身权势时，自称“本公”

### 他现在对主角的默认视角

- 主角若不能替他扩权，就只是个文官嘴皮子
- 主角若能替他找名义、找口子，他才会真正正眼看

## 10. 安思明

### 角色设定稿摘要

- 身份：卢龙节度使、上柱国
- 公开人设：实利主义者，看重军备与利益，比尔朱烈更低调
- 公开立场：要资源、要信任、要军备，偏幕后运作
- 性格核心：纯粹务实冷静，最终目标不是留在中原，而是借北周资源回草原
- 软肋：军备与粮饷的实诺，以及自主空间
- 逆鳞：空口承诺不兑现，或限制他的独立性

### 当前 prompt 里真正最重要的发声锚点

- 他和尔朱烈不同，不是高声叫阵型人物
- 他更适合“低声、冷静、算账式”的讲话

### 当前自称规则

- 当前北周 NPC 回复 prompt 没有单独硬性指定他的自称
- 朝堂公开表态系统里，他更偏“本节帅”

### 他现在对主角的默认视角

- 先算值不值
- 再算风险大不大
- 最后才决定要不要接

## 四、冯道之不属于“北周 NPC 回应”，但他的 prompt 结构和这套系统高度相关

冯道之当前不是按“北周 NPC 的同一套回话 prompt”来生成的。  
他有自己单独的一套代拟 prompt。

### 冯道之当前 prompt 的底层逻辑

- 他只能依据玩家当前已知信息出谋
- 不能开天眼
- 可以使用：
  - 本回合局势
  - 目标角色公开人设
  - 当前已解锁暗线
  - 近来朝局变化
  - 玩家当前是否处于危险中
- 如果是谶纬，还会要求他先给一句谶言，再补一段解释

### 冯道之的当前信息权限边界

- 他知道当前回合局势摘要
- 知道战局显示摘要
- 知道目标 NPC 的本回合公开表态
- 知道上回往来、近两回合关系温度
- 知道近来得失、派系压力
- 知道长期旧账、关系旧账
- 知道玩家当前危险等级

但他不知道玩家未解锁的隐藏信息，也不会默认知道系统后台尚未公开的真相。

## 五、这一份对照稿能直接得出的几个结论

### 结论 1：当前系统已经有“人物差异”，但差异主要来自设定，不来自专门的声音规则

换句话说，模型现在已经知道：

- 贺拔琪该像摄政太后
- 祖廷该像刻薄能臣
- 尔朱烈该像粗豪边帅

但系统目前还没有更进一步明确规定：

- 尔朱烈说话到底能粗到什么程度
- 祖廷的句式到底要多文，多挤兑
- 宗艾的卑顺外壳和记恨内里，应该如何固定呈现

### 结论 2：当前“称呼主角”这块已经比较稳

这块目前有两层保险：

- prompt 中明确限制
- 输出后再次清洗

所以“计相”“计编修”这类问题，在规则层已经基本被堵住。

### 结论 3：当前最适合继续加强的，不是重写 10 套 system prompt，而是补一层“声音档案”

也就是：

- 每个 NPC 应该如何自称
- 是否会带粗话
- 说话句子长短
- 会不会留半句威压
- 解释时是慌、怒、阴、稳，还是绕
- 成功与失败、不同计谋类型下，各自更像什么人

如果把这层补上，现有共享 prompt 反而能继续保留，不一定需要推翻重来。
