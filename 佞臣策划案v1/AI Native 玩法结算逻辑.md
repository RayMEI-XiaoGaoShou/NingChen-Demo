# 《佞臣》AI Native 玩法结算逻辑

> 本文档用于追认当前 Demo 中，玩家文本输入如何实际影响北周施计与南陈问政的结算结果。

---

## 1. 总原则

当前版本的 AI Native 不是“纯氛围文本”，而是会真实参与规则结算。

- 北周施计：玩家补的一句说辞，会影响计谋成功率，也会影响人物层、势力层、综合国力层的效果强度。
- 南陈问政：玩家写下的附言，会影响本回合问政收益倍率，也会影响法统余势与下一回合的政策余波。

当前版本仍以“规则评分 + 关键词/结构词命中”为主，不是完全开放式的大模型深语义判定。

---

## 2. 北周施计：总体结算链

北周施计统一按如下顺序生效：

1. 判断基础成功率
2. 读取玩家说辞，计算 `speechScore`
3. 用 `speechScore` 修正成功率
4. 若成功，则先结算人物层变化
5. 人物层变化再传导到势力层
6. 势力层变化再折算到北周五维与综合国力
7. 若命中战时/掌兵场景，还会触发额外军事外溢

简写为：

`玩家说辞 -> 成功率 -> 人物层 -> 势力层 -> 国力层`

---

## 3. 北周施计：说辞评分规则

### 3.1 speechScore 范围

- 最低：`-0.65`
- 最高：`0.72`

### 3.2 评分来源

#### 基础长度分

- 有输入：`+0.08`
- 长度 `>= 10`：`+0.10`
- 长度 `>= 22`：再 `+0.10`
- 长度 `>= 40`：再 `+0.08`
- 长度 `> 90`：`-0.05`

#### 命中目标人物正向关键词

若说辞命中以下字段提取出的关键词之一：

- `softSpot`
- `publicStance`
- `schemeHooks`
- `publicPersona`

则：`+0.30`

#### 命中目标人物逆鳞关键词

若说辞命中目标人物 `triggerPoint` 相关关键词：

- `-0.45`

#### 命中结构性语汇

若说辞包含如下类型词语之一：

- 粮、饷、边患、诏令、兵权、门阀、流民、西线、草原、归政、寿春、河北、中枢、节度、仓廪

则：`+0.12`

---

## 4. 北周施计：说辞对成功率的影响

最终成功率修正公式：

`最终成功率 = 基础成功率 + speechScore * 0.22`

因此：

- 最佳说辞可带来约 `+15.8%` 的成功率提升
- 最差说辞可带来约 `-14.3%` 的成功率惩罚

这意味着玩家文本输入会直接影响“计谋成不成”。

---

## 5. 北周施计：说辞对人物层的影响

### 5.1 成功时

若施计成功，人物层变化乘数为：

`1 + max(0, speechScore) * 1.05`

上限约为：

- `1.756x`

也就是说，一个很强的说辞，能把原本的人物层收益放大到约 1.76 倍。

人物层主要包括：

- 目标 NPC 对主角的信任变化
- 关联 NPC 的信任变化
- 外部人物的忠诚变化
- 外部人物的倾向偏移
- 暗线解锁增量

### 5.2 失败时

若施计失败，则失败惩罚乘数为：

`1 + max(0, -speechScore) * 0.55`

上限约为：

- `1.3575x`

即：说辞越踩雷，失败后的反噬越重。

---

## 6. 北周施计：说辞对势力层的影响

若施计成功，势力层变化乘数为：

`1 + max(0, speechScore) * 1.25`

上限约为：

- `1.90x`

势力层变化包括：

- 朝堂影响力 `courtInfluence`
- 内部稳定度 `internalStability`
- 军事实力 `militaryPower`

因此，说辞强时，不只是“此人更信你”，而是会把该人物背后的朝堂派系与政治结构变化一起放大。

---

## 7. 北周施计：说辞对综合国力层的影响

势力层变化不会停在派系数值，而会继续折算到北周五维：

- 财政 `finance`
- 粮赋 `grain`
- 军事 `military`
- 社会秩序 `socialOrder`
- 统治穿透力 `governance`

### 7.1 常规传导

势力层变化会按内置公式折算到五维，例如：

- 朝堂影响力越乱，越伤 `governance / socialOrder`
- 军事实力越受损，越伤 `military / grain`
- 内部稳定度越差，越伤 `finance / governance / socialOrder`

### 7.2 外部人物传导

若目标是外部人物，则其忠诚下降还会额外按军力折算成国力打击。

军力越高，影响越重。

### 7.3 军事外溢

在以下条件同时满足时，会触发额外军事链外溢：

- 计谋类型为：`离间 / 放风构陷 / 谗言 / 献策`
- 当前是支持军事外溢的回合
- 目标或关联角色属于掌兵人物
- 若是 `献策`，说辞中还需明显包含军务/粮道/兵权/边镇相关语言

此时会额外伤害：

- `military`
- `grain`
- `governance`
- 部分情况还会伤 `socialOrder`

---

## 8. 北周施计：高阶动作的文本影响

### 8.1 煽动割据

满足门槛后，成功会产生两段影响：

1. 人物层：忠诚大降，状态转为 `割据`
2. 国力层：按该人物军力直接重创北周五维

基础打击近似为：

- 财政：`- 军力 / 16`
- 粮赋：`- 军力 / 20`
- 军事：`- 军力 / 14`
- 社会秩序：`- 军力 / 22`
- 统治穿透力：`- 军力 / 16`

然后再乘势力/链式放大系数。

### 8.2 煽动造反

成功后伤害比割据更大，近似为：

- 财政：`- 军力 / 9`
- 粮赋：`- 军力 / 12`
- 军事：`- 军力 / 7`
- 社会秩序：`- 军力 / 10`
- 统治穿透力：`- 军力 / 9`

因此，AI Native 文本在高阶动作中影响最明显。

## 9. 北周施计：一个具体例子

以祖廷为目标使用“献策”为例：

基础成功模板大致是：

- 人物层：`trust +6`
- 势力层：所属派系 `courtInfluence +2.2`、`internalStability -0.8`

若玩家只写：

`请丞相帮忙。`

则大多只会接近基础收益。

若玩家写：

`丞相若趁灾年清丈仓廪、把饷权与赈务一并收回中枢，既能堵住河北豪右，也能让帝党无从越权。`

则会因为：

- 长度充分
- 命中祖廷的权力欲、行政中枢、财政卡位
- 命中仓廪、中枢、河北等结构词

获得更高 `speechScore`。

于是会同时出现：

- 更高成功率
- 更高人物层收益
- 更大的派系层变化
- 更明显的北周五维波动

这已在当前测试中被锁定。

## 10. 南陈问政：总体结算链

南陈问政按如下顺序生效：

1. 题库选项提供基础五维效果
2. 读取玩家附言，计算 `reasonModifier`
3. 用倍率修正本回合即时收益
4. 根据 `legitimacyEffect / aiScoringFocus / nextRoundFeedback` 生成下一回合余波

简写为：

`选项基础值 -> 附言倍率 -> 本回合收益 -> 下一回合余波`

---

## 11. 南陈问政：附言倍率规则

### 11.1 reasonModifier 范围

- 最低：`0.70x`
- 最高：`1.55x`

### 11.2 评分来源

#### 基础分

- 有附言：起始为 `0.82`
- 无附言：直接 `1.00`

#### 长度分

- 长度 `>= 8`：`+0.10`
- 长度 `>= 18`：再 `+0.12`
- 长度 `>= 36`：再 `+0.10`

#### 命中选项对应维度关键词

若附言命中该题实际影响维度的关键词，则每命中一个维度：

- `+0.09`

最多：

- `+0.27`

#### 命中策略/治理语言

若附言涉及：

- 风险、代价、短期、长期、门阀、后勤、执行、地方、窗口、权衡、先后、缓急、转运、掣肘、名分、军心、人心、中枢

则：

- `+0.12`

#### 命中题目 scoring focus

若附言切中该题的 `aiScoringFocus`：

- `+0.10`

#### 命中法统方向

若该题选项的 `legitimacyEffect = up`，且附言含：

- 人心、名分、安民、稳、抚、渐进、法统、秩序

则：

- `+0.08`

若该题选项的 `legitimacyEffect = down`，且附言含：

- 权宜、急征、强压、重税、严控、高压、急攻

则：

- `+0.04`

---

## 12. 南陈问政：即时收益如何形成

本回合即时收益公式：

`即时效果 = 题库基础效果 × reasonModifier`

例如某题选项基础效果为：

- 粮赋 `+3`
- 统治穿透力 `+1`

若附言很普通，最终可能接近：

- 粮赋 `+3.0`
- 统治穿透力 `+1.0`

若附言非常切题，最终可能达到：

- 粮赋 `+4.2 ~ +4.7`
- 统治穿透力 `+1.4 ~ +1.6`

---

## 13. 南陈问政：下一回合余波如何形成

### 13.1 余波比例

下一回合余波只继承“本回合的正向收益”。

- 若附言命中 `aiScoringFocus`：按即时正收益的 `0.38x`
- 若未命中：按即时正收益的 `0.22x`

### 13.2 法统余势修正

若 `legitimacyTone = up`：

- 额外 `governance +0.6`
- 额外 `socialOrder +0.6`

若 `legitimacyTone = down`：

- 额外 `socialOrder -0.8`
- 额外 `governance -0.4`

因此，问政附言不仅影响“这回合加多少”，也影响“下回合能不能继续发酵”。

## 14. 当前版本强度判断

### 14.1 北周施计

当前 AI Native 强度约为：`7/10`

原因：

- 已真实影响成功率
- 已穿透人物层、势力层、国力层
- 高阶动作与战时外溢时影响尤其明显
- 但判定仍偏规则化，尚未进入真正深语义理解

### 14.2 南陈问政

当前 AI Native 强度约为：`7.5/10`

原因：

- 已真实影响即时五维收益
- 已影响下一回合政策余波
- 已接入 `legitimacyEffect / aiScoringFocus / nextRoundFeedback`
- 但依旧以规则打分为主

### 14.3 综合结论

当前版本已经做到：

- 玩家输入有实质影响
- 影响可穿透到最终数值
- 玩家会明显感觉“随便写”和“认真写”不一样

但当前版本尚未做到：

- 对复杂长句进行真正语义理解
- 对高质量但不命中关键词的表达给予足够好回报
- 对 NPC 风格与回合事件作更精细的语境评分

因此，若后续继续增强 AI Native，重点应放在“提升语义识别质量”，而不是单纯继续放大倍率。
