# 《佞臣》前台交互与信息可见性设计

> 本文档定义前置导入页、核心流程页面、信息可见性规则与当前版本的新手引导方案。

---

## 1. 页面总览

```
背景序章页 → 玩法总览页 → 回合开始页 → 朝局观察页 → NPC详情页（可选）
    ↓
计谋操作页（×3）→ 女帝来信页 → 暗线回报页 → 北周结算页 → 回合收束页
    ↓（第20回合后）
结局页
```

补充追认：

- `背景序章页` 为独立前置页，负责交代世界背景、主角处境与十年之诺。
- `玩法总览页` 为独立前置页，同时也是后续全局 `玩法说明` 覆盖层的内容真源。
- `玩法说明` 现在采用覆盖层实现，打开和关闭都不改变主流程 phase，也不会清空已施计、已选问政等中间状态。

## 2. 各页面信息架构

### 2.1 背景序章页

| 区域 | 内容 | 说明 |
|------|------|------|
| 序章标题 | 背景序章 / 纷乱之世 | 纯叙事导入 |
| 结构化小标题 | 纷乱之世 / 你是谁 / 你为何入周 / 女帝之托 / 十年之诺 | 正式真源 |
| 核心时间信息 | 一年两回合，共 20 回合 | 必显 |
| 继续按钮 | `继续` | 进入玩法总览页 |

> 该页不讲系统按钮与操作方式，只负责把玩家带入萧宝颖的处境。

### 2.2 玩法总览页

| 区域 | 内容 | 说明 |
|------|------|------|
| 目标说明 | 保全自身 / 阻止提前南征 / 削弱北周 / 辅佐女帝 | 必显 |
| 每回合流程 | 朝局观察 → 施计三次 → 女帝问政 → 暗线回报 → 北周结算 | 必显 |
| 系统说明 | 计谋系统 / 势力与风险 / 天道判官 / 文字输入影响 | 必显 |
| 开局按钮 | `开始入局` | 开局时进入正式游戏 |
| 返回按钮 | `返回原页` | 覆盖层模式下返回原页面 |

> 当前 Demo 已落地两种模式：
> - `entry`：开局前独立页
> - `overlay`：游戏中覆盖层

### 2.3 回合开始页

| 区域 | 内容 | 说明 |
|------|------|------|
| 回合标题 | "第 X 回合 · 建文X年/天嘉X年" | 增强时代沉浸感 |
| 上回合问政余波 | 上一回合南陈政策的延迟反馈 + 微量五维修正 | 当前 Demo 已落地 |
| 宏观事件播报 | 本回合发生的全局事件卡片 | 1 个主事件，带简短描述 |
| 历史辅助 | 地理提示 / 势力提示 / 战略提示 + 极简方位示意 | 当前 Demo 已落地 |
| 冯道之锦囊 | 1 段暗示性提示 | 不直接说答案，提供方向 |
| 玩法说明入口 | 打开覆盖层 | 不改变当前流程状态 |
| 进入按钮 | "入朝" | 进入朝局观察页 |

> 回合 1 不再使用“新手手札”常驻块，改为首次进入页面弹窗。

### 2.4 朝局观察页

这是玩家每回合决策前的"仪表盘"。

| 区域 | 内容 | 优先级 |
|------|------|--------|
| **北周国力仪表** | 北周综合国力（标签制，见 3.1） | 必显 |
| **南征风险条** | 当前南征风险等级（见 3.3） | 必显 |
| **自身安全** | 当前生存风险等级（见 3.4） | 必显 |
| **朝堂势力概况** | 帝党 / 后党两派的朝堂影响力、内部稳定度与军事实力摘要 | 必显 |
| **外部权力人物** | 陇右 / 草原人物的军力、忠诚、倾向与当前状态 | 必显 |
| **可互动 NPC 列表** | 当前可交互的 NPC 头像+信任标签 | 必显 |
| **人物回合反馈** | 每位存活 NPC 对本回合事件的一句话判断 | 必显 |
| **南征/安内态势** | 两派力量对比条 | 必显 |
| 剩余计谋次数 | "今日可用计谋：3/3" | 必显 |
| 玩法说明入口 | 打开覆盖层 | 必显 |
| 返回按钮 | 返回回合开始页 | 必显 |

> 人物回合反馈在 Demo 当前口径下统一用**第一人称**呈现，以增强代入感。

### 2.5 NPC 详情页（点击 NPC 进入）

| 区域 | 内容 | 可见性 |
|------|------|--------|
| 头像与称号 | 姓名、官职、势力标签 | 公开 |
| 信任状态 | 标签制（见 3.2） | 公开 |
| 公开立场 | 1-2 句话 | 公开 |
| 已知情报 | 通过试探获取的暗线片段 | 逐步解锁 |
| 关系网络 | 该 NPC 与其他 NPC 的已知关系 | 逐步解锁 |
| 可用计谋列表 | 当前信任度下可对其使用的计谋 | 动态 |
| 行动按钮 | "施计" | — |

### 2.6 计谋操作页

| 步骤 | 内容 |
|------|------|
| ① 选择目标 NPC | 从可互动列表中选择 |
| ② 选择计谋类型 | 展示当前信任度下可用的计谋，灰显不可用的 |
| ③ 选择关联角色（部分计谋需要） | 如离间需指定第二个 NPC |
| ④ 补一句说辞 | 文本输入框，限 100 字以内 |
| ⑤ 确认执行 | "行事" 按钮 |
| ⑥ 进入暗线回报队列 | 本回合 3 条反馈在统一的"暗线回报页"集中呈现 |
| 玩法说明入口 | 打开覆盖层 | 必显 |
| 返回按钮 | 返回朝局观察页 | 必显 |

> 说辞不是纯氛围文本。若命中 NPC 的立场 / 软肋 / 痛点，会实质影响计谋成败率与效果幅度。

### 2.7 女帝来信页

| 区域 | 内容 |
|------|------|
| 来信人 | "南陈女帝 · 陈倩" |
| 本回合问政题 | 背景描述 + 题干 |
| 四个选项 | 选项卡/按钮形式 |
| 理由输入 | 选定选项后出现文本框，限 100 字 |
| 玩法说明入口 | 打开覆盖层 | 必显 |
| 递交按钮 | "奏上" |

> 理由输入会实际修正问政选项对南陈五维的影响幅度。命中"缓急、代价、执行路径"的解释更有价值。

### 2.8 暗线回报页

| 区域 | 内容 |
|------|------|
| 三条反馈卡 | 本回合 3 次施计对应 NPC 的完整反应 |
| 说辞回显 | 展示玩家当次补的那一句话 |
| 加载态 | 若 AI 未返回，显示"正在思忖" |
| 玩法说明入口 | 打开覆盖层 | 必显 |
| 继续按钮 | 3 条回报到齐后进入结算 |

### 2.9 北周结算页

| 区域 | 内容 | 展示方式 |
|------|------|----------|
| 计谋结果 | 3 次计谋的逐条结果 | 依次展开，NPC 完整回应+信任度变化标签 |
| 势力变化 | 四方势力的关键变动 | 变化箭头（↑↓—） |
| 北周国力变化 | 综合国力标签变化 | 标签色彩变化 |
| 南陈问政回批 | 本回合问政的女帝回信 + 南陈五维变化 | 同页前置展示 |
| 南陈问政后效预告 | 下一回合会发酵的政策余波 | 当前 Demo 已落地 |
| 朝堂势力裂口 | 帝党 / 后党的崩口、崩盘提示 | 当前 Demo 已落地 |
| 南北五维 | 北周 / 南陈五维雷达图 | 并列展示 |
| 南征风险变化 | 风险等级变化 | 色彩变化 |
| 危险预警 | 若接近死亡/南伐阈值 | 红色警报弹窗 |
| 玩法说明入口 | 打开覆盖层 | 必显 |

### 2.10 回合收束页

|------|------|

| 下回合钩子 | "下回合预告：XXX" |
| 继续按钮 | "翻月" → 进入下回合 |

## 3. 信息可见性规则

### 3.1 北周综合国力——标签制

玩家**不可见**具体数值，只能看到分段标签：

| 综合国力范围 | 显示标签 | 颜色 |
|-------------|---------|------|
| ≥ 75 | 鼎盛 | 深红 |
| 60–74 | 强盛 | 红 |
| 45–59 | 中平 | 黄 |
| 30–44 | 衰弱 | 绿 |
| < 30 | 崩塌 | 灰 |

> 北周初始 65.5 → 显示"强盛"。玩家需要将其打到"中平"以下才有胜算。

### 3.2 NPC 信任度——标签制

| 信任度范围 | 显示标签 | 图标 |
|-----------|---------|------|
| 0–14 | 敌意 | 🔴 |
| 15–29 | 戒备 | 🟠 |
| 30–49 | 平淡 | 🟡 |
| 50–69 | 信赖 | 🟢 |
| 70–89 | 倚重 | 🔵 |
| 90–100 | 深信 | 💜 |

> 不显示具体数字。玩家只能感受到大致区间，通过 NPC 的措辞变化判断微妙变化。

### 3.3 南征风险——三级信号

| 等级 | 条件 | 显示 |
|------|------|------|
| ✅ 安全 | 南征派影响力 < 安内派 × 0.8 | 绿色"安内占优" |
| ⚠️ 警戒 | 南征派影响力介于 0.8× ~ 1.3× 安内派 | 黄色"南征议起" |
| 🚨 危急 | 接近触发阈值（≥ 1.2× 且可战能力达标中） | 红色闪烁"南征在即" |

### 3.4 自身安全——三级信号

| 等级 | 条件 | 显示 |
|------|------|------|
| ✅ 安稳 | 无朝堂势力 NPC 满足死亡条件前两项 | 绿色"朝中无虞" |
| ⚠️ 有人盯上你 | 存在朝堂势力 NPC 影响力≥55 且信任≤25 | 黄色"暗流涌动" |
| 🚨 命悬一线 | 存在朝堂势力 NPC 影响力≥60 且信任≤15 且有处置能力 | 红色"祸在旦夕" |

### 3.5 南陈国力——Demo 当前为可见

当前 Demo 已改为：玩家可以在**回合首页**与**北周结算页**直接看到南陈五维雷达与相对北周的对比结果。

可见内容包括：
- 南陈五维雷达
- 南陈相对北周的综合强弱标签
- 本回合问政回批带来的五维变化

> 说明：这属于当前游戏机制的正式真相，策划案在此追认现实现状；后续若要回调为“部分隐藏”或“完全隐藏”，需另开版本讨论。

### 3.6 势力值与朝堂影响力

| 信息 | 可见性 | 显示方式 |
|------|--------|----------|
| 帝党 / 后党朝堂影响力 | **可见** | 当前 Demo 为数值摘要 + 条形图并存 |
| 帝党 / 后党内部稳定度 / 军事实力 | **可见** | 当前 Demo 以摘要数值显示 |
| 外部人物军力 / 忠诚 / 倾向 / 当前状态 | **可见** | 当前 Demo 直接显示数值 + 标签 |
| 外部人物真实算盘 | **不可见** | 需通过试探获取暗线碎片 |

### 3.7 暗线揭露规则

| 途径 | 说明 |
|------|------|
| 试探成功 | 获取 1 条暗线碎片，存入该 NPC 详情页的"已知情报" |
| 宏观事件触发 | 部分事件自动揭露 1 条相关暗线，并抬高该人物回合反馈的信息层级 |
| 冯道之锦囊 | 偶尔包含 1 条暗线提示 |
| 关系升级 | 信任度跨过新层级时可能自动揭露 1 条 |

> Demo 当前实现优先保证：试探成功必解锁 1 条暗线；同时已接入部分回合事件的自动揭露机制，用于把关键人物的线索抬升到更可判断的层级。

> 暗线碎片是永久的——一旦获取，终局可用。

## 4. 新手引导设计

### 4.1 引导时间线

| 回合 | 引导内容 |
|------|----------|
| 开局前 | 背景序章页：讲清世界背景、主角处境与十年之诺 |
| 开局前 | 玩法总览页：讲清目标、流程、系统与输入影响 |
| **回合 1** | 半教学回合：首次进入关键页面时弹出一次性说明 |
| **回合 2 起** | 不再强制弹窗，改为随时可打开 `玩法说明` 覆盖层 |

### 4.2 引导原则

- **前置分层**：先讲故事，再讲玩法，不把背景和系统硬塞在同一页
- **第一回合轻提示**：只在关键页面第一次进入时弹一次，不做常驻说教块
- **不中断状态**：帮助层和玩法说明只覆盖 UI，不重置玩家当前操作
- **全中文表达**：不使用英文术语提示玩家输入的重要性

### 4.3 当前 Demo 追认

当前版本已按“序章导入 + 第一回合半引导”落地：

- 开局前新增 `背景序章页`
- 开局前新增 `玩法总览页`
- 回合 1 在以下页面首次进入时弹出说明：
  - 回合开始页
  - 朝局观察页
  - 施计页
  - 女帝来信页
  - 暗线回报页
  - 北周结算页
- 以上说明弹窗均为一次性记录，并写入本地存档
- 主流程页统一提供 `玩法说明` 入口，关闭后返回原页面，不丢状态

这套机制现视为正式策划口径。

## 5. 存档与续局（Demo 当前机制）

- 当前 Demo 已支持本地单存档位
- 进入游戏时若检测到有效存档，会弹出：
  - `继续上局`
  - `重新开局`
- 本地存档会同时保存：
  - 当前是否仍处于序章 / 玩法总览 / 正式游戏
  - `玩法说明` 覆盖层状态
  - 第一回合各页面引导是否已看过
- 存档保存的是规则状态，不保存临时 UI 展开态
- 复盘与战报依赖 `roundHistory` 快照自动累计

## 6. 视觉与媒体资源追认

当前 Demo 已正式接入一版轻量视觉与媒体资源系统，原则是：**增强沉浸感，但不重做主循环页面结构。**

### 6.1 BGM 分配

当前 Demo 的页面配乐口径为：

- `BGM 4`
  - 背景序章页
  - 玩法总览页
  - 每回合天道结算页
- `BGM 1`
  - 每回合首页
  - 朝局观察页
- `BGM 2`
  - 施计页
  - 暗线回报页
- `BGM 3`
  - 女帝问政页

并统一使用：

- 单实例全局音频
- 页面切换自动换曲
- 可手动 `开声 / 静音`

### 6.2 地图呈现

当前 Demo 已将真实地图接入两个位置：

- 背景序章页 `纷乱之世` 段落下
- 每回合首页的 `历史辅助` 区块

首页中原本分开的：

- `历史辅助`
- `方位示意`

已合并为一张地图主导的辅助卡，地图下方继续保留：

- 地理提示
- 势力提示
- 战略提示

### 6.3 地图切换规则

当前 Demo 使用 4 张地图，并只在战役 `得手` 时切换领土态：

- 初始：`map_1`
- 南陈得巴蜀：`map_2`
- 南陈得巴蜀与淮南：`map_3`
- 南陈未得巴蜀但得淮南：`map_4`

`stalemate / failed` 不视为领土已稳定取得，因此不切占领态地图。

### 6.4 角色图呈现

当前 Demo 对角色图采用“轻量接入”：

- 群臣列传：小头像
- 施计页：目标小头像
- 暗线回报页：小头像
- NPC 详情页：大图主视觉

本轮不做：

- 群臣列传整卡半身像重构
- 施计页全卡大图化

这套资源接入现视为正式 Demo 口径。
