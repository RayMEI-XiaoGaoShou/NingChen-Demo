# 《佞臣》20 回合主线事件表

> 本文档汇总 20 回合的叙事骨架、结构化事件字段与核心 NPC 反馈方向。
> 用于反推问政题库、NPC 数据库与逐回合事件脚本。

---

## 1. 20 回合主线事件骨架

### 第一阶段：立朝未稳（回合 1–4）

1. 建文五年上 / 天嘉元年上：两朝新局初定，北周再起"乘虚南征"之议  
2. 建文五年下 / 天嘉元年下：淮南小规模摩擦升级，江北流民南渡  
3. 建文六年上 / 天嘉二年上：河北、河南春旱，北周东部欠收  
4. 建文六年下 / 天嘉二年下：突厥试边，雁门、卢龙告急

### 第二阶段：边患与西线危机（回合 5–8）

5. 建文七年上 / 天嘉三年上：吐谷浑侵扰河西，西域商道受阻  
6. 建文七年下 / 天嘉三年下：益州刺史公孙知祥叛变，自称奉诏安蜀，实则谋求割据  
7. 建文八年上 / 天嘉四年上：北周西征议起，争论谁领兵、谁筹饷、谁坐镇中枢  
8. 建文八年下 / 天嘉四年下：邺城与关中秋涝，北周下令清查仓廪

### 第三阶段：巴蜀线开启（回合 9–12）

9. 建文九年上 / 天嘉五年上：西线未靖，帝党重提"不可久拖，应南征以定天下心"  
10. 建文九年下 / 天嘉五年下：南陈正式发动第一次征蜀行动  
11. 建文十年上 / 天嘉六年上：蜀地战局僵持，北周争论战后如何安置西线兵权  
12. 建文十年下 / 天嘉六年下：突厥再犯，并提出岁赐与互市条件

### 第四阶段：内部张力上升（回合 13–16）

13. 建文十一年上 / 天嘉七年上：北方疫疠流行，谶言四起，人心不安  
14. 建文十一年下 / 天嘉七年下：小皇帝亲政意愿抬头，帝党与后党围绕归政暗斗  
15. 建文十二年上 / 天嘉八年上：河北豪强兼并、流民滋生，地方控制力下降  
16. 建文十二年下 / 天嘉八年下：南陈正式发动征淮南战役

### 第五阶段：淮南大战拖长，北周短板暴露（回合 17–20）

17. 建文十三年上 / 天嘉九年上：淮南久战，北周征发日重，前线后方俱显疲态  
18. 建文十三年下 / 天嘉九年下：草原势力乘北周主力南顾而抬价，燕云、辽东军情反复  
19. 建文十四年上 / 天嘉十年上：连年兵灾叠加灾耗，北周出现"大清查、大征发、大整肃"的呼声  
20. 建文十四年下 / 天嘉十年下：十年周期总摊牌，南北两朝进入终局结算

## 3. 核心 NPC 与势力每回合反馈方向

> 说明：即使某回合主受影响势力很明确，其他势力也必须有符合自身利益与人设的反馈，以保证朝堂"活起来"。

### 回合 1–4

- **回合 1**：宇文棣、祖廷、贺拔琪、冯道之为核心；帝党抢南征议题，后党抢节奏控制，草原势力抬边防价值
- **回合 2**：尉迟暮、宇文棣、祖廷、宗艾；帝党借边摩擦扩战，后党控局，宗艾借信息差做皇帝通道
- **回合 3**：祖廷、令狐律光、宇文棣、贺拔琪；后党借灾年治理稳中枢，帝党压低"灾年不宜动兵"的论调
- **回合 4**：尔朱烈、安思明、令狐律光、宗艾；草原势力借边患抬价，令狐律光借机压南征与压草原势力

### 回合 5–8

- **回合 5**：贺拔伯圭、独孤文约、祖廷、宇文棣；陇右勋贵借河西危机坐大，祖廷防饷权旁落
- **回合 6**：贺拔伯圭、独孤文约、祖廷、贺拔琪；益州叛乱让"谁平叛、谁得权"成为核心
- **回合 7**：贺拔伯圭、独孤文约、祖廷、宇文棣、贺拔琪；西征议本质是帅权、饷权、中枢权再分配
- **回合 8**：祖廷、贺拔琪、令狐律光、独孤文约；清仓不仅是救灾，更是借制度性整顿重新洗牌

### 回合 9–12

- **回合 9**：宇文棣、令狐律光、尉迟暮、宗艾；帝党与安内派围绕"该不该打"再次正面对撞
- **回合 10**：贺拔伯圭、独孤文约、祖廷、宇文棣；南陈征蜀使北周西线真实承压
- **回合 11**：贺拔伯圭、独孤文约、祖廷、贺拔琪、令狐律光；战后兵权归属成为核心
- **回合 12**：尔朱烈、安思明、令狐律光、宗艾；草原势力讨价还价，令狐律光欲压其坐大

### 回合 13–16

- **回合 13**：贺拔琪、祖廷、宗艾、宇文棣；疫病与谶言使名分、正当性与宫中流言上桌
- **回合 14**：宗艾、宇文棣、贺拔琪、祖廷；归政之争本质是"皇权、宗室、后党、宫中接口"重新排列
- **回合 15**：祖廷、令狐律光、贺拔琪、宇文棣；地方控制力下降，统治穿透力成为第一议题
- **回合 16**：尉迟暮、宇文棣、令狐律光、宗艾；征淮南使前线、后方、皇权的资源竞争彻底公开化

### 回合 17–20

- **回合 17**：尉迟暮、祖廷、令狐律光、宇文棣；久战状态下"谁背锅"开始成为真实问题
- **回合 18**：尔朱烈、安思明、令狐律光、宗艾；草原势力试图从依附者升级为不可替代的国柱
- **回合 19**：祖廷、贺拔琪、宇文棣、宗艾、贺拔伯圭；大整肃是终局前最后一轮全面洗牌
- **回合 20**：宇文棣、贺拔琪、祖廷、令狐律光、尉迟暮、贺拔伯圭、独孤文约、尔朱烈、安思明、宗艾全员上桌

## 4. NPC 动机骨架摘要

> 此处为基于 20 回合事件推进中提炼出的动机骨架。完整角色卡详见 `NPC角色卡.md`。

### 宇文棣
- 公开诉求：对陈强硬、抢占南征主导权、维护宗室与国家威势
- 隐性诉求：压后党、维持自己作为宇文氏最能担国难之人的位置
- 最容易被撬动：献策（顺着其强硬路线设计赢法）、谗言（放大后党拖延、误国）、离间（挑其与皇帝、后党的微妙互疑）

### 尉迟暮
- 公开诉求：前线需要更多兵、粮、授权
- 隐性诉求：将自己从边帅抬升为国家柱石，避免久战后背锅
- 最容易被撬动：献策（前线务实方案）、求援（将其转为保护者/渠道）、借刀（高信任后逼资源、压制掣肘者）
- 驻地口径追认：驻彭城，统淮南前线；寿春是其关键战区，而非唯一驻点

### 宗艾
- 公开诉求：替皇帝感知群臣忠诚、传递皇帝意志
- 隐性诉求：把自己做成皇帝与各派之间不可替代的接口
- 最容易被撬动：试探、求援、借刀、谶纬（在宫中叙事/名分回合）

### 祖廷
- 公开诉求：维持中枢秩序、掌后勤、掌财政、掌诏令
- 隐性诉求：将"无祖廷则国政不行"坐实，防军头、宗室、边镇抢走机器
- 最容易被撬动：献策（制度、财政、接管方案）、放风构陷（谁在侵吞、谁在借战乱揽权）、试探（辨其是护国还是护权）

### 令狐律光
- 公开诉求：先安内，后攘外；边镇、草原势力、地方失控都比仓促大战危险
- 隐性诉求：证明自己的路线从头到尾是对的，同时防任何一派借战乱吞并国家
- 最容易被撬动：谗言（主战派谋私）、离间（帝党、草原势力与后党之间的互疑）、献策（如何稳国家而非稳派系）

### 贺拔琪
- 公开诉求：稳定摄政秩序，任何大战略都必须在自己手里展开
- 隐性诉求：既要利用宇文棣、贺拔伯圭等人，又不能让他们借国难坐大到失控
- 最容易被撬动：求援（天然保护伞）、献策（如何平衡各方）、借刀（危机回合借其手清理问题人物）

### 贺拔伯圭
- 公开诉求：西线需要自己总领，护河西、护商道、护蜀地
- 隐性诉求：把战时权变成长期地方权，构筑河西—关西—蜀地的连续影响圈
- 最容易被撬动：献策（如何更名正言顺地揽权）、离间（中枢不信你、独孤抢你）、借刀（高信任后逼他主动压人）

### 独孤文约
- 公开诉求：自己也能平西线、也能为朝廷分忧
- 隐性诉求：绝不当贺拔伯圭的附庸，要做西线第二中心乃至替代方案
- 最容易被撬动：试探、离间（贺拔独吞功劳）、献策（你其实比贺拔更能和中枢合作）

### 尔朱烈
- 公开诉求：边地要兵、要封赏、要地位
- 隐性诉求：从依附草原首领升级为中原权力人物
- 最容易被撬动：献策、求援、离间（朝中谁真正看不起他、谁想压他）

### 安思明
- 公开诉求：要军资、要甲具、要信任
- 隐性诉求：借北周资源为未来重返草原做准备
- 最容易被撬动：献策、试探
