### ⚡ MVP 可选项（有余力则做）

| 模块 | 内容 | 价值 |
|------|------|------|
| 回合节奏标注 | 标记铺垫/高压/高潮回合 | 提升叙事节奏感 |
| 逐回合事件细稿 | 每回合的播报文案/锦囊文本/收束总结 | 提升文本品质 |
| 胜利分级 | 大胜/稳胜/险胜三档 | 增加重玩动力 |
| 失败分级 | 惨败/惜败/险败三档 | 情感层次更丰 |
| 统计摘要页 | 最常用计谋/最信任NPC/最大单次变动 | 重玩对比乐趣 |
| NPC 终局命运 | 结局页显示各 NPC 存活/死亡/得势 | 增加叙事厚度 |

### 🔮 远期扩展项（MVP 明确不做）

| 模块 | 内容 | 说明 |
|------|------|------|
| 弹劾/软禁/审讯缓冲态 | 死亡前增加缓冲阶段 | 增加生存策略深度 |
| 提前南伐后的短危机回合 | 不直接判负，进入抢救模式 | 减少挫败感 |
| 南陈完整朝堂人物网 | 将问政扩展为完整 NPC 交互 | 工作量极大 |
| NPC 专属计谋 | 每个 NPC 有独特的互动选项 | 增加角色辨识度 |
| 谶纬/密探/伪造文书 | 与关系网络更深绑定 | 系统复杂度极高 |
| 多阶段宫廷政变链 | 帝党/后党的终极对决线 | 剧情量大 |
| 灰色结局/隐藏结局 | 如"你活了但南陈亡了" | 需要额外叙事设计 |
| 更复杂的资源库存系统 | 金/粮/兵/情报等可消耗资源 | 偏离"强文本"定位 |

## 3. 技术实现优先级建议

面向开发 Agent 的实现建议顺序：

| 阶段 | 内容 | 目标 |
|------|------|------|
| **P0：可运行原型** | 回合循环 + 计谋选择 + 问政 + 基础结算 + 胜负判定 | 能跑通 20 回合并看到结局 |
| **P1：系统完整** | NPC Agent 接入 + 天道判官规则 + 信任度/势力/国力完整联动 | 所有系统可正确结算 |
| **P2：体验打磨** | 前台页面完整 + 信息可见性 + 教学引导 + 结局分级 | 真正可试玩 |
| **P3：内容填充** | 20 回合事件文案 + NPC 回应文本 + 冯道之锦囊 + 播报文案 | 文本品质达标 |

## 4. 裁剪决策速查

当开发过程中遇到"要不要做 X"的决策时，用以下原则判断：

| 原则 | 判断 |
|------|------|
| 是否影响胜负判定？ | 是 → 必做 |
| 是否影响核心循环的可运行性？ | 是 → 必做 |
| 是否需要新增系统/机制？ | 是 → 大概率是远期扩展 |
| 是否只是文本/美术品质提升？ | 是 → 可选项 |
| 是否需要大量手写内容？ | 是 → 评估 ROI 再决定 |
| 能否用"标签制"或"简化展示"替代完整实现？ | 能 → 先做简化版 |
