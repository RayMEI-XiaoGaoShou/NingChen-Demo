# 第一阶段：立朝未稳，先把局势拨活（回合 1–4）

## 回合 1｜建文五年上 / 天嘉元年上

**事件：两朝新局初定，北周再起“乘虚南征”之议**

**宇文棣**

- 公开诉求：立即形成对南陈的战略压迫，抢占“南征”议题主导权
- 隐性诉求：压制后党对朝政的话语权，同时证明自己是宇文氏天下最能打、最能担事的人
- 最易被撬动：**献策、谗言**
    - 献策：顺着他的强硬路线去“帮他更快赢”
    - 谗言：借机放大“后党拖延、误国”的印象

**祖廷**

- 公开诉求：先整顿中枢、理顺诏令和仓廪，不可仓促大举南征
- 隐性诉求：把“国家机器必须靠我运转”坐实，防止宇文棣拿战争抢走议程
- 最易被撬动：**献策、试探**
    - 献策：从政务、名分、后勤角度给他可执行方案
    - 试探：探其真正是“护国”还是“护权”

**贺拔琪**

- 公开诉求：朝局必须稳在自己手里，不能让南征议题失控
- 隐性诉求：既要利用宇文棣对陈强硬，又不能让其借国战坐大
- 最易被撬动：**求援、献策**
    - 求援：她已是主角保护伞，适合用“站台/背书”方式撬动
    - 献策：以“如何既打压宇文棣又不显怯战”为切口


---

## 回合 2｜建文五年下 / 天嘉元年下

**事件：淮南摩擦升级，江北流民持续南渡**

**尉迟暮**

- 公开诉求：增兵淮南、稳住边线、争取前线资源
- 隐性诉求：把自己塑造成“真正在扛国难”的人，借此抬升帝党军事实权
- 最易被撬动：**献策、求援**
    - 献策：围绕边务、军需、边防布置
    - 求援：在你已建立一定关系后，可把他变成前线保护者

**宇文棣**

- 公开诉求：把边境摩擦解释成“南朝可趁、不可纵”
- 隐性诉求：继续把一切地方摩擦升级为自己路线正确的证据
- 最易被撬动：**谗言、离间**
    - 可向他灌输“后方有人掣肘军机”的印象

**祖廷**

- 公开诉求：控住流民、控住边报、控住财政，不给帝党无限扩战借口
- 隐性诉求：用行政理性去抵消军功叙事，维持后党中枢地位
- 最易被撬动：**献策、放风构陷**
    - 适合借“谁在夸大战情、谁在借机索饷”做文章

**宗艾**

- 公开诉求：代皇帝传达“边务不可轻忽”的关切
- 隐性诉求：借边报成为皇帝与前线、与宗室之间的信息阀门
- 最易被撬动：**试探、求援、谗言**
    - 他最容易被“你可以帮陛下看清谁在欺君”这种说法撬动

---

## 回合 3｜建文六年上 / 天嘉二年上

**事件：河北、河南春旱，北周东部欠收**

**祖廷**

- 公开诉求：赈灾、清仓、减赋、稳秩序
- 隐性诉求：把灾年治理做成自己的政绩，证明“无祖廷则朝政难行”
- 最易被撬动：**献策、试探**
    - 你可从“如何救灾而不失控”入手

**令狐律光**

- 公开诉求：灾年不宜轻启大战，应先安内整军
- 隐性诉求：借灾情压制帝党的南征节奏，并凸显自己作为“定盘星”的价值
- 最易被撬动：**献策、谗言**
    - 他很容易被“某些人拿国家存亡赌个人军功”这种叙事触动

**宇文棣**

- 公开诉求：灾情虽有，但不能因此动摇国家对陈战略
- 隐性诉求：防止“灾年=不能打”在朝堂坐实
- 最易被撬动：**献策、谗言**
    - 可顺着他的强硬性格，设计“既显强硬又不被说成不顾民生”的方案

**贺拔琪**

- 公开诉求：以太后名义主持赈灾，稳人心、稳朝纲
- 隐性诉求：灾情反而是她展示统御力、压宗室锋芒的机会
- 最易被撬动：**献策、求援**
    - 她会接受“如何把赈灾做成政治资本”的进言

---

## 回合 4｜建文六年下 / 天嘉二年下

**事件：突厥试边，雁门、卢龙告急**

**尔朱烈**

- 公开诉求：加强北庭边备、补充军械、提高边镇自主度
- 隐性诉求：借边患抬升自己在中原的政治身价，向“边帅”以上迈一步
- 最易被撬动：**献策、求援、离间**
    - 他很容易被“你比朝中那群鲜卑贵胄更能镇边”这种话撬动

**安思明**

- 公开诉求：请求军械、甲具与更大作战授权
- 隐性诉求：借北周资源重建自己未来打回草原的本钱
- 最易被撬动：**献策、试探**
    - 他对现实利益、军备支持特别敏感

**令狐律光**

- 公开诉求：北边未稳，绝不可轻言南征
- 隐性诉求：同时防草原势力坐大、防帝党借国战夺军
- 最易被撬动：**离间、谗言**
    - 最容易撬他的，是“草原势力表里不一”“帝党纵容边镇坐大”

**宗艾**

- 公开诉求：替皇帝收拢北边军情，表现出皇权关切边防
- 隐性诉求：寻找皇帝越过后党与宗室、直接接触边镇的渠道
- 最易被撬动：**试探、求援**
    - 尤其容易被“你才是真正能替陛下听见边地声音的人”打动

---

# 第二阶段：边患与西线危机（回合 5–8）

## 回合 5｜建文七年上 / 天嘉三年上

**事件：吐谷浑侵扰河西，西域商道受阻**

**贺拔伯圭**

- 公开诉求：扩兵、扩饷、扩大河西军政自主权
- 隐性诉求：把“护商道”做成自己长期据有河西财政与军权的合法理由
- 最易被撬动：**献策、离间、求援**
    - 献策：替他设计更名正言顺的揽权路径
    - 离间：最容易激发他对中枢、对独孤文约的不满

**独孤文约**

- 公开诉求：支持守西线、护商道，但主张更灵活的中枢合作方式
- 隐性诉求：不让贺拔伯圭独占西线功劳，借中枢制衡换取更大利益
- 最易被撬动：**试探、献策、离间**
    - 他最适合被“你其实比贺拔更懂得和朝廷做生意”这种话撬动

**祖廷**

- 公开诉求：西线可以救，但饷权、任命权不能外流
- 隐性诉求：防止河西变成贺拔伯圭的半独立财政军区
- 最易被撬动：**放风构陷、谗言、献策**
    - 可用“有人借边患敛财”去激他

**宇文棣**

- 公开诉求：西线要守，但不能因此完全放弃南向战略
- 隐性诉求：避免贺拔与后党联手把国家重心从南征议题挪开
- 最易被撬动：**谗言、离间**
    - 很容易被“后党和贺拔借西线私相授受”的叙事撬动

---

## 回合 6｜建文七年下 / 天嘉三年下

**事件：益州刺史公孙知祥叛变**

**贺拔伯圭**

- 公开诉求：由自己主导平叛，西线军政必须统一
- 隐性诉求：平叛是假，借机把蜀地战区也纳入自己权力半径是真
- 最易被撬动：**借刀、献策、离间**
    - 他最容易被“你若不先下手，中枢就会把功劳给别人”撬动

**独孤文约**

- 公开诉求：请战，但更强调“因势制宜、不可一味蛮打”
- 隐性诉求：扮演比贺拔更可控的西线替代者
- 最易被撬动：**试探、离间、献策**
    - 尤其适合从“你若太慢，贺拔就独吞全局”切入

**祖廷**

- 公开诉求：平叛必须奉诏而行，军饷和文官接管都归中枢统筹
- 隐性诉求：防止任何一路军头借平叛形成事实割据
- 最易被撬动：**放风构陷、谗言**
    - 很适合向他暗示“有人借叛乱之机图谋自专”

**贺拔琪**

- 公开诉求：尽快平蜀，但不能让西线离心
- 隐性诉求：既护弟，又不能让弟弟强到威胁摄政平衡
- 最易被撬动：**求援、献策、离间**
    - 她最容易被“如何保住你的人又不让其失控”所打动

---

## 回合 7｜建文八年上 / 天嘉四年上

**事件：西征议起，谁领兵、谁筹饷、谁坐镇中枢成为朝争核心**

**贺拔伯圭**

- 公开诉求：自己应总领西征
- 隐性诉求：拿到的不只是帅印，而是战后秩序的话语权
- 最易被撬动：**借刀、离间**
    - 可鼓动他主动逼宫式要权

**独孤文约**

- 公开诉求：愿辅军国，若朝廷信任也可独当一面
- 隐性诉求：绝不接受只做贺拔的副手
- 最易被撬动：**离间、试探、献策**
    - 极适合做“让他觉得自己被低估”的操作

**祖廷**

- 公开诉求：后勤归中枢、军令归朝廷，不能让西征变成军头私战
- 隐性诉求：用制度安排卡住贺拔与独孤的空间
- 最易被撬动：**献策、放风构陷**
    - 你越能提供“制度性防兵变”方案，他越容易被说服

**宇文棣**

- 公开诉求：西征不能完全落到后党/贺拔一系手里
- 隐性诉求：不让别人通过平蜀复制自己的南征首脑位置
- 最易被撬动：**谗言、离间**
    - 适合放大“祖廷与贺拔另有默契”

**贺拔琪**

- 公开诉求：选出可平事之人
- 隐性诉求：平衡各方，任何一方都不能凭此摆脱自己控制
- 最易被撬动：**求援、献策**

---

## 回合 8｜建文八年下 / 天嘉四年下

**事件：邺城与关中秋涝，北周清查仓廪**

**祖廷**

- 公开诉求：查仓、堵漏、统筹粮运
- 隐性诉求：借清仓扩大自己对各州郡、各势力财政链条的掌控
- 最易被撬动：**献策、放风构陷**
    - 很容易被“谁在侵吞军粮/仓储”这种线索驱动

**贺拔琪**

- 公开诉求：支持清查，安定朝野
- 隐性诉求：把赈灾和清查都包装成摄政秩序能力
- 最易被撬动：**献策、求援**

**令狐律光**

- 公开诉求：军粮必须优先，都城与禁军秩序不能乱
- 隐性诉求：防清查沦为后党内部敛权工具，损害国家整体军备
- 最易被撬动：**献策、谗言**
    - 适合从“有人借查仓而坏军心”切入

**独孤文约**

- 公开诉求：支持国家救灾
- 隐性诉求：借中枢忙于清仓之际，把西线资源链条藏得更深
- 最易被撬动：**试探、离间**

---

# 第三阶段：巴蜀线开启（回合 9–12）

## 回合 9｜建文九年上 / 天嘉五年上

**事件：西线未靖，帝党重提“不可久拖，应南征以定天下心”**

**宇文棣**

- 公开诉求：对陈不能再拖，拖只会让南陈养成大患
- 隐性诉求：重新把国家主议程拉回自己最擅长的“对陈强硬”
- 最易被撬动：**献策、谗言**

**令狐律光**

- 公开诉求：西线、边患、内附势力皆未定，不宜妄动南征
- 隐性诉求：压制帝党，同时维护自己“北周忠臣而非后党家臣”的位置
- 最易被撬动：**谗言、离间**
    - 很适合从“南征派只为个人功名”下手

**尉迟暮**

- 公开诉求：前线若战，当由自己统筹淮南
- 隐性诉求：需要南征这件事持续存在，才能维持其不可替代性
- 最易被撬动：**献策、求援**
    - 他偏务实，吃“前线怎么办”的建议

**宗艾**

- 公开诉求：转达皇帝对南北大战略的关切
- 隐性诉求：站在归政与军权再分配的交叉口，积攒信息和筹码
- 最易被撬动：**试探、谗言、求援**

---

## 回合 10｜建文九年下 / 天嘉五年下

**事件：南陈正式发动第一次征蜀行动**

**贺拔伯圭**

- 公开诉求：西线应急归我，总领平蜀
- 隐性诉求：把蜀战转成自己河西—蜀地的连续权力空间
- 最易被撬动：**借刀、献策**

**独孤文约**

- 公开诉求：自己也能出战、也能收拾蜀局
- 隐性诉求：避免西线战事让贺拔一家独大
- 最易被撬动：**离间、试探、献策**

**祖廷**

- 公开诉求：蜀地可救，但必须有中央接管预案
- 隐性诉求：用战时财政与文官接管抢回中枢控制力
- 最易被撬动：**放风构陷、献策**

**宇文棣**

- 公开诉求：南陈既然敢主动出兵，更证明北周不能长期守势
- 隐性诉求：借南陈外向行动打击后党“求稳”路线
- 最易被撬动：**谗言、离间**

---

## 回合 11｜建文十年上 / 天嘉六年上

**事件：蜀地僵持，北周争论战后如何安置西线兵权**

**贺拔伯圭**

- 公开诉求：功劳该归一线将帅，战后也该由熟悉西地之人继续镇守
- 隐性诉求：把“战时代理权”固化成“长期地方权”
- 最易被撬动：**借刀、离间**

**独孤文约**

- 公开诉求：战后秩序应更平衡，不应让单一路数独控西地
- 隐性诉求：争当战后调停者与利益分配的关键人
- 最易被撬动：**离间、试探**

**祖廷**

- 公开诉求：战后应文武分权，军政分离
- 隐性诉求：防止西线军头复制边镇割据模板
- 最易被撬动：**献策、放风构陷**

**贺拔琪**

- 公开诉求：谁有功赏谁，但国家不能失控
- 隐性诉求：保贺拔伯圭而不纵贺拔伯圭
- 最易被撬动：**求援、献策**

**令狐律光**

- 公开诉求：任何地方重兵都应受制于朝廷
- 隐性诉求：把“防西线军头”也变成自己安内路线的正确性证明
- 最易被撬动：**谗言、离间**

---

## 回合 12｜建文十年下 / 天嘉六年下

**事件：突厥再犯，并提出岁赐与互市条件**

**尔朱烈**

- 公开诉求：边镇要军械、要封赏、要更高政治承认
- 隐性诉求：在中原建立可持续的高位身份
- 最易被撬动：**献策、求援、离间**

**安思明**

- 公开诉求：要实打实资源，以备北线反击
- 隐性诉求：为未来回草原做长期准备
- 最易被撬动：**献策、试探**

**令狐律光**

- 公开诉求：内附草原势力不可过分纵容
- 隐性诉求：要在边患中证明自己“识边患、能压边患”
- 最易被撬动：**谗言、放风构陷**
    - 特别适合从“草原势力忠诚可疑”切

**宗艾**

- 公开诉求：代表皇帝维持边地联系与朝廷威信
- 隐性诉求：看保皇线是否能借草原势力做自己的暗手
- 最易被撬动：**试探、求援、谶纬**
    - 若要做宫中秘谋，他是天然接口

---

# 第四阶段：北周内部张力上升（回合 13–16）

## 回合 13｜建文十一年上 / 天嘉七年上

**事件：北方疫疠流行，谶言四起**

**贺拔琪**

- 公开诉求：迅速定人心、止谣言、控朝局
- 隐性诉求：把“灾异”从自己摄政合法性上剥离
- 最易被撬动：**求援、献策、谶纬**
    - 她对“如何止谣而不显心虚”很敏感

**祖廷**

- 公开诉求：禁谣、救灾、维持行政秩序
- 隐性诉求：避免宗室、保皇派借天灾做政治文章
- 最易被撬动：**放风构陷、献策**

**宗艾**

- 公开诉求：在宫中维系皇帝声音
- 隐性诉求：趁谶言回合把“天命在谁”变成可操作资源
- 最易被撬动：**谶纬、试探、谗言**
    - 他是这类回合最适合被“改叙事”的人之一

**宇文棣**

- 公开诉求：国有灾，不妨碍定国策
- 隐性诉求：灾异若能削弱太后正当性，他不会放过
- 最易被撬动：**谗言、谶纬**

---

## 回合 14｜建文十一年下 / 天嘉七年下

**事件：小皇帝亲政意愿抬头，帝党与后党围绕归政暗斗**

**宗艾**

- 公开诉求：代皇帝感知群臣忠诚，促进“君臣沟通”
- 隐性诉求：把自己做成皇帝与各派之间不可替代的中间人
- 最易被撬动：**试探、求援、借刀**
    - 他非常适合被拿来“借刀”触发宫中路线

**宇文棣**

- 公开诉求：归政本是正理，宗室应扶皇帝
- 隐性诉求：借归政削弱太后，但不一定真的愿皇帝完全自主
- 最易被撬动：**离间、谗言**
    - 尤其适合挑拨他与皇帝之间“忠而被疑”

**贺拔琪**

- 公开诉求：国事未定，归政过早
- 隐性诉求：绝不让自己经营五年的中枢轻易旁落
- 最易被撬动：**求援、献策**

**祖廷**

- 公开诉求：归政须有次第，不可骤然扰乱政务系统
- 隐性诉求：守住自己作为后党中枢执行者的位置
- 最易被撬动：**献策、放风构陷**

- 隐性诉求：继续压帝党路线，同时防太后与贺拔系联手过强
- 最易被撬动：**谗言、离间**

**贺拔琪**

## 回合 16｜建文十二年下 / 天嘉八年下

**事件：南陈正式发动征淮南战役**

**尉迟暮**

- 公开诉求：前线要人、要粮、要授权
- 隐性诉求：借大战把自己从“边帅”抬到“国之柱石”
- 最易被撬动：**献策、求援、借刀**
    - 若已有高信任，他甚至能被推动去针对某位朝臣逼宫要资源

**宇文棣**

- 公开诉求：举国应战，不得内耗
- 隐性诉求：战争是自己天然擅场，绝不能让后党把战时资源握死
- 最易被撬动：**谗言、离间、献策**

**令狐律光**

- 公开诉求：淮南可救，但都城、河北、北边不能空
- 隐性诉求：压住帝党借战争吞并国家全部资源
- 最易被撬动：**谗言、献策**
    - 很容易被“有人想借国战掏空都城防务”刺激

**宗艾**

- 公开诉求：代皇帝督听前线战况
- 隐性诉求：把战时报捷、报忧变成宫中权力资源
- 最易被撬动：**试探、求援、借刀**

# 第五阶段：淮南大战拖长（回合 17–20）

## 回合 17｜建文十三年上 / 天嘉九年上

**事件：淮南久战，征发日重，前线后方俱疲**

**尉迟暮**

- 公开诉求：继续增援，不可半途而废
- 隐性诉求：不能让自己背“久战无功”的锅
- 最易被撬动：**求援、献策**
    - 他最容易接受“如何让朝廷继续支持你”的方案

**祖廷**

- 公开诉求：精打细算、统筹军粮、遏制财政崩盘
- 隐性诉求：把久战责任重新定义为“前线无能而非中枢无策”
- 最易被撬动：**放风构陷、献策**

**令狐律光**

- 公开诉求：必须重新评估久战成本
- 隐性诉求：证明自己的“安内为先”从头到尾都是对的
- 最易被撬动：**谗言、离间**

**宇文棣**

- 公开诉求：战争既开，不可示弱
- 隐性诉求：绝不让自己成为“误国主战派”的最终背锅者
- 最易被撬动：**谗言、求援**
    - 若局面不佳，他会对“谁在拖我后腿”的叙事更敏感

- 隐性诉求：若能压住草原势力，就能进一步证明自己路线正确

- 隐性诉求：看能否把草原势力秘密绑定到保皇线

## 回合 19｜建文十四年上 / 天嘉十年上

**事件：连年兵灾叠加灾耗，北周出现“大清查、大征发、大整肃”呼声**

**祖廷**

- 公开诉求：大整肃、大清查，重建国家汲取与调度能力
- 隐性诉求：以最后一次大整顿把中枢重新握紧
- 最易被撬动：**借刀、放风构陷、献策**
    - 这是他最容易被“点名整人”的回合

**贺拔琪**

- 公开诉求：非常时行非常法
- 隐性诉求：借危机重塑摄政秩序，至少守住自己的政治遗产
- 最易被撬动：**求援、献策、借刀**

**宇文棣**

- 公开诉求：整肃可以，但不能变成后党清洗异己
- 隐性诉求：把整肃导向“清理无能中枢”和“前线掣肘者”
- 最易被撬动：**谗言、借刀**

**宗艾**

- 公开诉求：传递皇帝对国家危局的忧惧
- 隐性诉求：大乱局是他最容易做暗中穿针引线的时刻
- 最易被撬动：**借刀、试探、谶纬**

**贺拔伯圭**

- 公开诉求：西线不可因整肃而削权
- 隐性诉求：如果中央想动自己，就要摆出地方反噬能力
- 最易被撬动：**离间、求援、借刀**

## 回合 20｜建文十四年下 / 天嘉十年下

**事件：十年周期总摊牌，南北进入终局结算**

这一回合本质是“全员亮底牌”，不再适合给每个人都写长篇，而适合按终局心态概括。

**宇文棣**

- 公开诉求：集中全力压住南陈
- 隐性诉求：若局势不利，迅速寻找替罪对象
- 最易被撬动：**谗言、求援**

**贺拔琪**

- 公开诉求：守住中枢、稳住国家
- 隐性诉求：至少确保自己一系不被终局清算
- 最易被撬动：**求援、献策**

**祖廷**

- 公开诉求：资源再集中、秩序再整顿
- 隐性诉求：保住自己作为“国家机器总阀门”的地位
- 最易被撬动：**借刀、放风构陷**

- 公开诉求：救国而非救派系
- 隐性诉求：谁真在祸国，谁就该在终局被处理
- 最易被撬动：**谗言、离间**

**尉迟暮**

- 公开诉求：前线必须得到最后支持
- 隐性诉求：不能让自己战败独背骂名
- 最易被撬动：**求援、献策**

**贺拔伯圭**

- 公开诉求：西线与关中不能被抽干
- 隐性诉求：若中央将倾，自己必须先保地盘
- 最易被撬动：**离间、借刀**

**独孤文约**

- 公开诉求：愿为朝廷分忧
- 隐性诉求：无论谁赢，自己都要成为还能谈条件的人
- 最易被撬动：**试探、离间、献策**

**尔朱烈**

- 公开诉求：边地需要朝廷承认其功
- 隐性诉求：拿到真正的中原高位
- 最易被撬动：**求援、离间**

**安思明**

- 公开诉求：要资源、要支持
- 隐性诉求：把北周当作重返草原的跳板
- 最易被撬动：**献策、试探**

**宗艾**

- 隐性诉求：终局时最大化自己的存续空间与交易价值
- 最易被撬动：**借刀、试探、谶纬**

## 2. 非关键人物补全口径

### 2.1 帝党朝堂人物

- 遇到南征 / 淮南 / 征发主题：
  - 默认反馈方向：借题推动主战、争军权、争皇权话语
- 遇到灾年 / 疫病 / 地方失控主题：
  - 默认反馈方向：把问题解释为后党治国失当，而非主战路线本身有误
- 遇到归政 / 宫中 / 谶言主题：
  - 默认反馈方向：把名分问题转成削后党、抬宗室、抬皇权的机会

### 2.2 后党朝堂人物

- 遇到南征 / 淮南 / 征发主题：
  - 默认反馈方向：不是绝对反战，而是坚持兵粮节奏必须握在中枢
- 遇到灾年 / 疫病 / 地方失控主题：
  - 默认反馈方向：借整顿、赈务、检籍、清查扩大中枢穿透力
- 遇到归政 / 宫中 / 谶言主题：
  - 默认反馈方向：先稳秩序、控流言、守接口，不让名分问题脱离自己控制

### 2.3 陇右人物

- 遇到西线 / 蜀地 / 河西主题：
  - 默认反馈方向：把危机转成扩军、扩饷、扩地盘的机会
- 遇到南征 / 淮南主题：
  - 默认反馈方向：表面谈国事，实则先算会不会抽空西线或影响地方权
- 遇到整肃 / 清查 / 归政主题：
  - 默认反馈方向：高度警惕中枢借乱碰地方军政链条

### 2.4 草原人物

- 遇到北边 / 边患 / 互市主题：
  - 默认反馈方向：抬价、要甲具、要封赏、要更高政治承认
- 遇到南征 / 淮南主题：
  - 默认反馈方向：观望谁更需要边军，借机谈条件
- 遇到整肃 / 归政 / 宫中主题：
  - 默认反馈方向：并无忠忧，只衡量这是否会改变自己的交易对象与筹码

## 3. 冯道之提示的补充规则

- 每回合优先点名该回合 `核心 NPC`
- 若某个核心 NPC 已死亡，则**不再点名**
- 点名不是直接给答案，而是提示：
  - 谁最急
  - 谁最怕失控
  - 谁最在意兵、粮、诏令、名分、地方权、边镇价码中的哪一个
- 若核心 NPC 死亡过多，则冯道之改为提示：
  - "本回合哪一条权力链已经断了"
  - "现在哪些还活着的人在接替原有位置"
