# 第三方审阅后续待讨论清单

日期：2026-04-23  
用途：承接第三方 Agent 对计谋系统文稿的审阅结果，把“仍值得讨论，但不属于当前必须立刻改”的点单独拎出来，方便后续继续与外部 Agent、策划和文案协同。

---

## 一、这份清单的定位

这一轮里，我们已经完成了两类动作：

1. 把第三方 Agent **判断正确、且属于文档表达问题**的部分，已经同步修进了  
   `北周计谋系统可解释性整理_2026-04-21.md`
2. 把第三方 Agent **因为看不到本地代码而误判**的部分，已经在当前线程中核清，不再作为问题继续推进

所以，这份清单只保留第三类事项：

- 它们不是“现在就错了”
- 也不是“已经彻底解决了”
- 而是“后面继续优化时，值得重新拿出来讨论”的点

---

## 二、建议继续讨论的点

### 1. 角色矩阵是否要做一版“阅读版”副本

当前矩阵已经满足了最初的设计目标：

- 每个施计对象一张表
- 横轴是全部计谋
- 纵轴是全部 10 位北周可施计对象
- 每个交点都写清“理想上想击中哪层数值或结构”

但代价也很明显：  
信息很完整，同时也比较密。

**为什么这件事值得继续讨论**

- 给内部设计和数值调优看，现在这版是对的
- 但如果之后要交给不熟悉机制的人快速理解，可能还需要一版“阅读版矩阵”

**可能的后续方向**

- 保留当前完整版作为“设计底稿”
- 另做一版简化副本，把单元格收成：
  - 个人值
  - 派系值
  - 国力值
  - 外部三值
  四类标签式表达

这不是当前必须做，因为现在我们的目标仍然是机制澄清，而不是对外展示优化。

---

### 2. `求援` 是否还要再强化“结构后果”

当前机制里，`求援` 并不只是“关系经营”：

- 会提升信任
- 对朝堂人物求援时，还会给对应派系补一层 `朝堂影响`

这已经比第三方 Agent 以为的“只有信任变化”更完整。

**为什么这件事还值得继续讨论**

虽然机制上它有结构后果，但玩家体感上，`求援` 仍然偏像“求一句话、求一层遮护”。  
它和 `试探` 的差异，现在更多还是在语义和 prompt 气质上，而不完全体现在前端可见反馈里。

**可能的后续方向**

- 不一定改数值
- 先考虑是否在结算解释层或 NPC 反馈里，让 `求援` 的“庇护 / 借势 / 交换条件”更明确

换句话说，这更像表现层深化，不是当前机制缺口。

---

### 3. `谗言 / 离间` 的“信任上升”是否值得在矩阵里显性展开

当前机制上，`谗言 / 离间` 成功后，施计对象是会更信任玩家的。  
这件事我们已经在文档里补充说明过。

**为什么这件事还值得继续讨论**

现在我们采取的写法是：

- 矩阵格子优先写“第二目标受击效果”
- 施计对象自身的 `信任↑` 作为共通副作用放在阅读说明里

这是正确且紧凑的写法，但也意味着：

- 专业读者能懂
- 非专业读者仍可能觉得“为什么格子里没写信任↑”

**可能的后续方向**

- 继续保持现在的写法，不动
- 或者给矩阵再加一列“施计对象共通副作用”

这属于“表达风格取舍”，不属于机制问题。

---

### 4. 普通朝堂角色攻击贺拔琪 / 宗艾时，是否要有更细的“人物化效果”

当前设计已经明确：

- 普通四个朝堂处置链目标，主要走 `皇帝恩宠 / 太后眷顾`
- 贺拔琪、宗艾作为两套庇护来源，本身不走双庇护链，而是直接受击于派系值

这个逻辑现在是成立的。

**为什么这件事还值得继续讨论**

虽然机制层已经说得通，但在“体感”上仍可能有一个问题：

- 玩家对祖珽、宇文棣等人动手时，会看到更明确的“个人庇护被削”
- 玩家对贺拔琪、宗艾动手时，看到的是更结构化的“派系受压”

这会让两者在沉浸感上有一点不对称：

- 前者像“我在打一个人”
- 后者像“我在打一整派”

**可能的后续方向**

- 不改底层数值结构
- 只在 NPC 回应或结算说明里，让贺拔琪/宗艾更明确表现出“我这一派的盘子被打松了”

这仍然更偏表现层优化，而不是机制漏洞。

---

### 5. 地方军头之间的跨目标博弈，是否要继续细分

当前矩阵里，地方军头之间使用 `谗言 / 离间` 的格子，已经能表达：

- 打忠诚
- 打军力
- 打协作链
- 推动其更偏自立、割据或翻脸

这已经足够支撑现有玩法。

**为什么这件事还值得继续讨论**

从“可解释性”角度看，它现在还是偏抽象：

- 独孤文约更像“另起方案”
- 贺拔伯圭更像“坐地自雄”
- 尔朱烈更像“公开翻脸”
- 安思明更像“体系性抽离”

这些差别，在文稿里已经有，但如果未来继续做数值精修，可能还会想继续把它们分得更细。

**可能的后续方向**

- 不是现在就加新数值
- 而是未来如果继续做地方军头线深化，可以考虑让“离心方向”表现得更明确

这属于玩法深化方向，而不是当前版本的问题。

---

### 6. `externalStatus` 是否还要继续弱化

当前 `externalStatus` 已经从核心数值退到了：

- 阶段标签
- 终局标签

它现在主要服务于：

- `已割据 / 已反叛` 这样的状态展示
- 某些残局和终局判断

**为什么这件事还值得继续讨论**

虽然我们已经把它从主数值层弱化了，但它还没有被完全删掉。  
后续如果继续做系统瘦身，仍然可能回头问一句：

- `watchful` 还有没有长期保留价值？
- 是否最终只保留 `loyal / secession / rebellion` 三档？

这不是当前要解决的问题，因为现在它已经不会误导玩家主流程理解了。  
但它仍是一个可以在更后阶段再做的“简化设计”议题。

---

## 三、这些点为什么不急着现在改

当前计谋/数值系统最重要的工作已经完成：

- 数值链更清晰了
- 计谋之间的分工更分明了
- 朝堂与地方两条线能用同一套文稿解释清楚
- 战役展示也已经从“前期硬剧透”改成了更自然的战役记录板块

所以此时最重要的，不是继续把每个角落都打磨成最完美的文案或最细的说明，  
而是先让当前版本保持：

- 机制闭环稳定
- 文稿解释不自相矛盾
- 外部 Agent 审阅时不再反复卡在基础定义上

这份清单里的内容，都属于“下一轮继续深化时，再拿出来讨论”的项。

---

## 四、建议的后续使用方式

如果后面还有外部 Agent 继续审：

1. 先给它最新版  
   `北周计谋系统可解释性整理_2026-04-21.md`
2. 再给它这份  
   `第三方审阅后续待讨论清单_2026-04-23.md`

这样它会更容易区分：

- 什么是已经修完的
- 什么是它之前误判的
- 什么才是现在仍值得继续提意见的

这样后续反馈会更聚焦，也能少走很多回头路。
