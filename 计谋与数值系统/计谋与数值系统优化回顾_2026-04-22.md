# 《佞臣》计谋与数值系统优化回顾

日期：2026-04-22  
定位：对外审阅用回顾文档  
用途：给未参与此前开发过程的 Agent、策划、文案、测试或外部协作者快速说明三件事：

1. 这一轮计谋/数值系统改动的起因是什么。  
2. 系统最终被我们改成了什么样。  
3. 我们为什么要这样改，希望玩家最终感受到什么。  

---

## 一、先说结论：这轮改动的本质，不是“再加几个数值”，而是把整套北周玩法从黑箱判分，改成一套能被玩家学会的结构系统

如果把这两天的改动压缩成一句话，那么就是：

**我们把《佞臣》北周线从“玩家输入一句话，系统神秘加减分”改成了“玩家输入 -> 打中某个中间层 -> 推动结构变化 -> 最终影响国力、战役与结局”的系统。**

这轮改动之后，系统最重要的变化不是多了多少字段，而是：

- 计谋的数值落点更明确了；
- 数值和数值之间的耦合关系更完整了；
- 很多原本只在代码里存在的中间层，开始有了玩家能理解的解释；
- 特色计谋不再只靠文案气氛区分，而是真正拥有了不同的结构作用。

---

## 二、这轮改动的起因：你最早提出的那一大串问题，核心其实都指向同一件事

从表面上看，你最早提出的是一长串分散的问题，例如：

- `暗线 / 情报进度` 到底会影响什么，为什么能解锁外部行动；
- 地方军头的 `军力` 为什么存在感这么弱，看起来几乎只有谶纬在动它；
- `忠诚度` 和 `externalStatus` 会不会是重复值；
- `谗言 / 离间 / 设局嫁祸 / 谶纬 / 借刀` 到底分别打在哪一层；
- `献策` 为什么有时看起来像是在帮北周，结果却在伤北周；
- 贺拔琪、宗艾这类派系入口人物被施计后，到底是伤了什么，不该只是“气氛受损”；
- 帝党 / 后党的 `朝堂影响 / 军事实力 / 内部稳定` 三值，究竟怎样继续传导到南征和国力；
- 战役动量和战役结果的关系不够直观，玩家很难知道自己前几回合到底推了什么；
- 结算页里很多话虽然说了，但玩家还是不知道“我这一步到底打中了哪一层”。

这些问题看起来各不相同，但本质上都在指向同一个核心矛盾：

> **系统内部已经开始变复杂，但玩家能看到的，仍然主要只有“输入”和“结果”，中间那条真正有策略性的传导链还不够清楚。**

换句话说，问题不再是“有没有机制”，而是：

- 机制之间是否彼此接通；
- 接通之后玩家是否能看懂；
- LLM 参与裁判时，这些机制是否被收束成了可控、可复盘、可解释的结构。

因此，这轮工作的真正起点，不是继续凭感觉调几个数值，而是先把系统重新定义清楚。

---

## 三、我们最初想解决的，不只是平衡问题，而是五类更底层的问题

### 1. 数值定义不清

玩家能看到很多值，但不一定知道它们各自负责什么。

最典型的是：

- `信任` 是“愿不愿意继续听你说”
- `暗线` 是“你有没有摸透这个人真正会被什么撬动”
- `忠诚度` 是“这个人还甘不甘心替朝廷卖命”
- `军力` 是“这个人现在手里还有多少真实可动员的兵势、资源和硬实力”
- `externalStatus` 不是和忠诚度重复，而是“这个人已经走到哪一个政治阶段”
- `皇帝恩宠 / 太后眷顾` 不是普通好感，而是“这个朝臣在御前和帘前还剩多少庇护”
- `朝堂影响 / 军事实力 / 内部稳定` 不是装饰条，而是派系真正会向下外溢的结构值

如果这些值的定义不清，玩家自然会觉得很多系统像重复值，或者像 AI 随机判出来的。

### 2. 计谋与数值的耦合不够均衡

在旧版本里，朝堂线已经有一些耦合，但地方军头线明显更弱，尤其是：

- `信任` 很有存在感；
- `忠诚度` 也有存在感；
- `军力` 却更像一个只在终局才想起来的结果值。

这会让地方军头玩法从策略游戏退化成单线程玩法，玩家只会盯着“忠诚度够不够低”，却不知道自己是不是在帮对方“养刀”、是不是已经在拆对方的刀。

### 3. 特色计谋边界模糊

在旧体验里，很多计谋虽然名字不同，但玩家体感上的差异并不够明显。

例如：

- `谗言` 和 `离间` 都像是在说坏话；
- `设局嫁祸` 和 `谶纬` 都像是在制造嫌疑；
- `献策` 看上去像好话，但数值逻辑不够直观；
- `借刀` 玩家也不容易明白它其实不是“制造嫌疑”，而是“兑现已经成熟的嫌疑”。

这会让计谋系统失去学习曲线，玩家很难形成“我为什么此时该用这一计，而不是另一计”的手感。

### 4. 玩家只能看到头尾，看不到中间

旧版本最常见的体验是：

- 玩家知道“这一手成了”；
- 也知道“北周国力掉了一点”；
- 但不知道为什么这一次只是铺垫、下一次可能就能借刀；
- 也不知道为什么这一步明明没有立刻伤很多国力，却已经把一条战役线或割据线往前推了一大截。

所以我们后面提出了一个更明确的设计目标：

> 要让玩家逐步理解，自己每次施计其实在经营三种不同的链条：

- 朝堂削势链
- 地方离心链
- 战役准备链

### 5. AI 裁判自由度过大，需要被结构收束

如果系统只说“把一句话交给 AI，让它自己判断有没有用”，那玩法很容易变成黑箱。

我们后面一直在做的工作，本质上就是在给 AI 判定加边界：

- 不同计谋应优先看什么；
- 不同计谋允许影响哪些中间值；
- 这些中间值又如何继续向下传导；
- 解释层如何把这件事翻译成人话。

这既是为了提升玩家体验，也是为了让后续自动化 QA 和数值平衡更可控。

---

## 四、最终我们把系统改成了什么样：从“单点成败”改成了“三层传导”

### 1. 系统总读法：不再只看一句话有没有说服人，而是看它打中了哪一层

当前最新版的北周计谋系统，已经可以用下面这张总图来理解：

### 第一层：输入层

也就是玩家真正操作的部分：

- 选施计对象
- 选计谋类型
- 输入计谋内容

### 第二层：中间层

这一层是这轮改动的重点，也是我们花最大力气补齐和解释的部分：

- `信任`
- `暗线`
- `忠诚度`
- `军力`
- `皇帝恩宠`
- `太后眷顾`
- `朝堂影响`
- `军事实力`
- `内部稳定`
- `externalStatus`
- `courtStatus`

### 第三层：结果层

中间层继续向下导出的结果，主要包括：

- 北周国力五维变化
- 割据 / 造反推进或兑现
- 罢黜 / 处决推进或兑现
- 战役准备与战役结果
- 派系崩口、崩盘、朝局反噬

这意味着玩家现在真正经营的，不是“几句话的表演效果”，而是一张结构网。

---

## 五、这轮改动后，三条主要玩法链已经被明确写清并接进了代码

## 1. 朝堂削势链

当前正确的读法是：

`试探 / 献策 -> 谗言 / 离间 -> 设局嫁祸 / 谶纬 -> 借刀 -> 罢黜 / 处决 -> 派系值与国力受损`

这条链现在已经不是抽象概念，而是有明确数值支点：

- `试探` 用来提信任、开暗线、摸清人物真正关心的东西；
- `谗言 / 离间` 不只是制造气氛，而是能真实压低目标的 `皇帝恩宠` 或 `太后眷顾`；
- `设局嫁祸 / 谶纬` 用来把嫌疑和名分裂缝打到更重的程度；
- 当某个角色的 `皇帝恩宠` 和 `太后眷顾` 同时低于阈值后，他会进入可罢黜 / 可处决链；
- 最后只有通过贺拔琪或宗艾的 `借刀`，才能把成熟嫌疑兑现成组织处理。

这条链想实现的效果，不是“玩家突然就杀了谁”，而是：

- 先经营入口；
- 再拆庇护；
- 再做嫌疑；
- 最后再收网。

也就是说，`借刀` 现在终于被明确成了“兑现”，而不是“制造”。

## 2. 地方离心链

当前正确的读法是：

`试探 -> 献策 -> 谗言 / 离间 / 设局嫁祸 / 谶纬 -> 忠诚与军力变化 -> 煽动割据 / 煽动造反 -> 外部势力失控 -> 国力受损`

这条链这次被补强得最明显的地方有三个：

### 第一，`暗线` 不再是设定文本，而是真正的门槛

现在地方军头的高阶动作不只看信任，还看暗线：

- 试割据需要足够暗线；
- 试造反需要更多暗线；
- 暗线本质上代表“你是不是已经知道这人真正会被什么撬动”。

### 第二，`军力` 不再只是终局结算值

这是这轮最重要的机械补强之一。

现在军力会受到多类计谋的影响：

- 对地方军头本人 `献策`，可能让其军力上升；
- 对地方军头本人 `设局嫁祸`，可能让其军力下降；
- 对地方军头施 `谶纬`，常见是“军力小降、忠诚更降”；
- 借别人之口对地方军头施 `谗言 / 离间`，也可能连带打到其忠诚与军力。

这让地方军头线从原来的“只看忠诚度”升级成了“离心与资源并行”。

### 第三，`externalStatus` 被重新定义成阶段标签，而不是隐藏主数值

这一点是较新的收束结果。

我们没有把 `externalStatus` 完全删掉，但把它从“额外核心惩罚轴”弱化成了：

- 阶段标签
- 终局标签

现在更推荐这样理解：

- `忠诚度` 是主数值，决定离心温度；
- `军力` 是资源与伤害放大器；
- `信任` 决定你还能不能继续推进；
- `externalStatus` 更多负责说明这个人已经走到了 `观望离心 / 已割据 / 已反叛` 的哪一步。

在最新版本里，普通压力也不再自动把人推成 `watchful`，`watchful` 也不再额外叠一层隐藏惩罚去双重压外援。  
这一步的目的，就是让地方军头系统更符合玩家直觉，不再像第四个偷偷生效的黑箱数值。

## 3. 战役准备链

当前正确的读法是：

`献策 / 试探 / 谶纬 / 问政 -> 触碰战区关键 -> 形成战役准备与战区风向 -> 战役记录板块展示 -> 最终战果`

这条链的变化主要有两层：

### 第一层：机制层

战役不再是“到了回合直接掷骰子”，而是会累计：

- 粮道
- 军备
- 调度
- 法统动员
- 前线人心
- 问政方向

只有真正碰到这些关键层的计谋，才会形成有效战役推进。

### 第二层：表现层

我们后面又把早期太难理解、又有剧透问题的“局势伏线 / 战役动量”展示收掉，改成了更直观的战役记录板块：

- `巴蜀之战` 只在对应回合窗口出现；
- `淮南之战` 只在对应回合窗口出现；
- 前期铺垫不再强行让玩家“开天眼”；
- 战役真正开始时，再统一回顾之前几回合积累了什么，并在战役过程中持续记录态势与结果。

这一步的目的，是把“战役准备链”从后台判定，变成玩家能复盘、能理解、也不至于过早被剧透的玩法层。

## 六、各类计谋最终被我们改成了什么样

这一部分是外部 Agent 最值得重点看的，因为它直接回答“计谋边界最后是怎样定的”。

## 1. 试探

### 起因

旧体验里，`试探` 很容易像一个低存在感的前置动作，玩家只知道它能涨一点信任，却不一定知道它为什么重要。

### 最终改法

现在 `试探` 的功能被重新明确成了三件事：

- 提升信任；
- 推进暗线解锁；
- 在某些条件下切中战区关键，顺带推进战役准备。

### 想实现的效果

让 `试探` 从“开场白”变成真正的铺路动作。  
玩家应该理解：这一步不一定当回合见血，但很多高阶动作本来就建立在它身上。

## 2. 献策

### 起因

你最早指出的问题非常关键：  
如果玩家写的献策真的是利于北周整体国力的，那北周就应该受益；只有“利人害国”的献策，才应该伤北周。

### 最终改法

`献策` 被正式拆成了三种结果：

- `真利国`
- `空泛模糊`
- `利人害国`

其效果也分别不同：

- 真利国：北周五维真的受益；
- 空泛模糊：轻微拖累治理与秩序；
- 利人害国：直接伤北周治理、财政、粮赋、秩序；
- 如果对象是地方军头，还可能同时让其信任上升、忠诚下降、军力上升。

### 想实现的效果

让 `献策` 从“表面看上去都是好话”变成真正需要玩家思考利益结构的计谋。  
玩家需要明白：

- “对 NPC 个人有利”不等于“对北周整体有利”
- 真正有价值的坏献策，应该是利人害国，而不是纯粹写一句看起来很阴的话。

## 3. 谗言

### 起因

旧版里 `谗言` 容易像纯粹的人际台词，玩家不一定能感知到它已经触发了更深的结构后果。

### 最终改法

现在 `谗言` 已经不是只有“关系变差”这一层，而是会沿着三条路径生效：

- 伤朝堂关系与派系值；
- 在军事型人物上产生战略外溢；
- 如果第二目标是地方军头，还能顺带打到其忠诚和军力。

在朝堂处置链里，它尤其重要，因为它已经能真实降低某些角色的单边庇护值。

### 想实现的效果

让 `谗言` 成为“撬动怀疑与上报链”的计，而不是单纯骂人。  
玩家应该逐步学会：这类计谋的价值，不只在于当回合削一点国力，而在于把某个目标往可处置区间推。

## 4. 离间

### 起因

旧体验里，`离间` 和 `谗言` 差别不够大。

### 最终改法

`离间` 被明确成更偏“拆协作链”的计谋，因此：

- 比谗言更容易伤 `内部稳定`；
- 更容易影响派系协作、军事节奏、粮道调度；
- 若第二目标是地方军头，也可能顺带打忠诚和军力。

### 想实现的效果

让玩家把 `谗言` 和 `离间` 区分开：

- 谗言更像挑起怀疑；
- 离间更像拆掉合作和共同利益。

## 5. 设局嫁祸

### 起因

你当时提出：如果“设局嫁祸”只是简单制造嫌疑，不足以区分它和其他计谋；它应当更像让目标陷入失言、失态、失措。

### 最终改法

当前 `设局嫁祸` 被明确成：

- 对朝堂人物：推进高阶嫌疑链，并直接轻中度伤国；
- 对地方军头：同时可能打到忠诚和军力，因为中枢会更防他、资源会收紧；
- 在 NPC 回应层：也被要求表现为更明显的慌乱、自辩、急于解释。

### 想实现的效果

让 `设局嫁祸` 既有强烈的戏剧性，也有清晰的机制落点。  
玩家应该感受到：这不是“多一种挑拨话术”，而是让目标自己掉进局里、背上嫌疑。

## 6. 借刀

### 起因

早期最容易误解的一点就是：`借刀` 好像也是在制造嫌疑。

### 最终改法

现在 `借刀` 被彻底定义为“成熟嫌疑的兑现动作”：

- 只有双边庇护被压到阈值以下，才有意义；
- 只有贺拔琪、宗艾这类有正式收网权的人物才能完成；
- 一旦成功，会按不同角色类型真实重伤北周五维。

### 想实现的效果

让 `借刀` 真正变成高阶收网动作，而不是普通挑拨的同义词。  
玩家应当知道：如果前面没把链条铺好，借刀就不该有结果。

## 7. 谶纬

### 起因

你一直明确希望 `谶纬` 是特色玩法，而且强度应当偏高。但同时，你也明确指出它不能只是一句玄学话，而应该有完整链路。

### 最终改法

`谶纬` 现在被明确成“打名分、打法统、打不祥”的特色计：

- 对朝堂人物：高质量谶纬会直接伤 `治理`、`社会秩序`，高强度时继续伤 `财政 / 粮赋`；
- 对地方军头：核心逻辑不是直接劝反，而是让中枢起疑、进而收紧资源，造成“军力小降、忠诚更降”；
- 在引导层和代拟层：也加入了“双段结构”，即谶辞 / 征兆 + 解释 / 指向。

### 想实现的效果

让 `谶纬` 真正成为《佞臣》的特色高阶计谋：

- 它强，不只是因为数值大；
- 而是因为它打的是合法性和政治秩序。

## 8. 煽动割据 / 煽动造反

### 起因

你很早就指出：照旧逻辑走，普通玩家其实很难自然摸到割据/造反玩法。

### 最终改法

我们没有把它们做成“随便一点就能成功”，而是把前置链补清楚了：

- 先要有足够信任；
- 再要有足够暗线；
- 再要把忠诚压低；
- 再看军力和回合窗口。

此外，成功后的结果也更明确：

- 割据：坐地自雄，真实伤国；
- 造反：公开反旗，伤害更重。

### 想实现的效果

让地方线不是“隐藏彩蛋”，而是一条玩家能理解、也能一步步经营出来的玩法。

---

## 七、这轮改动后，几个最关键的结构问题被怎样处理了

## 1. 贺拔琪 / 宗艾不再像“被施计却打不到数值”的空气角色

### 起因

你当时最尖锐的质疑之一就是：  
如果对贺拔琪、宗艾施计，最后只是文案里说“后党受损”“帝党受损”，但没有真正的数值落点，那玩家会觉得这就是打空气。

### 最终改法

我们没有给他们硬加一套新的“恩宠轴”，而是把他们定义成：

- 派系入口人物
- 收网入口人物

因此，对他们施压时，主要受击位置变成了：

- 对贺拔琪：优先伤后党的 `朝堂影响 / 内部稳定`
- 对宗艾：优先伤帝党的 `朝堂影响 / 内部稳定`

这些派系值又会继续向下传导到：

- `治理`
- `社会秩序`
- 部分 `财政 / 粮赋 / 军事`

### 想实现的效果

让“打中枢人物”这件事有真实后果，但又不把他们生硬塞进和四个朝堂处置目标完全一样的机制里。  
也就是说，玩家打贺拔琪和宗艾，不是为了把他们送上处决链，而是为了打他们那一派的统筹力和号召力。

## 2. `externalStatus` 最终没有删掉，但被明显弱化了

### 起因

你后面补充得很明确：  
如果 `externalStatus` 只是一个不那么重要、拿走也不影响玩法理解的指标，那干脆可以删，因为前端真正呈现给玩家的还是军力、忠诚度、信任度三值。

### 最终改法

最后的处理不是直接删字段，而是把它弱化成：

- 终局态标签
- 阶段态标签

并把真正的玩法刹车收回到：

- `忠诚度`
- `军力`
- `信任`

最新版本里：

- 普通忠诚下跌不再自动升级成 `watchful`
- `watchful` 不再额外双重惩罚外部支持
- 新档地方军头初始状态也统一收回 `loyal`
- 终局状态如 `secession / rebellion` 则继续保留，并会影响目标可操作链路和终态展示

### 想实现的效果

保留“这个人已经走到哪一步”的政治阶段信息，但不要让玩家额外背一个看不见、却在暗中强烈生效的第四条主数值。

## 3. `schemeEngine` 的 fallback 和 explainability helper 被收束了

### 起因

这属于工程层问题，但它跟玩法长期稳定性直接相关：  
如果 parse fallback 四处散落，或者 explainability helper 各页各写各的，后面继续调系统时就很容易出现“同一个状态在三个页面说法不一样”“某个计谋忘了补字段”的情况。

### 最终改法

我们做了两类收束：

- 把 `schemeEngine` 里重复的默认 parse fallback 提成共享结构；
- 把若干 explainability helper 收成共享逻辑，让朝堂页、施计页、详情页不要再各说各话。

### 想实现的效果

不是为了代码漂亮，而是为了让这套计谋/数值系统后续还能继续扩，不至于每加一条链就开始漂移。

---

## 八、这轮改动后，玩家视角的解释层被重新设计了

这是外部 Agent 审阅时非常值得关注的一点。

旧问题不是“系统没算”，而是“系统算了，玩家没看见”。  
因此我们后来集中做了一轮解释层重构。

### 1. 单条计谋结算不再胡乱堆信息，而是强调两个核心标签

当前玩家在单条计谋筹算结果里，重点看到的是：

- `国力影响`
- `朝堂政局`

这背后的意思分别是：

- `国力影响`：这一手是不是已经顺着权力链、粮道、兵权、调度或法统真正打到了北周五维
- `朝堂政局`：这一手即便没有当场大伤国，也可能已经拆了合作、种了疑心、动了派系平衡

旧的第三段“局势伏线”则被移出了单条计谋卡片，避免前期战役信息太早、太拗口。

### 2. 战役信息从零散动量提示，改成统一的战役记录板块

也就是前面提到的：

- `巴蜀之战`
- `淮南之战`

这不是单纯换个标题，而是一次解释方式上的重做：

- 前期不再强迫玩家理解抽象“战役动量”；
- 等真正到战役窗口，再统一告诉玩家：此前几回合到底积累了什么，当前局势推进到了什么程度。

### 3. 结算层开始更明确区分三类后果

虽然前端最后没有把三段标签全部永久可见，但我们这轮机制思维已经明确区分了三类后果：

- 直接伤国
- 结构施压
- 状态推进

这件事非常重要，因为它决定了玩家能否理解：

- 为什么这一步没立刻掉很多国力，却很有价值；
- 为什么另一种计谋虽然现在只掉一点点，但再下一回合就能收网。

## 九、如果要把这轮改动概括成“起因 -> 改法 -> 目的”，最重要的是下面这张对应表

| 起因 / 原始问题 | 最终改法 | 想达到的效果 |
| --- | --- | --- |
| 玩家看不懂暗线到底有什么用 | 把暗线与外部高阶动作解锁直接绑定 | 让 `试探` 和情报经营有真实机械价值 |
| 地方军头军力存在感太弱 | 让 `献策 / 设局嫁祸 / 谗言 / 离间 / 谶纬` 都可能影响军力 | 让地方线变成“忠诚 + 资源”双线玩法 |
| `忠诚度` 和 `externalStatus` 看起来重复 | 把忠诚度保留为主数值，把 externalStatus 弱化为阶段/终局标签 | 保留阶段信息，但减少黑箱感 |
| `献策` 逻辑混乱，看起来什么都能伤国 | 把献策拆成“真利国 / 空泛 / 利人害国”三态 | 让玩家真正理解“利人未必利国” |
| 贺拔琪 / 宗艾被打后像打空气 | 把两人定义为派系入口，受击落点挂到派系值 | 让中枢人物受击有真实结构后果 |
| `谗言 / 离间` 差异不明显 | 明确前者偏怀疑链、后者偏协作链与稳定链 | 让玩家学会按结构选择计谋 |
| `借刀` 像普通挑拨的同义词 | 明确借刀只负责兑现成熟嫌疑，由正式收网人物执行 | 让高阶计谋有节奏感与门槛感 |
| 谶纬只是玄学气氛，不够像特色玩法 | 明确谶纬打法统、打名分、打中枢疑心，并在地方线形成“军力小降、忠诚更降” | 让谶纬真正成为有辨识度的特色玩法 |
| 割据 / 造反难以自然摸到 | 把信任、暗线、忠诚、军力、窗口条件整合成可学习的前置链 | 让普通玩家也能理解外部线该如何一步步推进 |
| 战役动量难懂且容易剧透 | 改成只在战役窗口出现的战役记录板块 | 让战役准备变成可复盘、不过早剧透的玩法层 |
| 玩家只能看到输入和结果，看不到中间层 | 重做 explainability，把中间层翻译成结算语言和状态提示 | 让玩家逐渐觉得“自己在经营结构”，而不是碰运气 |
| AI 裁判自由度太大、难复盘 | 把不同计谋的允许影响范围和结构落点逐步写清 | 提升稳定性、可解释性和后续自动化调优能力 |

## 十、截至最新版，这轮工作已经形成了怎样的“最终状态”

如果按最新版来概括，这轮计谋/数值系统优化已经形成了一个比较稳定的底盘：

### 已经明确成立的部分

- 朝堂处置链已经闭环：`信任 -> 恩宠/眷顾 -> 借刀 -> 罢黜/处决`
- 地方离心链已经闭环：`信任/暗线 -> 忠诚/军力 -> 割据/造反`
- 贺拔琪 / 宗艾已有明确数值受击落点，不再是空气角色
- 军力已经不再只是终局装饰值，而是真正可被多种计谋影响的玩法值
- `externalStatus` 已从重复核心数值收成阶段/终局标签
- 结算解释层已经开始围绕“国力影响 / 朝堂政局”来组织
- 战役中间层的可见化方式已经从抽象动量，改成战役记录板块

### 当前更像“下一阶段继续优化”的部分

- 普通玩家如何更自然摸到割据 / 造反，还可以继续加强教学
- 战役数值本身仍可继续平衡
- 冯道之与女帝这两条 AI 输出链，还可以像北周 NPC 一样继续做更细的反应矩阵

也就是说，底层结构现在已经不像一团散沙了。  
后续再优化时，我们不需要重做整个系统，而是在一个已经理顺的底盘上继续往前走。

---

## 十一、为什么这份回顾值得给其他 Agent 审阅

因为这轮改动真正重要的，不是“新增了多少规则”，而是：

- 我们已经明确了这套系统想服务什么样的玩家体验；
- 也明确了不同计谋应该分别打什么结构层；
- 同时又开始把表现层、解释层、工程层对齐。

对一个外部 Agent 来说，这份材料最值得关注的不是某个数值具体是 `-0.4` 还是 `-0.6`，而是下面三点：

1. 这套系统现在已经不再是黑箱评分，而是结构传导系统；
2. 各类计谋的职责边界已经比以前清楚很多；
3. 未来继续做调优时，应该优先沿着“可解释性 + 结构耦合 + 玩家学习曲线”这三条线看，而不是只盯着某个单独数值。

---

## 十二、最后一句话总结

这轮计谋/数值系统优化，真正完成的不是一次“调参”，而是一次**系统重命名**：

我们把《佞臣》北周线从“计谋成功率 + 国力加减”的旧读法，改成了“你在经营一整张权力结构网”的新读法。

只要这个前提成立，后续无论是继续做数值平衡、补教学、优化 AI 回应，还是让外部 Agent 继续审阅和接手，都会更有抓手，也更不容易返工。
