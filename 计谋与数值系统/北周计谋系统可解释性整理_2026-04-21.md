# 《佞臣》北周计谋系统可解释性整理

日期：2026-04-21  
2026-04-23 按最新版机制重排  
定位：对外策划案风格文档  
用途：按最初约定的四段结构，把北周线的“计谋 -> 数值 -> 结构 -> 国力后果”重新讲清楚，方便策划、文案、测试、UI 和外部协作者理解当前已经落地到游戏中的版本。

## 一、数值词典

这一节只回答两件事：

1. 这个值主要受什么影响。  
2. 这个值又会继续影响什么。  

当前北周系统里，真正重要的不是“某一条话术有没有被 AI 判高分”，而是玩家到底在打哪一层数值。

### 1. 信任

**它代表什么**  
这个人愿不愿意继续听你说，愿不愿意把你当成可用的说话对象。

**主要受什么影响**

- `试探`：最稳定的提升来源
- `献策`：尤其是当建议贴合此人个人利益时
- `求援`：更偏“你把我当自己人 / 你肯来找我”
- `谗言 / 离间` 成功：当 NPC 觉得你说到了他的疑心、私心或立场裂缝时，也可能升信任
- 高质量 `设局嫁祸 / 谶纬`：通常不以加信任为主，但在少数“你替我揭开局面”的语境里也可能略升
- 施计失败、说辞露底、连续高压：会掉信任

**它会继续影响什么**

- 某些计谋能否解锁
- 高阶计谋的基础成功率
- 玩家是否值得继续深挖同一角色
- 冯道之代拟和 NPC 回应时，是否会把你当“自己人 / 可利用的人 / 值得防的人”

### 2. 暗线 / 情报进度

**它代表什么**  
你摸透了这个人几张底牌，知道他真正会被什么触动。

**主要受什么影响**

- `试探` 成功：最主要来源
- 部分回合自动情报推进
- 朝局发展带来的被动暴露

**它会继续影响什么**

- 地方军头能否尝试 `煽动割据 / 煽动造反`
- 冯道之代拟时，能否写得更贴这个人的真实弱点
- 玩家自己是否已经从“这个人愿意听我说”走到“我知道该怎么把他推到下一步”

### 3. 忠诚度

**它代表什么**  
地方军头还甘不甘心继续替北周朝廷卖命。

**主要受什么影响**

- 对地方军头本人的 `献策`
- 借别人之口指向地方军头的 `谗言 / 离间`
- 对地方军头本人的 `设局嫁祸`
- 对地方军头本人的 `谶纬`
- 高阶外部动作推进、失败或终局后的状态结算
- 朝廷收紧资源、加强疑心时的连带反应

**它会继续影响什么**

- 是否接近 `割据 / 造反` 阈值
- 外部势力对朝局与南征风向的支撑程度
- 战役与国力层面的持续压力
- 玩家是否已经把此人从“替朝廷算账”推成“开始替自己算账”

### 4. 军力

**它代表什么**  
地方军头手里还有多少真实兵势、粮械、武备和调度能力。

**主要受什么影响**

- 对地方军头本人的 `献策`：可能上升
- 对地方军头本人的 `设局嫁祸`：可能下降
- 对地方军头本人的 `谶纬`：常见是小降
- 借别人之口指向地方军头的 `谗言 / 离间`：可能顺带打到
- `割据 / 造反 / 平叛` 相关结算

**它会继续影响什么**

- 这个军头平时是否值得朝廷忌惮
- 他一旦失控，能造成多大伤害
- 玩家现在是在“养一把刀”还是在“拆一把刀”
- 战役、地方失控和国力层面的最终伤害规模

### 5. 皇帝恩宠

**它代表什么**  
这个朝臣在御前还剩多少庇护。

**主要受什么影响**

- 借帝党入口人物之口施 `谗言 / 离间`
- 高质量 `设局嫁祸`
- 高质量 `谶纬`
- 某些高压回合里，对其不利的信息持续积累

**它会继续影响什么**

- 该角色是否接近 `可罢黜 / 可处决`
- 借刀链是否成熟
- 玩家这一步是不是已经开始触动真正的朝堂处置链

### 6. 太后眷顾

**它代表什么**  
这个朝臣在帘前还剩多少庇护。

**主要受什么影响**

- 借后党入口人物之口施 `谗言 / 离间`
- 高质量 `设局嫁祸`
- 高质量 `谶纬`

**它会继续影响什么**

- 与 `皇帝恩宠` 一起决定该角色是否进入罢黜 / 处决链
- 后党在某个朝臣身上还能不能继续替他托底

**补充说明**

- 贺拔琪、宗艾不走这一套个人双庇护链
- 原因不是他们更安全，而是他们本身就是两套庇护的来源：贺拔琪代表帘前，宗艾代表御前
- 所以打他们时，当前机制主要落到的是对应派系的 `朝堂影响 / 内部稳定`，而不是他们个人的 `皇帝恩宠 / 太后眷顾`

### 7. courtStatus

**它代表什么**  
朝堂处置链的最终状态。

当前主要状态包括：

- `在位`
- `已被罢黜`
- `已被处决`

**主要受什么影响**

- `皇帝恩宠`
- `太后眷顾`
- `借刀` 是否正式收网

**它会继续影响什么**

- 该角色是否继续留在普通朝堂博弈链中
- 该角色退出后对派系与国力造成的预设伤害

**当前真正适用的核心目标**

- 祖珽
- 宇文棣
- 令狐律光
- 尉迟暮

### 8. externalStatus

**它代表什么**  
地方军头当前走到了哪一个政治阶段。

当前主要状态包括：

- `loyal`：仍受节制
- `watchful`：观望离心
- `secession`：已割据
- `rebellion`：已反叛

**主要受什么影响**

- 高阶外部动作是否成功
- 割据 / 造反 / 平叛相关结算
- 特殊终局与残局状态

**它会继续影响什么**

- 角色是否仍可继续进入某些普通操作链
- 朝堂页、施计页、角色卡上的终态展示
- 锦囊、说明层和终局判定里的阶段表达

**当前最新版的特别说明**

- 它已经被弱化为“阶段 / 终局标签”
- 普通压力不再自动把人推成 `watchful`
- `watchful` 也不再额外承担核心双重惩罚
- 对玩家理解玩法来说，当前真正的主数值仍是：`忠诚度 + 军力 + 信任`

### 9. 派系值

当前帝党、后党各自都有三条核心值。

#### 朝堂影响

**主要受什么影响**

- 入口人物受压，如贺拔琪、宗艾被打
- 朝堂核心角色被谗言 / 离间 / 嫁祸 / 谶纬牵动
- 派系内部主导权、议程权和秩序感被触动

**它会继续影响什么**

- 北周 `治理穿透力`
- 北周 `社会秩序`
- 南征政治风向

#### 军事实力

**主要受什么影响**

- 军事型角色被削
- 战区主张、军令权、战功链被触动
- 地方与中枢间的军事支撑削弱

**它会继续影响什么**

- 北周 `军事`
- 北周 `粮赋`
- 战役准备质量

#### 内部稳定

**主要受什么影响**

- `离间`
- 高质量 `谗言`
- 入口人物与关键人物之间的协作关系破裂
- 派系内部出现互相掣肘

**它会继续影响什么**

- 北周 `治理穿透力`
- 北周 `社会秩序`
- 部分 `财政`

### 10. 国力五维

当前北周综合国力在玩法里主要表现为：

- `财政`
- `粮赋`
- `军事`
- `社会秩序`
- `治理穿透力`

下表只讲“常见受击来源”和“它继续决定什么”。

| 维度 | 常见受影响来源 | 它继续影响什么 |
| --- | --- | --- |
| 财政 | 利人害国的献策、派系内耗、文治中枢失序、谶纬高质量外溢 | 军费、调度能力、后续多维承压能力 |
| 粮赋 | 祖珽/令狐律光/尉迟暮等与粮运后勤有关的人物受损，战区调度受阻，利人害国的献策 | 军需、战役准备、地方军头可持续兵势 |
| 军事 | 将帅被削、战区主张被扰、派系军事实力下降、地方失控 | 南征成败、平叛成本、前线承压能力 |
| 社会秩序 | 派系裂缝、名分受损、谶纬外溢、治理失衡 | 朝局反噬、法统稳定、持续性国力下滑 |
| 治理穿透力 | 文治中枢被拆、入口人物受压、派系朝堂影响下降、设局嫁祸/谶纬直接打击 | 国家机器是否还能有效运转，很多后续伤害是否会被放大 |

## 二、计谋总表

这一节回答的是：

- 每种计谋主要打哪一层；
- 设计上它想让玩家实现什么效果；
- 在当前版本里，它更偏“铺路”“结构施压”还是“直接伤国”。

| 计谋 | 主要打哪一层 | 当前主要适用对象 | 当前已落地的核心效果 | 设计意图 |
| --- | --- | --- | --- | --- |
| 试探 | `信任 + 暗线` | 全体可施计对象 | 提信任、开暗线，少数情况下顺带推进战役准备 | 让玩家先摸透人，再决定往哪条链深入 |
| 献策 | `利益结构 + 国力五维 + 地方军头三值` | 朝堂人物、地方军头 | 已拆成“真利国 / 空泛 / 利人害国”三态；对地方军头还可能带来“信任升、忠诚降、军力升” | 让玩家真正思考“利人”和“利国”不是一回事 |
| 谗言 | `怀疑链 + 单边庇护 + 派系值` | 朝堂人物、地方军头 | 可压恩宠/眷顾，可伤派系值，可顺带打 related 地方军头忠诚/军力；在军政条件成立时，也可能直接外溢到 `军事 / 社会秩序 / 治理穿透力` | 让玩家通过“说到疑心处”去触发怀疑与上报链 |
| 离间 | `协作链 + 内部稳定 + 庇护链` | 朝堂人物、地方军头 | 比谗言更偏拆合作、拆协作，通常对内部稳定和战略节奏伤得更重 | 让玩家拆掉人和人之间的共同利益，而不只是挑疑心 |
| 设局嫁祸 | `高阶嫌疑链 + 直接伤国 + 地方资源收紧` | 朝堂人物、地方军头 | 对朝堂人物能推进处置链并直接伤国；对地方军头能让忠诚和军力一起受损 | 让目标自己掉进局里、露出失言失态失措 |
| 借刀 | `处置兑现层` | 仅贺拔琪、宗艾可正式收网 | 不制造嫌疑，只兑现成熟嫌疑；成功后直接造成角色退出与重度伤国 | 让高阶收网有节奏、有门槛 |
| 求援 | `信任 + 庇护 + 交易感` | 朝堂人物、地方军头 | 更偏提信任、争取庇护或交换条件；对朝堂人物求援时，还可能替对应派系补一层 `朝堂影响` | 让玩家在高压局里建立“可以求、能换、要付价”的关系 |
| 谶纬 | `合法性 + 名分 + 中枢疑心` | 朝堂人物、地方军头 | 对朝堂人物直打治理/秩序；对地方军头常见是“军力小降、忠诚更降” | 让《佞臣》的特色玩法真正打到法统和政治秩序 |
| 煽动割据 | `外部终局动作` | 地方军头 | 成功则进入 `已割据`，并按军力规模真实伤国 | 让地方线有“坐地自雄”的高阶兑现 |
| 煽动造反 | `外部终局动作` | 地方军头 | 成功则进入 `已反叛`，伤害更重；失败也可能有平叛成本 | 让地方线有更激进、更高风险的终局选择 |

## 三、角色矩阵

这一节按你最新要求，恢复成“真矩阵”版本。  
每一张表都固定一个**施计对象**；横轴是**全部计谋**，纵轴是**全部 10 位北周可施计对象**。  
单元格里写的不是台词，而是**当前已落地版本里，这一步理想上最想击中哪一层数值或结构**。

为把地方军头的 `信任 / 忠诚 / 军力` 一并纳入说明，这里纵轴不只列纯朝堂人物，而是统一列出全部 10 位北周可施计对象。

**阅读说明**

- `—`：当前机制不适用
- `暗线+`：新增或推进一条暗线
- `信任↑`：对主角信任上升
- `皇恩↓`：皇帝恩宠值下降
- `眷顾↓`：太后眷顾值下降
- `影响↓`：对应派系朝堂影响下降
- `稳定↓`：对应派系内部稳定下降
- `忠诚↓`：地方军头忠诚度下降
- `军力↓ / 军力↑`：地方军头军力变化
- `嫁祸`=`设局嫁祸`；`割据`=`煽动割据`；`造反`=`煽动造反`
- `试探 / 献策 / 嫁祸 / 求援 / 谶纬 / 割据 / 造反` 在当前版本里主要是**单目标计**，因此通常只有“本角色”这一行有值；`谗言 / 离间 / 借刀` 才是跨目标矩阵
- `谗言 / 离间` 在当前版本里必须有第二目标，因此自我行通常记为 `—`
- 跨目标格默认优先写“第二目标受击效果”；施计对象自身因计谋成功而获得的 `信任↑`，属于这类计谋的共通副作用，已统一写在第一节“信任”与第二节“计谋总表”里，不在每个交点重复展开
- `谗言 / 离间` 压哪边庇护，取决于施计对象的派系位置：通过后党人物施计，主要压目标的 `太后眷顾`；通过帝党人物施计，主要压目标的 `皇帝恩宠`；通过地方军头施计时，不直接压双庇护，而更偏打派系协作或地方三值

## 四、关键传导链

这一节只讲当前玩家最应该理解的几条主链。  
它们不是文案上的抽象描述，而是当前版本已经落地的玩法骨架。

### 1. 朝堂处置链

当前正确读法是：

1. 先用 `试探 / 献策` 经营入口角色，提信任、摸底牌  
2. 用 `谗言 / 离间` 去打单边庇护  
3. 用 `设局嫁祸 / 谶纬` 去打更重的嫌疑与名分裂缝  
4. 当同一目标的：
   - `皇帝恩宠`
   - `太后眷顾`
   都掉到阈值以下时，进入可罢黜 / 可处决区间  
5. 最后借贺拔琪或宗艾之手，通过 `借刀` 正式收网  

**这条链想让玩家学会什么**

- `借刀` 不是制造嫌疑，而是兑现成熟嫌疑
- 入口人物不是终点，而是通向终点的权力通道
- 单回合不见血，不代表这一步没有价值

### 2. 地方军头离心链

当前正确读法是：

1. 先把地方军头的 `信任` 养起来  
2. 再通过 `试探` 开足够的暗线  
3. 用 `献策 / 谗言 / 离间 / 设局嫁祸 / 谶纬` 去同时动：
   - `忠诚度`
   - `军力`
4. 等信任、暗线、忠诚、窗口条件都到位后，再尝试：
   - `煽动割据`
   - `煽动造反`
5. 最终把地方离心兑现成对北周的真实伤害  

**这条链想让玩家学会什么**

- 不是“忠诚够低就能反”
- 而是“你有没有先养关系、摸底牌、再决定是养刀还是拆刀”

### 3. 派系值如何汇入国力

当前帝党 / 后党的三条派系值，不是展示条，而是真会向下传导。

#### 朝堂影响下降后，常见后果

- 北周 `治理穿透力` 下降
- 北周 `社会秩序` 下降
- 南征风向更难被这一派稳定主导

#### 军事实力下降后，常见后果

- 北周 `军事` 下降
- 北周 `粮赋` 承压
- 战区准备和前线支撑变差

#### 内部稳定下降后，常见后果

- 北周 `治理穿透力` 下降
- 北周 `社会秩序` 下降
- 一部分 `财政` 被内耗拖累

**这条链想让玩家学会什么**

- 你打的是一个人，但掉下来的可能是整派的结构能力
- 派系值很多时候是“结构伤”，不是立刻见血的“直伤”

### 4. 补充：战役准备链

虽然这份文档的主轴仍然是北周计谋与数值，但按最新版机制，有必要补一句战役链的当前读法。

当前正确读法是：

1. `献策 / 试探 / 谶纬` 和南陈问政一起，持续累计战役准备  
2. 不是所有成功计都能推进战役，只有真正碰到：
   - 粮道
   - 军备
   - 调度
   - 法统动员
   这类关键层时，才会形成有效推进  
3. 到战役窗口后，前端不再用抽象“战役动量”硬塞给玩家，而是通过：
   - `巴蜀之战`
   - `淮南之战`
   两个战役记录板块去统一回顾、展示和结算  

**这条链想让玩家学会什么**

- “朝堂说热了”不等于“前线就被推动了”
- 真正能推战役的，是碰到了战区关键层的计谋

## 结语

按最新版机制来看，北周线现在真正有意思的地方，已经不是“这句话会不会被 AI 判高分”，而是：

- 你判断这个人真正怕什么、想要什么；
- 再判断这一手该打信任、打关系、打名分，还是打地方离心；
- 最后让局势顺着权力结构自己往下滚。

因此，玩家现在真正经营的不是一堆孤立台词，而是四张会互相咬合的网：

1. 朝堂削势网  
2. 地方离心网  
3. 派系传导网  
4. 战役准备网  

只要后续继续把表现层和说明层追平，这套系统就会越来越像一盘可以被学会、被复盘、也值得反复推演的权力游戏。
